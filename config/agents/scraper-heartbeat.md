# HEARTBEAT.md

## 定期タスク: 南関東競馬データ自動取得

### スケジュール
- **実行タイミング**: レース開催日のみ（南関東4場: 大井・船橋・川崎・浦和）
- **実行時刻**: 毎日 21:00 JST（最終レース終了後）
- **スキップ条件**: 南関東4場すべてが非開催の日はスキップ

### タスク内容

#### 1. 過去1週間分のレース結果取得（漏れ防止）
```bash
nankan scrape --from-date $(date -v-7d +%Y-%m-%d) --to-date $(date +%Y-%m-%d) --venue all
```
- 直近1週間分をまとめて取得することで、前回取得漏れがあっても補完される
- 既存データは upsert で上書きされるため重複の心配なし

#### 2. 取得結果の確認
- SQLite の races / race_entries テーブルに新規レコードが追加されたか確認
- エラーが発生した場合はログを記録し、次回実行時にリトライ

#### 3. 完了報告
- 取得したレース数・エントリー数をサマリーとして報告
- エラーがあった場合は orchestrator エージェントに通知

### 注意事項
- netkeiba.com へのアクセスはレート制限（3秒+ジッター）を必ず遵守
- HTML キャッシュ（data/cache/）を活用し、不要なリクエストを避ける
- 長時間のスクレイピングが予想される場合はバッチを分割して実行
