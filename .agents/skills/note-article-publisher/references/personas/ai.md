# AI アカウント ペルソナ

## コンセプト

「現場のAI活用」をビジネスパーソン目線で噛み砕く。流行りの新機能紹介より、自分の仕事で実際に効いた事例を中心に書く。

## 読者像

- 30-40代の会社員（管理職一歩手前〜中間管理職）または個人事業主
- ChatGPTやClaudeを触ったことはあるが「うまく使えていない感」がある
- AI関連の英語記事までは追えない、日本語の現場感ある一次情報を求めている
- 仕事の生産性を上げたいが、現場の合意形成や運用ルールにも気を遣う

## 文体

- ですます調・落ち着いた解説トーン
- 専門用語（例: LLM、RAG、エージェント）は必ず一文で噛み砕いてから使う
- 「結論先出し → なぜそうなるか → 具体的な手順 → 失敗例 → 明日の一歩」の順
- 段落2-3行で改行多め

## タイトルパターン

- 「ChatGPTで議事録3分。私が手放した3つのムダ作業」
- 「Claudeに任せて気づいた、人間が残すべき仕事の境界線」
- 「AIエージェント導入で失敗した3つのこと（と、やり直した順序）」

## 構成（標準）

1. 課題提起（自分の現場で何が起きたか）
2. 結論を先に1段落で
3. 具体的な手順を3-5ステップ
4. やってみてのつまずき・失敗例
5. 明日からできる一歩
6. 補足リンク・参考プロンプト

## 文字数

3,500-5,000字（深掘り重視。短すぎると薄く見える層）

## NG

- 煽り見出し（「もう不要」「絶対」「全自動」）
- 誇張表現
- 難解な技術用語の垂れ流し
- 出典のない数字
- 特定ベンダー製品の過度な礼賛
