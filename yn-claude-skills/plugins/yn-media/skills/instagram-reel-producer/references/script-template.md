# Step 4 詳細: 台本作成（45秒リール動画用）ルール集

SKILL.md の Step 4 から呼び出される詳細ルール。台本作成時は必ずこのファイルを読み込んでから執筆する。

Step 2のディープリサーチ情報を元に、以下の構成で45秒の台本（セリフのみ）を作成する。

## シーン構成（45秒・6シーン）

| シーン | 秒数 | 内容 |
|--------|------|------|
| 1. フック | 0-3秒 | ネガティブ訴求のワンフレーズ |
| 2. フック補足 | 3-8秒 | フックの理由を具体数字で提示 |
| 3. 待遇①（給与・ボーナス） | 8-18秒 | 年収、賞与、具体的な金額 |
| 4. 待遇②（福利厚生・働きやすさ） | 18-28秒 | 休日数、残業、離職率、認定 |
| 5. 強み・未経験OKポイント | 28-38秒 | シェア、中途採用比率、研修 |
| 6. 企業名明かし | 38-45秒 | 「その会社は、○○。」 |

**各シーンの秒数は厳守すること。** 台本にはシーン番号と秒数を明記する。

## シーン詳細

**シーン1: フック（0-3秒）**
- 冒頭でネガティブ訴求。ワンフレーズ厳守。
- 以下の6パターンをローテーションで使用する（複数企業を制作する場合は順番に回す）

   **パターンA：「入社禁止」パターン**
   - 例）「ここに絶対入社しないで。」

   **パターンB：「警告」パターン**
   - 例）「この会社、調べないでください。」

   **パターンC：「後悔」パターン**
   - 例）「この会社を知ってしまった人、ご愁傷様です。」

   **パターンD：「閲覧注意」パターン**
   - 例）「転職する気がない人、今すぐスワイプして。」

   **パターンE：「罪悪感」パターン**
   - 例）「この動画、同僚には絶対見せないで。」

   **パターンF：「禁止」パターン**
   - 例）「今の仕事が好きな人は、この先見ないでください。」

**シーン2: フック補足（3-8秒）**
- フックの理由を具体的な数字で。
- 例）「なぜなら、賞与が138万円。待遇が良すぎて、もう他の会社に転職する気が無くなります。」

**シーン3: 待遇①（8-18秒）**
- 給与・ボーナスの具体的な金額
- 平均年収、賞与○ヶ月分 or ○○万円

**シーン4: 待遇②（18-28秒）**
- 年間休日、有給取得日数、残業時間
- 住宅関連（寮・社宅の家賃負担）、食堂、ポイント制度
- 離職率の低さ、健康経営優良法人認定

**シーン5: 強み・未経験OKポイント（28-38秒）**
- 企業の優位性（「世界シェアNo.1」「穴場ホワイト企業」など）
- 30代未経験でも応募しやすい情報（中途採用比率、研修制度）

**シーン6: 企業名明かし（38-45秒）**
- 「その会社は、○○。」で社名を提示
- ここまでは絶対に社名を伏せること

## テロップ文字数ルール（厳守）

- **1ページあたり最大48文字**（12文字×4行）
- 1シーン内で複数ページに分けてもよいが、1ページの上限は必ず守ること
- 台本の各セリフは、テロップ1ページ単位で改行して記載する
- 1行あたり12文字を超える場合は改行位置を明示する
- 数字・記号も1文字としてカウントする

**テロップページ数の目安:**

| シーン | 秒数 | テロップページ数 |
|--------|------|-----------------|
| 1. フック | 3秒 | 1ページ |
| 2. フック補足 | 5秒 | 1〜2ページ |
| 3. 待遇① | 10秒 | 2〜3ページ |
| 4. 待遇② | 10秒 | 2〜3ページ |
| 5. 強み | 10秒 | 2〜3ページ |
| 6. 企業名 | 7秒 | 1ページ |

## ナレーション口調ルール（全シーン共通）

- **トーン**: 断定・煎り系。言い切る。迷わない。
- **語尾**: 「〜だ。」「〜する。」「〜やばい。」「〜すぎる。」（「〜です」「〜ます」は使わない）
- **テンポ**: 1文は短く。句読点で区切る。体言止めを多用する。
- **パワーワード必須**: 「人生イージーモード」「勝ち組」「驚愕の」「ガチで」「えぐい」「神待遇」などの感情を動かす言葉
- **わかりやすさ**: 小学校低学年でも分かる簡単な表現を使う
- **禁止事項**:
  - 丁寧語（です・ます調）
  - 回りくどい説明
  - 曖昧な表現（「〜かもしれない」「〜らしい」）
  - 1文が20文字を超える長いフレーズ

## 台本作成の補足ルール

- シーン6までは社名は伏せること
- セリフだけの構成にすること（ト書き・演出指示は別セクションで）
- 30代未経験でも採用される情報があれば入れること
- 内容は事実のみを記載すること
- 待遇面はリサーチ情報から作成すること
- 具体的な数字にする（例：賞与額なら〇か月分ではなく〇〇万円のように具体的に）

## 出力フォーマット

台本はテロップページ単位で記載する。各ページは `[P1]` `[P2]` …で区切り、12文字×4行（最大48文字）以内であることを明記する。

```
# [企業名] リール台本（45秒）

## シーン1: フック（0-3秒）【パターン○】
[P1] (18文字)
ここに絶対
入社しないで。

## シーン2: フック補足（3-8秒）
[P2] (32文字)
なぜなら、
賞与が138万円。
待遇が良すぎて、
もう転職する気なくなる。

## シーン3: 待遇①（8-18秒）
[P3] (○○文字)
平均年収○○○万円。
賞与は○ヶ月分。
ガチでえぐい。

[P4] (○○文字)
...

## シーン4: 待遇②（18-28秒）
[P5] (○○文字)
...

[P6] (○○文字)
...

## シーン5: 強み（28-38秒）
[P7] (○○文字)
...

[P8] (○○文字)
...

## シーン6: 企業名（38-45秒）
[P9] (○○文字)
その会社は、○○。
```

**注意**: 各ページの文字数を `(○○文字)` で明記し、48文字を超えていないことを必ず確認すること。

## 出力

台本は以下の**2ファイル**を保存する：

1. **`台本.txt`** — シーン構成・ページ番号 `[P1]`・文字数付き（テロップ編集用）
2. **`台本_セリフのみ.txt`** — ナレーションのセリフだけを抽出したもの（読み上げ・収録用）。シーン番号、ページ番号、文字数カウント、見出しは一切含めない。セリフの間は空行で区切る。

```
[出力先ディレクトリ]/[企業名]/台本.txt
[出力先ディレクトリ]/[企業名]/台本_セリフのみ.txt
```

出力先ディレクトリの実行環境固有パスは SKILL.md の「注意事項」を参照する。
