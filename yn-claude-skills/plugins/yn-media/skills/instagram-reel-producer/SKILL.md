# Instagramリール動画制作スキル (Instagram Reel Producer)

## 概要

このスキルは、1投稿に対して1企業の求人情報を発信するInstagramアカウント（@tenshoku_nocareer）のリール動画制作素材を自動生成します。企業名を入力するだけで、求人調査からキービジュアル取得、台本・キャプション・カバーキャッチコピーまでを一括で作成します。

## 入力

- **企業名**（必須）: 対象企業名（指定がない場合はStep 1で自動ピックアップ）

## 前提情報

- **発信者**: 45歳男性。キャリアコンサルタントで人事経験20年のプロフェッショナル。
- **ターゲット**: 転職活動をしている30代。
- **トーン**: 説得力のある落ち着いた雰囲気。
- **アカウント**: @tenshoku_nocareer

## ワークフロー

### Step 1: 企業検索（対象企業のピックアップ）

※企業名が指定されている場合はこのステップをスキップします。

1. `browser`ツールで転職求人サイト（doda、エン転職、マイナビ転職）にアクセスします。
2. 以下の条件で求人を検索します：
   - **勤務地**: 東京、神奈川、大阪
   - **雇用形態**: 正社員
   - **未経験歓迎**であること
3. 条件に合致する企業をピックアップし、対象企業を決定します。

---

### Step 2: ディープリサーチ（企業情報の収集）

`browser`ツールで対象企業の求人情報を中心に、以下の情報を詳細に調査します。

#### 調査項目

- **待遇面の詳細（数字で説得力を演出）**
  - 給与・ボーナス：具体的な金額、平均年収や賞与は◯ヶ月分など
  - 福利厚生：年間休日、有給取得日数、住宅関連（寮・社宅の家賃負担）、食堂、ポイント制度など

- **働きやすさの証明**
  - 離職率の低さ、健康経営優良法人認定、残業時間の少なさ

- **企業の強み・特徴の提示**
  - 「世界シェアナンバーワン製品」や「社員が高待遇すぎる穴場ホワイト企業」など
  - 事実に基づく企業の優位性を具体的に示す

- **企業の事業内容・実績**
  - 歴史（創業年、事業展開）、具体的な市場シェア、グローバル展開状況など

- **リアルな課題・デメリット（信頼性向上）**
  - 「よくある退職理由」を示す

---

### Step 3: キービジュアル画像の取得

対象企業の公式HPからキービジュアル画像を20枚取得します。

#### 3-1. 公式HPの特定

1. `browser`ツールで企業名を検索し、公式HPのURLを特定します。
2. 公式HPのトップページにアクセスし、サイト構造を把握します。

#### 3-2. サイト巡回と画像URL収集

1. **トップページ**の画像を収集します。
2. サイト内の主要ページを巡回して、さらに画像を収集します。巡回対象：
   - サービス・事業内容ページ
   - ニュース・お知らせページ
   - コラム・レポート・ライブラリページ
   - 採用情報ページ
   - 企業情報・会社概要ページ
   - IR情報ページ
   - その他コンテンツページ
3. 以下の**除外対象**をフィルタリングします：
   - ロゴ画像（ファイル名に `logo` を含むもの）
   - アイコン画像（ファイル名に `icon` を含むもの、またはサイズが極端に小さいもの）
   - ヘッダー・フッター背景画像（ファイル名に `bg_header`, `bg_footer` を含むもの）
   - 関連サイト・外部リンクのバナー（ファイル名に `relation` を含むもの）
   - SNSアイコン・シェアボタン画像
   - 1px×1px のトラッキングピクセル
   - SVGファイル（装飾用が多いため）

#### 3-3. キービジュアルの選定基準

1. **解像度が高い画像を優先**: 幅800px以上、または高さ400px以上の画像を優先
2. **コンテンツ性のある画像**: メインビジュアル、バナー、記事サムネイル、サービス紹介画像、イベント画像など
3. **多様性の確保**: 同じページからの画像ばかりにならないよう、複数ページからバランスよく収集
4. **重複排除**: 同一画像（URLベース）は1枚のみ

#### 3-4. 画像のダウンロード

1. 保存先ディレクトリを作成します：
   ```bash
   mkdir -p /home/ubuntu/instagram_reel/[企業名]/images/
   ```
2. 選定した20枚の画像をダウンロードし、わかりやすいファイル名で保存します。
   - ファイル名の命名規則: `[カテゴリ]_[連番].[拡張子]`
   - 例: `kv_01.jpg`, `topics_01.jpg`, `banner_01.png`, `service_01.jpg`
3. ダウンロードに失敗した場合は、予備の画像URLから補充して必ず20枚を確保します。

#### 3-5. ZIP圧縮

```bash
zip -j /home/ubuntu/instagram_reel/[企業名]/kv_images.zip /home/ubuntu/instagram_reel/[企業名]/images/*
```

---

### Step 4: 台本作成（45秒リール動画用）

Step 2のディープリサーチ情報を元に、45秒・6シーン構成の台本（セリフのみ）を作成する。

シーン構成（フック→フック補足→待遇①→待遇②→強み→企業名明かし）、フックの6パターン、テロップ文字数ルール（1ページ最大48文字）、ナレーション口調ルール、出力フォーマットの詳細は **`references/script-template.md` を必ず読み込んでから**執筆する。

出力は以下の2ファイル（保存先パスは本ファイル末尾の「注意事項」を参照）：

1. **`台本.txt`** — シーン構成・ページ番号 `[P1]`・文字数付き（テロップ編集用）
2. **`台本_セリフのみ.txt`** — ナレーションのセリフだけを抽出したもの（読み上げ・収録用）

---

### Step 5: キャプション作成

キャプションの構成（フック→メンション→区切り線→投稿補足→区切り線→固定CTA→区切り線→固定著作権表記→固定ハッシュタグ）、400字以内ルール、固定CTA文言、固定著作権表記、固定ハッシュタグ、回答フォーマット例の詳細は **`references/caption-and-cover.md` を必ず読み込んでから**執筆する。

出力：
```
/home/ubuntu/instagram_reel/[企業名]/キャプション.txt
```

---

### Step 6: カバー画像のキャッチコピー作成

プロのSNSマーケター兼コピーライターとして、求職者の「不安」を取り除き、「欲望」を刺激する言葉選びを行う。中央2行構成・1行6〜10文字程度・週刊誌見出しトーンで、数字強調とギャップ（意外性）を必ず使う。制約条件・使用テクニック・参考事例・出力形式（5案）の詳細は **`references/caption-and-cover.md` を必ず読み込んでから**執筆する。

出力：
```
/home/ubuntu/instagram_reel/[企業名]/カバーキャッチコピー.txt
```

---

### Step 7: 成果物の保存と報告

1. **フォルダ構成の確認**: 以下の構成で全ファイルが揃っていることを確認します。
   ```
   /home/ubuntu/instagram_reel/[企業名]/
   ├── 台本.txt                 ← シーン構成・ページ番号・文字数付き
   ├── 台本_セリフのみ.txt       ← ナレーション用セリフのみ
   ├── キャプション.txt
   ├── カバーキャッチコピー.txt
   ├── kv_images.zip
   └── images/
       ├── kv_01.jpg
       ├── kv_02.jpg
       └── ... (計20枚)
   ```

2. **最終報告**: `message`ツールを使い、以下の内容をユーザーに報告してタスクを完了します。
   - 対象企業名と調査概要
   - 台本の全文
   - キャプションの全文
   - カバーキャッチコピー5案
   - キービジュアル画像の一覧（枚数・サイズ）
   - 全成果物のファイルをattachmentsとして添付

## 注意事項

- 本スキルの保存先パス `/home/ubuntu/instagram_reel/[企業名]/` は、Mac/Windowsのローカル環境ではなく別のサンドボックス実行環境を前提にしている可能性がある。YNFactory-cc の他スキルはリポジトリルート相対パスまたは `.company/outputs/` 配下を使う運用のため、実際にこのパスで動作しているか要確認（実行時挙動の変更は本ブラッシュアップのスコープ外のため、パス自体は書き換えていない）。
