# ショート動画自動編集スキル (Short Video Editor)

## 概要

動画素材を渡すだけで、ジェットカット・文字起こし・テロップ・Bロール（画像/動画）・効果音・BGM・レンダリング・品質検証ループまで全自動で実行する動画編集スキル。

## 起動時の質問（3つ）

スキル起動時にユーザーに以下を質問する:

1. **どの動画を編集しますか？** — 動画ファイルパスを受け取る（ドラッグ&ドロップ対応）
2. **画像生成はどうしますか？** — 選択肢: なし / 少なめ(3枚程度) / 普通(5枚程度) / 多め(8枚程度)
3. **タイトルはどうしますか？** — ユーザー指定 or 「いい感じに作って」で自動生成

## 前提条件

### 環境変数
- `OPENAI_API_KEY`: Whisper API用（文字起こし）
- `GEMINI_API_KEY`: NanoBanana2 画像生成用（画像Bロール）
- `RENOIZE_API_KEY`: Renoize動画生成用（動画Bロール、オプション）

### インストール済みツール
- **FFmpeg**: 動画解析・無音検出・カット・音声抽出
- **Remotion**: レンダリング・動画合成・最終書き出し
- **Editor Starter** (Remotion拡張): ブラウザベースのタイムラインエディター（localhost:5174）
- **Python 3** + openai パッケージ: Whisper API呼び出し
- **Node.js**: Remotion実行環境

### 素材フォルダ（スキルフォルダ内に配置）
- `assets/bgm/` — BGMファイル（事前に配置）
- `assets/se/` — 効果音ファイル（事前に配置）

## プロジェクトパス

- **作業ディレクトリ**: 動画ファイルと同階層に `{動画名}_edit/` を作成
- **出力先**: `{動画名}_edit/output/`

## ワークフロー全体像

```
動画素材 → [Step1] 解析(FFmpeg+Whisper) 
         → [Step2] 字幕品質チェック（並列エージェント）
         → [Step3] 編集プラン最適化（コンテンツプランナーエージェント）
         → [Step4] ジェットカット実行
         → [Step5] テロップ生成
         → [Step6] Bロール挿入（画像/動画）
         → [Step7] 音響設定（効果音+BGM）
         → [Step8] Remotionレンダリング
         → [Step9] 品質検証ループ（検証エージェント）
         → [Step10] 完成 → 次アクション選択
```

---

## Step 1: 動画解析（FFmpeg + Whisper）

1. FFmpegで動画から音声を抽出（WAV 16kHz mono）
2. FFmpegの `silencedetect` フィルタで無音区間を検出（**0.1秒単位**で記録）
3. OpenAI Whisper API に音声を送信
4. **ミリ秒単位**のタイムスタンプ付きセグメント・ワードデータを取得
5. `transcript.json` として保存（各ワードの開始・終了時刻をms単位で記録）

### 重要ルール
- タイムスタンプは全て**ミリ秒(ms)単位**で管理する
- 無音検出は**0.1秒**以上の余白があればカット対象とする

## Step 2: 字幕品質チェック（並列処理）

**`whisper-subtitle-checker` エージェントを並列起動する。**

このエージェントがWhisperの文字起こし結果を検証・修正する:
- 固有名詞の修正（例: カタカナ「クロード」→ 英語「Codex」）
- 誤認識の修正（文脈から判断）
- 専門用語の正確な表記チェック
- 句読点・区切りの最適化

## Step 3: 編集プラン最適化

**`video-content-planner` エージェントを起動する。**

このエージェントが編集プランを構築する:
- カットポイントの決定（どこで切るべきか）
- 不要なタイムラインの除去判定
- Bロール挿入ポイントの決定
- テロップの強調ポイント（赤色テロップ）の決定
- 全体の構成・流れの最適化

結果は `editplan.json` として保存。

## Step 4: ジェットカット実行

`editplan.json` に基づいてFFmpegでカット:

### カットルール
- **無音部分**: 0.1秒以上の無音は全てカット
- **フィラーワード**: 「えー」「あの」「まあ」等を削除
- **重複ワード**: 同じ言葉を2回連続で言っている場合、最初の1回を削除（例:「ウェブサイトの、ウェブサイトの」→「ウェブサイトの」）
- **噛んだ箇所**: 言い直しがある場合、最後の正しい発話のみ残す
- カット精度は**0.1秒単位**

## Step 5: テロップ（字幕）生成

### テロップルール
- **1テロップ最大15文字**まで
- 自然な区切りで分割する（文節・助詞の後で区切る）
- フォント: Noto Sans JP Bold
- 通常テロップ: **白文字 + 黒アウトライン**
- 強調テロップ: **赤文字 + 白アウトライン**（`editplan.json` で指定されたポイント）
- 位置: 画面下部、話者の顔の**やや下**に固定配置
- テロップと音声の同期精度: **0.2秒以内**

### タイトルバナー
- 画面上部に**常時表示**
- **黄色背景 + 黒文字**
- タイトルテキストはStep起動時の質問で決定した内容

## Step 6: Bロール挿入

### 画像Bロール（NanoBanana2 / Gemini API）
- `editplan.json` で指定されたタイミングに画像を生成・挿入
- 生成枚数はユーザー指定（なし/3枚/5枚/8枚）
- 映像の切り替わり演出として使用
- アスペクト比は元動画に合わせる（ショート動画なら9:16）

### 動画Bロール（Renoize、オプション）
- `RENOIZE_API_KEY` が設定されている場合のみ
- Renoize CLIを使って短尺動画を生成
- 内容に合ったイメージ動画を生成し、適切なタイミングに挿入
- アスペクト比は元動画に合わせる
- FacePas機能: ユーザーの顔写真が登録されていれば人物を統一

## Step 7: 音響設定

### 効果音（SE）
- `assets/se/` フォルダから効果音を使用
- 挿入タイミング:
  - 映像が切り替わるタイミング
  - 赤色テロップ（強調）の表示タイミング
- 音量: メイン音声の邪魔にならないレベル

### BGM
- `assets/bgm/` フォルダからBGMを使用
- 動画全体に敷く
- 音量: メイン音声より十分に小さく（-20dB程度）

## Step 8: Remotionレンダリング

Remotionを使って全要素を合成:
1. ジェットカット済み映像
2. テロップ（ASS字幕 or Remotionテキスト）
3. タイトルバナー
4. Bロール（画像/動画）
5. 効果音 + BGM

→ `output/final.mp4` として書き出し

### レンダリング時の注意
- カット間に**黒フレーム（暗転）が入らない**ようにする
- シーンつなぎ目に**ブツッというノイズが入らない**ようにクロスフェード処理
- H.264 CRF18 高品質出力

## Step 9: 品質検証ループ

**`video-quality-checker` エージェントを起動する。**

完成動画に対して以下を検証し、**全項目が合格するまでループ修正**する:

1. Whisperで完成動画を**再解析** → 不要な文字起こしデータがないか確認
2. テロップと音声の同期が**0.2秒以内**かチェック
3. テロップの位置が話者の**顔と被っていない**かチェック
4. 効果音の音量が**大きすぎ/小さすぎないか**チェック
5. BGMの音量が**大きすぎ/小さすぎないか**チェック
6. カット間に**黒フレーム（暗転フラッシュ）がないか**チェック
7. シーンつなぎ目に**ブツッという異音がないか**チェック
8. ジェットカットの**余白が0.1秒以上残っていないか**チェック
9. 重複ワードが**残っていないか**チェック

→ 不合格項目があれば自動修正して再レンダリング → 再検証 → 合格まで繰り返す

## Step 10: 完成後アクション

動画が完成したら、ユーザーに以下の3択を提示:

1. **エディターで最終調整** — Editor Starter (Remotion) をlocalhost:5174で起動し、タイムラインエディター上で手動微調整可能にする
2. **実画面の映像を挿入してから調整** — ユーザーが別途撮影した画面録画等をBロールとして追加挿入
3. **このままBGM追加で完成** — 現在の出力をそのまま最終版とする

## 出力ファイル構成

```
{動画名}_edit/
├── audio.wav                # 抽出した音声
├── transcript.json          # Whisper文字起こし結果（ms単位）
├── silence_ranges.json      # 無音区間データ（0.1秒単位）
├── editplan.json            # 編集プラン（カットポイント・Bロール位置・強調テロップ等）
├── subtitles.ass            # ASS字幕ファイル
├── images/                  # 生成画像（Bロール）
│   ├── broll_00.png
│   └── ...
├── videos/                  # 生成動画（Bロール、Renoize使用時）
│   ├── broll_00.mp4
│   └── ...
├── quality_report.json      # 品質検証結果ログ
└── output/
    └── final.mp4            # 完成動画
```

## エージェント依存

このスキルは以下の3つのサブエージェントを使用する:

| エージェント | 用途 | 起動タイミング |
|---|---|---|
| `whisper-subtitle-checker` | 文字起こし品質チェック・修正 | Step2（並列処理） |
| `video-content-planner` | 編集プラン構築・最適化 | Step3 |
| `video-quality-checker` | 完成動画の品質検証ループ | Step9（合格まで繰り返し） |
