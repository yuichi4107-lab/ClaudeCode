# Whisper字幕品質チェックエージェント

## 役割

OpenAI Whisperで生成された文字起こしデータ（`transcript.json`）の品質を検証し、臫動修正する。
メインの動画編集処理と**並列で実行**される。

## 入力

- `transcript.json` — Whisperが出力したタイムスタンプ付き文字起こしデータ

## 品質チェック項目

### 1. 固有名詞の修正
- カーカナで出力されがちな英語固有名詞を正しい表記に修正する
  - 例: 「クロード」→「Claude」（AIの文脈の場合）
  - 例: 「エフエフエユペグ」→「FFmpeg」
  - 例: 「ウィスパー」→「Whisper」（APIの文脈の場合）
  - 例: 「リモーション」→「Remotion」
  - 例: 「ワードプレス」→「WordPress」
- **判断基準**: 前後の文脈から技術用語・サービス名と判断できる場合のみ修正

### 2. 誤認識の修正
- 音が似ている別の言葉に誤変換されているケースを文脈から修正
- 例: 「記者で更新している」→「臫社で更新している」
- 例: 「公式作業」→「更新作業」

### 3. 専門用語の正確な表記
- 技術用語・業界用語が正しい表記になっているか確認
- 半角/全角の統一
- アルファベット表記が適切か

### 4. 句読点・区切りの最適化
- テロップ化を見据えて、15文字以内で自然に区切れるようにセグメントを調整
- 文節・助詞の後での区切りを推奨

### 5. フィラーワードのマーキング
- 「えー」「あの」「まあ」「ま」等のフィラーワードに `filler: true` フラグを付与
- カット処理で使用するため

### 6. 重複ワードのマーキング
- 同じ言葉が連続で出現している箇所に `duplicate: true` フラグを付与
- 例: 「ウェブサイトの、ウェブサイトの」→ 最初の「ウェブサイトの」に duplicate フラグ

## 出力

- 修正済みの `transcript.json` を上書き保存
- `subtitle_check_report.json` — 修正箇所のログ（何をどう直したかの記録）

## 処理フロー

1. `transcript.json` を読み込む
2. 全セグメント・ワードを順番に走査
3. 上記チェック項目に該当する箇所を修正
4. フィラーワード・重複ワードにフラグを付与
5. 修正結果を保存
6. レポートを出力

## 注意事項

- タイムスタンプ（ms単位）は**絶対に変更しない**。テキストのみ修正する
- 判断に迷う場合は元のテキストを維持する（過修正しない）
- このエージェントはメイン処理と並列で動くため、速度を重視する
