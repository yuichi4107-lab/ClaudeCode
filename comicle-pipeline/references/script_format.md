# 台本Markdownフォーマット仕様

## 基本構造

台本はMarkdown形式で記述し、以下の構造に従う。

```markdown
# タイトル

## セクション名（例：第1章 時代背景）

ミユ「セリフ内容」
ヨウイチ「セリフ内容」
pause,,,
```

## 話者

| 話者名 | VoiceID | 役割 |
|--------|---------|------|
| ミユ | Female_3 | 質問役（視聴者目線） |
| ヨウイチ | Male_15 | 解説役（先生・専門家） |

話者名は必ずカタカナで記述する。

## セリフ記法

```
ミユ「セリフ内容」
ヨウイチ「セリフ内容」
```

- 1行1セリフが基本
- セリフ内に句点（。）・感嘆符（！）・疑問符（？）が含まれる場合、convert_to_csv.pyが臫動分割する
- 読点（、）で区切らた文が30字を超える場合も自動分割される

## ポーズ記法

```
pause,,,
```

話者が切り替わる箇所に挿入する。convert_to_csv.pyが自動でポーズ行をCSVに追加する。

## フリガナ記法

台本Markdown段階ではフリガナを付与しない。フリガナはconvert_to_csv.py実行後に、add_furigana.pyで付与する。

## 6段階シナリオ構成

| フェーズ | 内容 | 目安行数 |
|---------|------|---------
| 1. 時代定義 | 時代・人物の基本紹介 | 20〜30行 |
| 2. トリガー | 主人公が直面した課題・葛稗・ | 20〜30行 |
| 3. 権力争い | 対竘・綷争・葛藤 | 30〜40行 |
| 4. 思想彧竭 | 価値裳・信念の窗突 | 20〜30行 |
| 5. 結末 | 歴史的転換点・結果 | 20〜30行 |
| 6. エンディング | 現代への的靘敠・杯侉 | 10〜20行 |

## セリフ長の目安

- **推奨**: 15〜25字（フオトカイマの徕）
- **上限**: 30字（フォース除跁，方、ヽ、だと、じの漢字を許容

## 視聴者層への配慮（60代以上）

- 難しい漢字には必ずフリガナを付与（add_furigana.pyで自動処理）
- 1セリフあたりの情報量を絞り、短文を心がける
- 専閐用語は初出時に必ず説明を加える
