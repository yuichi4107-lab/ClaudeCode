# AIリテラシー講座・コミュニティ 先行案内フォーム仕様書

作成日: 2026-04-23
用途: note記事 Article #5 の CTA からリンクする Googleフォーム

## 設計方針

- **目的**: 講座・コミュニティの先行案内を受け取りたい人のメールアドレスを集める
- **離脱を防ぐ**: 質問数は最小限。必須はメールアドレスのみ
- **セグメント情報を取る**: 「Bタイプ（副業/個人事業主）」「Cタイプ（経営者/マネージャー）」をタスクに合わせた案内に使うため軽く分類
- **安心感を与える**: 登録無料・解除自由・商用転用なし を明示

## フォーム設定

| 項目 | 値 |
|---|---|
| タイトル | AI活用の設計力 講座・コミュニティ 先行案内リスト |
| 説明文 | 下記参照 |
| Google アカウントのログイン必須 | **OFF**（匿名でも送信可） |
| メールアドレスの自動収集 | **OFF**（自分で Q1 に入力してもらう方式の方が離脱率が低い） |
| 1人1回の回答制限 | **OFF** |
| 回答のコピーを回答者に送信 | **任意でON**（任意設定） |
| 進捗バー | OFF（全1〜3ページで短いため） |
| 送信後の確認メッセージ | 下記「送信後メッセージ」参照 |

## 説明文（フォームの先頭に表示）

```
AI活用の「設計力」を学べる講座・コミュニティを準備しています。

note のシリーズ『AIを使いこなす』を読んでくださった方で、今後の先行案内を受け取りたい方は、下記フォームからメールアドレスをご登録ください。

■ 案内が届くタイミング
- 講座の開講日程が決まったとき
- コミュニティの開設準備が整ったとき
- 上記に関する追加情報がまとまったとき

■ このフォームについて
- 登録は無料です
- いつでも解除できます（届くメールの末尾に解除リンクを記載）
- 登録情報は本案内以外の目的では使用しません
```

## 質問項目

### Q1: メールアドレス（必須）

- 質問タイプ: **短文回答**
- 質問文: **メールアドレス**
- 説明: 案内メールをお送りする先のアドレスをご記入ください
- 必須: **ON**
- 回答の検証: **メールアドレス形式のみ**（「回答の検証」→「テキスト」→「メールアドレス」）
- エラーメッセージ: 有効なメールアドレスをご入力ください

### Q2: あなたに近い立場はどちらですか？（任意）

- 質問タイプ: **ラジオボタン**
- 質問文: **あなたに近い立場はどちらですか？**
- 説明: 案内内容を立場に合わせて最適化するための任意項目です
- 必須: **OFF**
- 選択肢:
  - 個人事業主・副業・フリーランス（Bタイプ）
  - 経営者・マネージャー（小規模組織）（Cタイプ）
  - 上記にあてはまらない／まだ決めていない
  - その他（自由記述）

### Q3: 特に興味のあるテーマはどれですか？（任意・複数可）

- 質問タイプ: **チェックボックス**
- 質問文: **特に興味のあるテーマはどれですか？（複数選択可）**
- 説明: 今後の講座・コミュニティの設計に反映させていただきます
- 必須: **OFF**
- 選択肢:
  - タスク設計の3問フレーム
  - 境界線設計（AIに任せる／自分が握るの切り分け）
  - AI部署の組織設計
  - 品質評価の基準づくり
  - 具体的な事例・ケーススタディ
  - 参加者同士の交流・相談

### Q4: ご自由にお書きいただけること（任意）

- 質問タイプ: **段落**
- 質問文: **ご質問・ご要望など（任意）**
- 説明: 現時点でのAI活用に関するお悩みや、講座・コミュニティに期待することがあればお書きください。すべて拝読します。
- 必須: **OFF**

## 作成手順（3ステップ）

### ① Googleフォームを開く

1. https://forms.google.com にアクセス
2. 「空白のフォーム」をクリック

### ② タイトル・説明文・質問を入力

- タイトル欄に: `AI活用の設計力 講座・コミュニティ 先行案内リスト`
- 説明欄に: 上記「説明文」セクションをコピペ
- 質問 Q1〜Q4 を順に追加（上記仕様のとおり）

### ③ 設定調整・URL取得

1. 右上の「設定」タブ
   - 「全般」→「メールアドレスを収集する」を**OFF**（Q1 で手動収集する方式）
   - 「回答者がアクセスする」→ ログイン要求をOFF
   - 「プレゼンテーション」→「確認メッセージ」を上記「送信後メッセージ」に差し替え
2. 右上の「送信」ボタン
3. URLアイコン（🔗）を選択 → 「URLを短縮」をON → URLをコピー
4. そのURLを私に伝えてください → Article #5 の `【先行案内フォームURLをここに挿入】` を差し替えて再コミットします

## 追加推奨設定（任意）

- 回答のスプレッドシート連携: ON推奨（「回答」タブの緑アイコン）→ 新規スプレッドシートを作成
- 回答通知メール: ON推奨（「回答」タブの縦三点→「新しい回答についてメール通知を受け取る」）
