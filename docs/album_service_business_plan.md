# アルバム(日記)作成アシスタント 実用化分析・事業プラン

作成日: 2026-07-17
対象資料: 企画メモ「アルバム(日記) 作成アシスタント」

---

## 1. 企画資料の整理

添付資料から読み取れるサービスコンセプトは以下の通り。

- **コア価値**: 「LINEで写真を送るだけ」でアルバム(日記)が自動的にでき上がる作成アシスタント
- **ターゲット用途**: ① 子供の成長記録 ② 家族の思い出 ③ 恋人との思い出
- **機能**: 日付毎の自動整理 / 日常写真・記念写真・動画のアルバム化 / クラウド保存+バックアップ / 見たい時にいつでも見返せる
- **特典(リアル連携)**:
  - 0〜7歳の子供へ毎年バースデーカード送付
  - お宮参り・七五三などの着物レンタル割引
  - 入園・卒園・入学・卒業(小中)のお祝い
  - 「今年の抱負」記録、成人式で親から子へ渡す(長期タイムカプセル)

**本質**: 単なる写真共有アプリではなく、「LINE完結の手軽さ」×「ライフイベントに寄り添うリアル特典」×「20年スパンの思い出資産化」の3点セット。

**みてねの弱点(口コミ調査より)**:
1. **アプリのインストール・招待が前提** — 祖父母世代には初期設定のハードルが残る(ブラウザ版はあるが補助的)
2. **家族からの干渉疲れ** — コメント返信や投稿催促が「うざい・しんどい」という声
3. **動画アップロードが遅い/失敗する**、PC版UIのわかりにくさ、人物自動振り分けの精度不満
4. **公開範囲の細かい設定は有料**(両家で分けたいニーズ)
5. **子供中心設計** — 恋人・夫婦・ペット用途には設計上も情緒的にも合わない
6. **サービス終了時にデータが消える不安**が口コミで言及される

### 2.3 重要な発見: 「LINE完結」の空白地帯

- LINE公式アカウントには標準のアルバム機能が**存在しない**([LME解説](https://lme.jp/media/line/album-creation/))
- 「LINEで送るだけで整理されたアルバムができる」体験を大手が押さえていない
- みてね・ALBUS・ノハナはすべて**専用アプリのインストールが必須**

→ 「アプリを入れない・使い方を覚えない」層(祖父母、ズボラ層、ITが苦手な親)に対する**チャネル差別化が成立する**。

## 3. 外部サービス依存リスク(「使えなくなるか」の調査)

企画の根幹が外部プラットフォームに依存するため、以下を確認した。

### 3.1 LINE (Messaging API)

- **技術的可否**: ○ 可能。LINE公式アカウント+Messaging APIで、ユーザーが送信した画像・動画をWebhook経由で取得し、自社クラウドへ保存できる
- **注意点**:
  - 受信コンテンツはLINEサーバーに**一定期間しか保持されない**ため、受信後すみやかに自社ストレージへ退避する設計が必須
  - 応答メッセージは無料だが、プッシュ配信(バースデーカード案内等)は**従量課金**(無料枠超過分)。配信コストを価格設計に織り込む
  - 規約変更・アカウント停止リスクはゼロにできない → **メール/Webへのエクスポート経路を常備**し、LINEはあくまで「入口」、データ資産は自社側に持つ構成にする

### 3.2 クラウドストレージ

- AWS S3 / Cloudflare R2 等で問題なし。写真1枚平均3MB、月100枚/人として月0.3GB/人 → ストレージ原価は月数円/人レベル。動画中心になると跳ね上がるため、**動画は長さ・画質制限を無料プランに設ける**(みてねと同じ構造)

### 3.3 印刷・発送(バースデーカード、フォトブック)

- しまうまプリント等の印刷OEM・APIや、ネットプリント業者との提携で内製不要。1通あたり印刷+郵送で150〜300円程度を想定

### 3.4 法規制

| 法令 | 論点 | 対応 |
|---|---|---|
| 個人情報保護法 | 子供の顔写真は個人情報。**未成年者のデータの第三者提供には親権者の同意が原則必要**。クラウド保存は「クラウド例外」の整理とアクセス制御などの安全管理措置が必要 | プライバシーポリシー整備、提携先(着物レンタル等)へ個人データを渡す場合は明示同意を取得。顔検出等のAI処理も利用目的に明記 |
| 景品表示法 | バースデーカード・割引などの特典は、設計次第で「総付景品」規制(取引価額の20%上限等)の対象になり得る | 「会員サービスの一部(アフターサービス)」または「値引き」として設計すれば原則規制外。無料会員への高額特典は要注意。実施前に消費者庁ガイドライン確認を推奨 |
| 特定商取引法 | 物販・サブスク課金を行うため通信販売の表示義務、サブスクの解約導線明示 | LP・アプリ内に法定表記 |
| 資金決済法 | 独自ポイント・前払いチャージを導入する場合のみ前払式支払手段の届出が必要 | 初期はポイント制を避ければ不要 |

出典: [個人情報保護委員会 3年ごと見直し資料(未成年データ)](https://www.ppc.go.jp/files/pdf/240410_shiryou-1.pdf) / [クラウド例外の解説(BUSINESS LAWYERS)](https://www.businesslawyers.jp/articles/1399) / [NTTデータ クラウドと個情法](https://www.nttdata.com/jp/ja/trends/data-insight/2024/1106/)

**結論**: 「使えなくなる」致命的な外部依存はない。ただし①LINE規約変更に備えたデータ主権の確保、②子供の個人情報の扱い、③特典の景表法設計、の3点は初期から織り込むこと。

## 4. 事業プラン(3パターン+補足1)

### プランA: LINE完結ライトアルバム「送るだけアルバム」(推奨・最速)

- **概要**: LINE公式アカウントに写真を送るだけ。日付毎に自動整理され、月次のWebアルバムページ(閲覧はブラウザ、アプリ不要)が家族に共有される
- **ターゲット**: みてねの初期設定・招待が面倒な層、祖父母、恋人・夫婦
- **収益**: フリーミアム。無料=月30枚+閲覧90日 / 有料 月480円=無制限保存・動画対応・一括ダウンロード(**みてねプレミアム590円より安く**設定)
- **強み**: 開発が軽い(2〜3ヶ月でMVP)、CAC が低い(LINE友だち追加のみ)、みてねと正面衝突しない
- **リスク**: LINE依存、単価が低い

### プランB: ライフイベント特典型「成長おいわいクラブ」(資料の特典構想を主役に)

- **概要**: プランAを基盤に、0〜7歳バースデーカード送付、お宮参り・七五三の着物レンタル割引、入園卒園・入学卒業祝いを年齢連動で自動お届けする**子育てCRM/O2Oサービス**
- **ターゲット**: 0〜7歳の子を持つ家庭(七五三・入学等の記念需要が集中する層)
- **収益**: 月額800〜980円のサブスク+提携送客手数料(写真館・呉服店・スタジオから10〜20%)。スタジオアリスの七五三出張撮影が3.8万円規模である通り、記念撮影は単価が高く送客手数料が成立する([スタジオアリス](https://www.studio-alice.co.jp/753/rental.html))
- **強み**: みてねが「みてねファミリーパートナー」で同方向に動き始めたばかり(2026年7月に1社先行実施)で、**ローカル提携網の構築はまだ空白**。地域の写真館・呉服店・こども園と直接組めば模倣されにくい
- **リスク**: 提携営業の工数、景表法設計、地域限定スタートになる

### プランC: 恋人・夫婦向け「ふたりアルバム」(みてねの空白セグメント)

- **概要**: 同じ基盤で、カップル・夫婦2人用の思い出日記。記念日リマインド、付き合った日からの経過日数、年1冊の自動フォトブック、プロポーズ・結婚式への導線
- **ターゲット**: 20〜30代カップル。みてねは子供中心設計でこの層を取れていない
- **収益**: 月300〜480円の低単価サブスク+記念日ギフト・フォトブック販売
- **強み**: 競合が手薄。子供が生まれたらそのままプランA/Bへ移行してもらえる**顧客生涯導線**になる
- **リスク**: 別れによる解約、市場規模は子育て層より小さい

### 補足プランD: B2B2C(写真館・こども園向けOEM)

自社集客をせず、写真館・こども園・産院に「LINEアルバム機能」を月額で提供する。営業先が明確でキャッシュが早いが、スケールは限定的。プランBの提携網構築と並走させると相乗効果が高い。

## 5. 対「みてね」勝ち筋戦略

みてねと**同じ土俵(家族共有アプリ)で戦えば確実に負ける**(無料で容量無制限、国内浸透率65%、資本力)。勝ち筋は以下の5点。

1. **土俵をずらす: 「アプリ」ではなく「LINE」**
   みてねの体験は「アプリを入れて・招待して・アップロードする」。本企画は「いつものLINEに送るだけ」。導入障壁ゼロが最大の武器であり、みてねがこの体験に寄せるには自社アプリ経済圏を壊す必要があるため追随しにくい。

2. **みてねの「干渉疲れ」の逆を張る**
   口コミで明確な不満である家族コメント疲れに対し、「共有は月1回のまとめアルバムだけ」「コメント不可・見るだけモード」など、**静かな共有**を初期設定にする。

3. **リアル特典×地域提携の先行(プランB)**
   みてねのファミリーパートナーは大手ブランド広告型。こちらは**地域の写真館・呉服店との送客提携**という別レイヤーを先に押さえる。七五三・お宮参りは必ず「地元」で発生する行事であり、ローカル網は大手が最も取りにくい資産。

4. **「20年タイムカプセル」の情緒的ロックイン**
   資料にある「今年の抱負」「成人式で親から子へ」は、みてねに無い独自概念。毎年1通の抱負+写真を封印し、成人式に一括開封して渡す「未来への手紙」商品は、**解約＝20年分の手紙を失う**という強力な継続動機になる。

5. **データ主権の透明性で信頼を取る**
   「サービスが終わったらデータが消えるのでは」というみてねへの不安に対し、**いつでも全量エクスポート可能・終了時は6ヶ月前告知+全データ返却保証**を明文化して掲げる。

## 6. 実装ロードマップ(難易度別フェーズ分け)

「簡単な操作はすぐ動くもの(ライブ)として先行リリースし、難しい分析・自動化はフェーズを分けて実装」する前提で3段階に分割。

### Phase 1: MVP — すぐ作れる範囲(開発2〜3ヶ月)
- LINE公式アカウント+Messaging API Bot(画像・動画の受信→S3保存)
- 日付毎の自動整理(EXIF/受信日時ベース)、月別Webアルバム閲覧ページ(閲覧リンクを家族に共有、アプリ不要)
- Stripe等でのサブスク課金、法定表記・プライバシーポリシー
- **検証指標**: 友だち追加→初回送信率、週1回以上の送信継続率、無料→有料転換率

### Phase 2: 差別化機能+特典(Phase 1検証後、+3〜4ヶ月)
- アルバム自動生成(顔検出でベストショット選定、ブレ・重複除去)
- 印刷OEM連携: 年1冊自動フォトブック、バースデーカード印刷・発送
- 提携特典: 地域写真館・着物レンタルのクーポン配信(まず1エリアで実証)
- 静かな共有モード、両家別々の公開範囲設定(みてね不満点の解消)

### Phase 3: 高度な分析・長期商品(+6ヶ月〜)
- AI成長記録(身長・イベントの自動タグ付け、1秒動画的なダイジェスト動画生成)
- 「今年の抱負」音声・動画レター、成人式タイムカプセル商品(20年保存の信託的設計)
- 恋人向け(プランC)展開、B2B2C(プランD)展開

## 7. 推奨アクション

1. **プランA(LINE完結MVP)を最小構成で先行リリース**し、「送るだけ」体験の継続率を実測する
2. 並行して**地元1エリアで写真館・呉服店2〜3店と提携交渉**(プランBの実証)。ここが最も模倣されにくい資産になる
3. 特典設計の前に**景表法の整理(値引き/アフターサービス扱いにする設計)と、子供の個人情報の同意取得フロー**を固める
4. みてねの動向(ファミリーパートナー拡大)を四半期ごとにウォッチし、ローカル提携のスピードで先行する
