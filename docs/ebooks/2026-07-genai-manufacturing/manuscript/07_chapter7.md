# 第7章 コピペで使えるプロンプトテンプレート集

この章は「実用の道具箱」です。本文で紹介したものを含め、中小製造業の日常業務でそのまま使えるプロンプトを15本収録しました。[ ]の部分を自社の内容に差し替えて使ってください。

使い方の原則を3つだけ。

1. **[ ]は具体的に埋める**。具体性が出力の質を決める(第1章)
2. **機密情報は伏せ字にする**。固有名詞・数値を一般化すれば大半の相談は可能(第2章)
3. **出力は下書き**。事実確認と最終判断は人間が行う

---

## 事務・総務編

### テンプレート1: ビジネスメール全般

```
以下の条件でビジネスメールを書いてください。
・宛先: [相手の立場。例: 長年の取引先の購買担当]
・用件: [伝えること]
・背景: [相手との関係、これまでの経緯]
・トーン: [丁寧/簡潔/お詫び基調 など]
文面は短めにし、件名の案も3つ付けてください。
```

### テンプレート2: 言いにくいことを伝えるメール

```
[値上げのお願い/納期遅延のお詫び/依頼のお断り]のメールを書いてください。
・相手: [立場と関係性]
・事情: [正直な背景事情]
・守りたいこと: 相手との関係を損なわない/曖昧にせず結論は明確に伝える
・代替案として提示できること: [あれば]
```

### テンプレート3: 議事録の整形

```
以下の打ち合わせの文字起こしを議事録にしてください。
構成: 日時・出席者/決定事項/宿題(誰が・何を・いつまでに)/次回予定
言い間違いは文脈から補正し、判断がつかない箇所は【要確認】と印を
付けてください。
[文字起こし]
```

### テンプレート4: 社内文書のたたき台

```
[業種・従業員数]の会社の「[文書名。例: 慶弔見舞金規程]」のたたき台を
作ってください。一般的な中小企業の相場感で作り、会社として判断が必要な
箇所には【要確認】と印を付けてください。
```

### テンプレート5: Excelの家庭教師

```
Excelで[やりたいこと]を実現する方法を教えてください。
・データの構成: [A列に〇〇、B列に〇〇…]
・私のレベル: [関数は SUM 程度なら使える 等]
手順を追って、初心者向けに説明してください。
```

## 現場編

### テンプレート6: 口頭説明から作業手順書

```
以下は作業者が口頭で説明した「[作業名]」の文字起こしです。
新人が読めば作業できる手順書に整形してください。
・構成: 準備するもの/手順(番号付き・1手順1動作)/注意点/よくある失敗
・曖昧な箇所・説明が飛んでいる箇所は末尾に【確認事項】として列挙
[文字起こし]
```

### テンプレート7: KYT(危険予知)シナリオ

```
[業種・工程]の工場で使うKYTシナリオを3つ作ってください。
・場面: [例: 金型交換、フォークリフト搬入、単独残業]
・各シナリオに「潜んでいる危険は?」の問いと、進行役用の解答例を付ける
```

### テンプレート8: ベテランへのインタビュー設計

```
[職種・勤続年数]のベテランの判断ノウハウを聞き出すための
インタビュー質問を20個作ってください。
・本人が無意識にやっている判断(異常への気づき、段取りの決め方など)を
　引き出す質問にする
・具体的な場面を想定した、答えやすい聞き方にする
```

### テンプレート9: 不具合報告書の整形

```
以下のメモを客先提出用の不具合報告書に整えてください。
・構成: 事象/原因/応急処置/恒久対策/再発防止
・事実と推定を区別する(推定には「〜と推定される」と明記)
[現場メモ]
```

### テンプレート10: 改善の壁打ち

```
[工程・作業]を改善したいです。
現状: [数値や事実を箇条書きで]
[SMED/5S/動線分析 など使いたい枠組みがあれば]の考え方に沿って、
改善の着眼点を「すぐできること」「投資が必要なこと」に分けて
10個挙げてください。
```

## 技術・品質編

### テンプレート11: 技術調査の地図づくり

```
[検討していること。例: 新しい表面処理への変更]を検討しています。
[自社の業種]の技術者として、検討・確認すべき観点を網羅的に
挙げてください。品質・コスト・納期・安全・法規制の面から。
最後に「特に見落としやすい点」を3つ選んでください。
```

### テンプレート12: 不良解析の要因出し

```
[不良の内容と傾向。例: 内径寸法がロット内で徐々に拡大]という不良が
出ています。特性要因図(4M: 人・機械・材料・方法)の枠組みで、
考えられる要因を網羅的に挙げてください。定番の要因と、
見落としやすい要因の両方を含めてください。
```

### テンプレート13: VBA/自動化ツールの作成

```
Excel VBAのコードを書いてください。
・やりたいこと: [処理内容を箇条書きで]
・シートとデータの構成: [シート名、列の内容]
・私はVBA未経験です。コードの貼り付け方と実行方法も説明してください。
エラーが出たら、メッセージを貼るので一緒に直してください。
```

## 営業編

### テンプレート14: 自社の強みの言語化

```
当社の強みを整理する壁打ち相手になってください。
当社: [業種、従業員数、創業年数]
事実: [リピート率、対応力、実績などを箇条書きで]
発注側(調達担当者)に刺さる強みの表現を5案作り、それぞれ
「どんな課題を持つ客に刺さるか」を添えてください。
不足している情報があれば私に質問してください。
```

### テンプレート15: 商談ロールプレイ

```
[商談の内容。例: 8%の価格改定のお願い]の商談を控えています。
あなたは[相手の立場。例: 厳しい調達担当者]役になってください。
私の説明に対して想定される反論を一往復ずつぶつけ、
最後に私の説明の改善点を指摘してください。では始めます。
私の説明: [説明内容]
```

---

## テンプレートを「自社の型」に育てる

このテンプレート集は出発点にすぎません。使ってみて良い出力が得られたら、そのプロンプトを社内の共有フォルダに「勝ちパターン集」として貯めてください。「うちの会社の言い回し」「うちの客先の特性」を書き足したプロンプトは、汎用のテンプレートよりずっと強力です。第2章で決めたAI係が月に一度集めて回覧する——それだけで、会社としてのAI活用力は複利で伸びていきます。
