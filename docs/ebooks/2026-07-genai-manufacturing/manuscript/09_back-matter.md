# おわりに

最後まで読んでいただき、ありがとうございました。

本書を貫くメッセージは、突き詰めればひとつです。

**生成AIは、中小製造業の「言葉の仕事」を肩代わりする道具である。そして中小製造業には、言葉の仕事が想像以上に多い。**

メールを書く。手順書を作る。議事録をまとめる。強みを説明する。ベテランの技を言葉にする——。これらはどれも、モノづくりの本業を支える大切な仕事でありながら、常に後回しにされ、少数の人の残業で支えられてきました。生成AIは、この構造を変えられる初めての道具です。

しかも、必要な投資は月額数千円と、始める勇気だけ。設備投資に何千万円もかかる製造業の世界で、これほど投資対効果の高い道具はめったにありません。

一方で、本書では「してはいけないこと」も繰り返し書きました。機密情報を無防備に入力しない。数値・規格・法令をAIの回答だけで確定させない。出力はあくまで下書きで、責任は人間が持つ。道具の限界を知って使うことは、道具を怖がることとは違います。旋盤で安全カバーを付けるのと同じ、プロの作法です。

90日後、あなたの会社の誰かが「これ、AIに下書きさせたら早いですよ」と自然に口にしていたら、本書の役割は果たされています。

あなたの会社のモノづくりが、言葉の仕事から解放されて、いっそう輝くことを願って。
