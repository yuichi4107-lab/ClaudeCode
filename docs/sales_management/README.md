# 販売管理システム ドキュメント

社内の受注〜発注〜納品〜請求業務を管理する販売管理システムの要件定義・設計ドキュメント群。
現在 Excel で運用しているイメージ(受注/発注カード、明細一覧、納品書・請求書発行)をもとに作成している。

## ドキュメント構成

| # | ファイル | 内容 |
|---|---------|------|
| 1 | [01_要件定義書.md](01_要件定義書.md) | 背景・目的、業務フロー、機能要件、非機能要件、実装形態の比較と推奨、スコープ外 |
| 2 | [02_画面設計書.md](02_画面設計書.md) | 画面一覧、画面遷移、各画面のレイアウトと項目定義 |
| 3 | [03_データベース設計書.md](03_データベース設計書.md) | ER図、テーブル定義、採番・金額計算ルール |
| 4 | [04_帳票設計書.md](04_帳票設計書.md) | 納品書・請求書のPDFレイアウト(適格請求書対応) |

## 想定読者

- 発注者(業務担当者): 01 を中心に、業務の流れ・機能が合っているかを確認する
- 開発者: 01〜04 すべてを実装のインプットとする
