# 販売管理システム 帳票設計書

- 版数: 1.1
- 対象帳票: 納品書、請求書(いずれも A4縦・**ブラウザからの印刷が基本**)
- 生成方式(推奨案): 印刷用CSS(`@media print`)を当てたHTMLプレビュー画面を表示し、画面の**印刷ボタン**(`window.print()`)からA4で印刷する。PDF生成ライブラリ(WeasyPrint 等)によるPDFダウンロードは**オプション機能**(必要になった場合のみ追加)

## 1. 共通仕様

| 項目 | 仕様 |
|------|------|
| 出力方法 | プレビュー画面の**印刷ボタン** → ブラウザの印刷ダイアログ → A4縦で印刷。印刷時は帳票部分のみ出力され、画面のボタン・メニューは印刷されない |
| 用紙 | A4 縦、余白 上下20mm・左右15mm(`@page` で指定し、どのPC・プリンタでも同じレイアウトになるようにする) |
| フォント | 日本語ゴシック体。本文10.5pt、表題18pt |
| 金額表示 | カンマ区切り(例: 20,000)。通貨記号は「¥」を合計欄のみに付す |
| 日付表示 | `2026年7月10日` 形式 |
| 発行者情報 | company_settings(社名・住所・電話・登録番号)から印字 |
| 再印刷 | 同一内容で何度でも印刷可。請求書の再印刷は確定時の保存値から生成する |
| PDF化(オプション) | ブラウザの印刷ダイアログで「PDFとして保存」を選べば追加機能なしでPDFにできる。保存する場合はNAS共有フォルダ `\\NAS\販売管理\帳票\{YYYY-MM}\` に下記の命名規則で手動保存(発行と同時の自動PDF保存は将来のオプション) |

### PDF保存時のファイル命名規則(手動保存時の推奨ルール)

| 帳票 | 命名 | 例 |
|------|------|-----|
| 納品書 | `納品書_{管理No}_{客先名}_{納品日YYYYMMDD}.pdf` | `納品書_10100_ダイゴテック_20260729.pdf` |
| 請求書 | `請求書_{請求No}_{客先名}.pdf` | `請求書_INV-202607-001_ダイゴテック.pdf` |

### 2.2 印字項目

| 項目 | データソース |
|------|-------------|
| 宛名 | customers.name + honorific |
| 納品日 | deliveries.delivery_date |
| 管理No. | sales_orders.order_no |
| 客先管理No. | sales_orders.customer_order_no(未入力なら空欄) |
| 明細行 | 品名・型式図番・数量・単位・単価・金額(=小計) |
| 備考 | sales_orders.note |
| 合計 | 明細金額の合計(税抜)。納品書は税額を記載しない |
| 発行者 | 自社情報(社名・住所・電話) |

- 明細行は初期版では1行(1受注=1品目)だが、レイアウトは複数行対応(最大10行/頁、超過時は改頁)とする

## 3. 請求書(適格請求書)

### 3.1 適格請求書の記載要件との対応

| インボイス制度の必須記載事項 | 本帳票での記載 |
|------------------------------|----------------|
| ① 発行事業者の氏名(名称)と登録番号 | 自社名 + 登録番号 T+13桁 |
| ② 取引年月日 | 明細行の納品日 |
| ③ 取引内容 | 明細行の品名・型式図番 |
| ④ 税率ごとに区分した対価の合計額と適用税率 | 「10%対象 20,000円」表記(本システムは10%のみ) |
| ⑤ 税率ごとに区分した消費税額 | 「消費税(10%) 2,000円」 |
| ⑥ 交付を受ける事業者の氏名(名称) | 宛名(客先名) |

- 明細列は Excel イメージの明細一覧(注文管理No.・受注日・納品日・品名・型式・図番・数量・単位・単価・小計・備考)を踏襲する。備考は紙幅の都合で明細行下段に小さく印字する
- 合計欄は Excel イメージ同様「消費税(10%)」「ご請求額」の並びとする

### 3.3 印字項目

| 項目 | データソース |
|------|-------------|
| 宛名 | customers.name + honorific |
| 請求日 / 請求No. / 請求期間 | invoices.issue_date / invoice_no / period_start〜period_end(客先の締め日から算出された期間の確定値) |
| 明細行 | invoice_lines → sales_orders(管理No.・受注日・品名・型式図番・数量・単位・単価)+ deliveries.delivery_date |
| 税抜合計 / 消費税 / ご請求額 | invoices.subtotal / tax / total(確定時保存値) |
| 登録番号・振込先 | company_settings.invoice_reg_no / bank_info |
| お支払期限 | 締め日(請求期間終了日)の翌月末(初期版は固定ルール。客先ごとの支払サイト設定は将来対応) |

- 明細は最大15行/頁。超過時は改頁し、合計欄は最終頁のみに印字する
