# note×AI 収益化プラン（第2版）

作成日: 2026-08-04
**第1版（競馬AI・日本史コンテンツを主軸とした版）は、本人の「既存テーマにこだわらず、世の中で収益実績の上がっている型を参考にしたい」という要望により全面的に差し替えた。**

前提: 本業のある個人が **週5〜7時間** の稼働で取り組む想定（稼働時間・初期資金は未確認のため仮置き。実態が異なる場合はロードマップ期間を比例調整する）。

数値の出典は4段階で区別する：**公式発表 / 第三者メディア / ★自己申告 / 未確認**。★自己申告と未確認の数値は参考情報にとどめ、**本プランの意思決定の根拠には公式・第三者検証可能なデータのみを用いる。**

## 1. 結論（30秒で読める）

**賭ける型：「型7＝Claude Code等の開発ワークフロー教材化」を主軸に、「型3＝技術教材の併売（note＋Zenn）」で商品棚を作り、90日以降に「型4＝小規模なAI導入支援（受託）」への出口を開く多層構造。note は収益の本体ではなく入口である。**

理由は3点。

1. **需要の裏付けが公式・第三者データで取れている唯一の空白地帯だから。** Amazon生成AI書籍ランキング上位5冊中3冊がClaude/Claude Code関連（2026年8月、価格帯2,000〜3,300円）。一方、個人が「Claude Code教材で○万円売れた」という検証可能な成功事例は今回の調査で確認できなかった。**需要は実証済み・個人の供給は未成立**という組み合わせは7類型の中でここだけ。
2. **本人の能力と最も重なるから。** Claude Code のスキル（SKILL.md）を自作し、多段パイプラインを実務で運用している個人は現時点で希少。スクレイピング→DB→ML→CLI→運用まで一人で作り切った経験は「動くものを前提にした教材」の一次情報になる。
3. **単発コンテンツ販売だけでは生活に届かないことがデータで明白だから**（urajo：1年で8,500円／Zenn Git本：9ヶ月で4,170円）。だから note 単体で完結させず、教材→信頼→相談・受託という導線を最初から設計する。

**90日の到達目標（測定可能）**：有料商品3本＋無料記事12本以上を公開し、購入・読了・流入の実測データが取れている状態。金額目標は標準シナリオで**手取り累計 約3〜5万円**（保守シナリオは1万円未満、下記§7）。90日は「稼ぐ期間」ではなく「何が売れるかを実測する期間」と位置づける。

## 3. 先に直視する：市場の残酷な現実

戦略の前に、noteという市場の実力分布を確認する。

- 有料記事投稿者 約17万人のうち、**累計売上10万円超は約2,800人（1.6%）、100万円超は約370人（0.2%）**（※個人ブログ集計・未確認データ。ただしオーダー感として他データと矛盾しない）。
- 単体記事の**中央値は399円**・最頻値300円（有料記事200本の個人調査）。価格分布と個別事例からの推定では、**大半の有料noteの実売は一桁〜数十部。100部超で相当な成功、1,000部超は稀**（推定・未確認扱い）。
- note公式発表「累計20万人が収益化・年間販売総額170億円超」は、**1人あたりに均すと年8.5万円規模**。プラットフォーム全体が「平均的参加者には月7,000円程度」の市場である。
- 会員1,000人超の規模（後藤達也3万人、近代麻雀 約1,500人・年商約4,000万円）は、**例外なくサブスク型（メンバーシップ／定期購読マガジン）でのみ**確認された。単発記事で1万部級の第三者検証可能な事例は発見できなかった。
- 直近の失敗実例：「Claude Cowork×noteで毎日投稿を半自動化」500円が**公開24時間で売上0件**。urajoは2本の記事で**約1年かけて累計8,500円**。

**では何が違いを生むのか。** 上記の分布とジャンルデータから、差が付く変数は次の4つに絞れる。

1. **ジャンル選定**：テクノロジー・AI活用が前年比+268.6%で伸び率1位（note公式）。実用ノウハウ系の平均単価1,842円は読み物系983円の約1.9倍。伸びるジャンル×実用系に置くだけで期待値が変わる。
2. **一次情報の希少性**：「実績・専門性のない一般人の日記」は買われない、が複数の実践者報告で一致。逆に高額が成立する条件は「他では手に入らない再現性の高い実践データ・テンプレート」。本人は実運用中のコード・開発記録・スキル定義という一次情報を持つ。
3. **外部流入**：noteのアルゴリズムは外部流入のある記事を優遇（観測ベース）。note内だけで戦わない。
4. **サブスク or 出口**：単発販売の天井は低い。規模はサブスクで、単価は外部（受託）で取る。90日間はその前段の信頼構築と割り切る。

「1.6%に入る」ことを願うのではなく、**1〜4を全て意図的に満たす設計にする**のが本プランである。

## 4. 戦略の中核

### 4-1. 需要と空白の接続

- **需要側**：日本企業の87%がAI活用・推進段階に入ったのに、「期待を大きく上回る効果」を出せたのは**9%のみ**（PwC、6カ国中最低）。中小企業の最大障壁は「何から始めればいいか分からない」62%・「社内にAI人材がいない」48%（民間調査・信頼度低いが公的調査の「専門人材・ノウハウ不足」とも整合）。個人側では生成AIパスポート累計受験者11.5万人（公式）、書籍売れ筋はClaude/Claude Code実践書へシフト（第三者集計）。
- つまり市場の渇望は「AIの紹介」ではなく「**AIを使って実際に業務が回る状態まで持っていく具体的な手順**」にある。
- **供給側の空白**：Claude Codeの法人研修は事業者が続々参入している（2日で2,066名受講）が、**個人による教材の成功事例は未確認**。かつ既存の書籍（2,000〜3,300円）は汎用入門であり、「実務パイプラインをスキル化して運用し続ける」という運用フェーズの一次情報はほぼ流通していない。

### 4-2. 「この人が書けて他人が書けないもの」

競馬・日本史というドメインを外して能力だけを抽出すると、次の2点が残る。

1. **「一気通貫で作り切った」経験**：スクレイピング（レート制限・キャッシュ・差分更新）→SQLite（WAL）→特徴量設計（リーク防止）→ML（LightGBM・キャリブレーション・時系列CV）→CLI→バックテストまでを一人で設計・実装・運用した実績。書籍執筆者の多くはツール解説者であり、「自分の金と時間で動かし続けているシステム」を持つ書き手は少ない。
2. **Claude Code スキルの自作・運用実績**：SKILL.md を書き、複数ステップのパイプラインをスキル化して日常運用している。書籍が扱うのは「Claude Codeの使い方」まで。**「自分の業務をスキルとして定義し、再実行可能な資産に変える方法」**は運用者にしか書けない。

商品の題材はこの2つの「能力」であり、競馬・日本史は「筆者は実際にこれで動くものを作った」という信頼性の傍証として1〜2箇所で触れるにとどめる。

### 4-3. ガジェットLAB失敗（24時間0件）からの差別化

「AI×note自動化」が売れなかった構造的理由を推測すると：(a) 買い手（note副業勢）は「自動化で楽して稼ぐ」情報を既に大量に無料で浴びており供給過多、(b) 無編集AI量産はnote自身がスパム判定リスクを明言しており買い手も筋の悪さを感じている、(c) 売り手に固有の実績がない。
本プランは**「noteを自動化する」系の切り口を全面的に禁止**し、以下で差別化する：

- **対象読者を変える**：note副業勢ではなく、「Claude Codeを業務で使いたいエンジニア・技術職・データを扱う実務者」。Amazon実務書を3,300円で買う層と同じ。
- **題材を変える**:「コンテンツ量産」ではなく「開発・データ業務のワークフロー構築」。
- **証拠を変える**：プロンプトの羅列ではなく、実運用中のスキル定義・失敗記録・修正履歴という一次情報。

### 4-4. 多層構造（note＝入口、収益の本体は別）

```
[無料] X・Zenn無料記事・note無料記事 …… 発見される場所（外部流入を作る）
   ↓
[低額 500〜1,000円] 入口商品 …… 購入体験を作る・実測データを取る
   ↓
[中核 1,480〜2,480円] 教材＋テンプレ同梱 …… 収益の中心（実用系平均1,842円帯）
   ↓
[91日目以降] スポット相談・小規模受託（型4）/ メンバーシップ …… 収益の本体候補
```

urajo（1年8,500円）と Zenn Git本（9ヶ月4,170円）が示す通り、**上2層だけでは月数千円が現実的な着地**である。設計の主目的は下2層への導線を90日で準備することにある。

## 7. 収益シミュレーション（90日累計・手取りベース）

手取り計算：クレカ決済手数料5% → 残額にプラットフォーム利用料10% → 振込手数料270円/回。

## 11. 数値の扱いについて（本プランの前提）

本プランで引用した数値は以下の4段階で区別している。

1. **公式発表**：note公式統計（ジャンル別成長率・単価分析・還元プログラム実績）、Anthropic公表値、政府統計（総務省白書）、帝国データバンク・中小機構・PwC調査、補助金制度 — **意思決定の根拠として使用**
2. **第三者メディア**：近代麻雀noteの購読者数・売上（livedoor報道）、Amazonランキング（AI Watch集計）、Thomas Frank関連報道 — **意思決定の根拠として使用**
3. **★自己申告**：Sai・ゆとりの販売部数、「数日で45万円」等 — **参考情報。目標設定・シミュレーションには不使用**
4. **未確認**：「17万人中1.6%が10万円超」等の個人集計 — **オーダー感の把握のみに使用し、その旨を本文に明記**

また、収益シミュレーション（§7）の保守シナリオは、確認できた中で最も地味な実例（24時間0件／1年8,500円）を基準点にしており、実際の結果がこれを下回る（0円）可能性も否定していない。本プランは「90日で稼ぐ計画」ではなく、**「公式データが示す需要の空白に、検証可能な最小コストで商品を置き、実測データで次の投資判断を行う計画」**である。
