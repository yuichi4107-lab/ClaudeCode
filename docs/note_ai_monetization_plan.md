作成日: 2026-08-04

**版の変遷**：

## 1. 結論（30秒で読める）

**やること：3層構造。①即金層＝クラウドワークス／ランサーズでAI×エンジニア案件を受注（公式データで生成AI案件単価3.5倍の裏付け）、②資産層＝Claude Code運用教材のnote×Zenn併売（第2版の主軸を継承）、③集客層＝X運用で外部流入を作る。ココナラは「稼ぐ場所」ではなく「実績とレビューを買う場所」と最初から割り切る。**

**狙う金額**：90日で手取り累計 標準シナリオ約10万円（保守：受注ゼロなら1万円未満、0円もあり得る）。加えて固定費削減で月1〜3万円のキャッシュフロー改善（§7）。90日は「稼ぎ切る期間」ではなく「受注実績と実測データを取る期間」。

**なぜそう決めたか**：
1. 第2版の最大の弱点は「教材が売れるまで90日間ほぼ無収入」だったこと。5メソッドのうちメソッド3・5（クラウドソーシング受注／低価格で実績を貯める）を統合すると、この空白を**即金層**で埋められる。クラウドワークス公式発表で生成AI関連案件は前年同月比8.4倍・報酬1.8倍・ITエンジニア職の単価3.5倍と、本人の能力が最も高く売れる場が公式データで特定できている。
2. 教材主軸（第2版）は維持する。Amazon生成AI書籍売れ筋上位5冊中3冊がClaude/Claude Code関連（第三者集計）という需要と、個人の成功事例未確認という供給の空白の組み合わせは変わっていない。
3. 5メソッドの収益目標値（「月30万円」等）はいずれも★自己申告か仮定の逆算であり、目標には使わない。使うのは「工程」だけ（§2）。

### 2-3. 「1日112PVで月100部＝月収30万円」の算術的正体

メソッド1の中核数値を分解する。

```
月収30万円 = 3,000円 × 100部
100部 ÷ CVR（購入率）3% = 3,333PV/月 ≒ 3,300PV
3,300PV ÷ 30日 ≒ 110〜112PV/日
```

つまり「1日112PVで達成可能」は独立した実績データではなく、**「CVR 3%」という仮定を置いた瞬間に自動的に出てくる逆算値**である。検証すべきは112PVではなくCVR 3%と単価3,000円の妥当性だが：

- note有料記事のCVRは**公式非公開**。個人クリエイターの実測報告は概ね数%〜10%と幅が大きいが、報告例は少数で、そもそも報告する人が成功者に偏るサンプリングバイアスがある。
- 単価3,000円は、note単体記事の**中央値399円・平均1,186円・実用ノウハウ系平均でも1,842円**（note公式・30万件分析）の1.6〜7.5倍。
- 月100部は、**大半の有料noteの実売が一桁〜数十部、100部超で相当な成功**（推定）という分布の上位側。月収30万円＝年360万円は、**有料記事投稿者約17万人中、累計（月次ですらない）売上100万円超が約370人（0.2%）**（個人集計・未確認だがオーダー感）という分布のさらに外側。
- 対照実例：urajo氏は有料note2本（500円・100円）で**1年間の累計売上8,500円**。「Claude Cowork×note自動化」500円は**公開24時間で売上0件**。

**結論：CVR 3%・単価3,000円・月100部は「不可能な水準」ではないが、「誰でも再現できる標準値」という裏付けは得られなかった。** 本プランではこの収益モデルを目標値に採用しない。なお「12ステップの黄金テンプレート」「3大欲求（繁殖・承認・金銭）」というフレーズは、書籍本文・KADOKAWA公式・各書評のいずれからも一次情報を確認できなかった（出所不明。動画側の要約または別ソース由来の可能性）。存在が確認できないテンプレートは採否の判定対象にしない。

### 2-6. 書籍の批判的レビューと、本プランの罠回避

書評には次の指摘がある（好意的レビューも含め、同じ手法で実際に稼げたという**第三者の再現報告は発見できなかった**）。

- らっこ本への書評：①「好きなことでジャンルを決めるな」と説きつつ著者自身は得意分野「noteで稼ぐ方法」をジャンルにしている自己矛盾、②「24時間で3,771万円」が本文中少なくとも15回繰り返される反復刷り込み、③「週4時間労働」と複数事業展開の矛盾。別書評は「**数字が強い本ほど『自分にも起きる』と錯覚しやすい**」「**再現できるのは『工程』であり、結果はジャンル・信用・導線・タイミングでぶれる**」と警告。
- あべむつき本への批判ブログ：LINEスタンプ市場の飽和データ、SNSクリエイターの78%は年収235万円程度という市場データ、米国FTCが2023年に根拠なき収益約束で700社へ警告した事例（※この批判ブログ自体は個人運営で、内部の個別主張の一次照合は未了）。
- 荻原本：「タイトル詐欺」との指摘（内容の7割が一般的なAI活用のお金管理術）。

**本プランはこの警告を設計原理として組み込む**：

1. **数字は最小実例から取る**：目標・保守シナリオの基準点は★自己申告の成功譚ではなく、確認できた最も地味な実例（24時間0件／1年8,500円／ココナラ時給58〜78円）に置く（§7）。
2. **採用するのは「工程」だけ**：無料部設計・X集客・受注での実績づくり・切り出し原則は工程として採用し、「結果の数値」は一切引き継がない。結果は自分の90日実測で置き換える（§6）。
3. **ジャンル・信用・導線・タイミングを運任せにしない**：ジャンルは公式データで成長率1位の領域（AI活用+268.6%）、信用は受注実績とレビューで先に作り、導線はX→note/Zenn→受託を設計し、タイミングは補助金最終年度（2027年3月終了予定）のAI導入需要期に合わせる。
4. **撤退基準を先に決める**（§8）。錯覚が起きても損失が有限になる。

## 3. 市場の現実（第2版から継承・要点のみ）

- note有料記事投稿者 約17万人中、**累計売上10万円超は約1.6%（約2,800人）、100万円超は0.2%（約370人）**（個人集計・未確認だがオーダー感）。note公式「累計20万人が収益化・年間販売総額170億円超」は**1人あたり年8.5万円規模**。
- 単体記事の中央値399円・実用ノウハウ系平均1,842円（読み物系983円）。**文字数と売上の相関はほぼゼロ**（note公式30万件分析）。
- **1,000人超の規模は例外なくサブスク型でのみ達成**（後藤達也 有料会員3万人／近代麻雀note 約1,500人・年商約4,000万円＝第三者メディア報道）。

## 4. 戦略の中核：3層構造（＋効率・守り）

第2版の弱点「90日間ほぼ無収入」を、5メソッドから採用した要素で埋める。**収益の3層＋それを支える2機能**で構成する。

```
【即金層】受注（M3・M5統合）          → 30〜90日で最初の現金と実績
   CW/ランサーズ：AI×エンジニア案件（単価3.5倍の公式裏付け）
   ココナラ：実績・レビューを「買う」場（時給58〜78円の実例＝期待値は最初からゼロ近傍に設定）
【資産層】教材（第2版主軸を継承、M1の「工程」を採用）
   note×Zenn併売：Claude Code運用教材（無料部で品質証明→有料部で再現手順）
【集客層】X運用（M1採用）
   noteアルゴリズムの外部流入優遇と接続。受注のポートフォリオ紹介先も兼ねる
────────────────────────────
【効率層】自動化（M4の個人版）
   「自分にしかできないこと以外」を外注ではなくClaude Codeスキル化で切り出す
   （本人は既に実践中。外注は個人規模では固定費・管理コストのリスクが大きい）
   ※この実践プロセス自体が資産層の教材ネタになる＝一石二鳥
【守り】固定費最適化（M3採用）

   ただし1回きりの効果で上限がある。初月に2〜3時間だけ投じて完了させる
```

**3層の相互作用が本体**である：
- 即金層の受注実績・レビュー → 資産層の教材の信頼性（「実案件で使っている手法」）を裏書きする。

- 集客層のX → noteの外部流入優遇を起動し、かつ受託の指名問い合わせ窓口になる。
- 効率層 → 週5〜7時間しかない稼働の実効量を増やし、その過程が教材になる。

**ストアカの手数料発見を組み込む**：ストアカの手数料は自己集客（自分のURL経由）10%／ストアカ送客30%（オンライン）で、リピートは一律10%。noteの実質手数料は約14.5%（決済5%→残額に利用料10%）＋振込270円。つまり**X・noteで自前の集客ができた時点で、講座形式の商品はストアカ自己集客URLで売る方がnoteより手数料が安い**。逆に自前集客がないうちのストアカは送客30%を取られる。したがってストアカ講座は「集客資産ができた後」（Day 61以降〜分岐A）に投入する順序とする。月売上5万円以上でさらにボリューム割（-3%〜）。

## 11. 数値の扱いについて（本プランの前提）

本プランの数値は以下の4段階で区別した。

1. **公式発表**：note公式統計（ジャンル成長率・単価分析）、クラウドワークス公式（生成AI案件8.4倍・報酬1.8倍・単価3.5倍）、各プラットフォームの手数料（note・ココナラ・ストアカ・ランサーズ・CW・BOOTH）、PwC・帝国データバンク・中小機構・総務省白書、補助金制度、KADOKAWA公式リリース（3万部）— **意思決定の根拠として使用**
2. **第三者検証可能**：法人登記（スカイ・ムツキ興業・ラスディ）、YouTube登録者数・受賞・メディア出演、Amazonレビュー統計、Amazonランキング（AI Watch集計）、近代麻雀note報道 — **著者実績の確認と市場把握に使用**
3. **★自己申告**：「24時間で3,771万円」「note累計2億円」「年商40億円」「2年で2億円」「2ヶ月で月30万円」「成約率65%」等 — **参考情報。目標設定・収益試算には一切不使用**
4. **未確認**：「17万人中1.6%が10万円超」（個人集計）、LINEスタンプ「90%売上ゼロ」（独立筋複数だが公式でない）、ココナラ初受注までの期間（体験談のみ）、CVR実測報告（少数・生存バイアスあり）、LINE分配率35%・ココナラ振込期限等の一次未確認事項 — **オーダー感の把握のみに使用し、本文にその旨を明記**

収益シミュレーション（§7）の保守シナリオは、確認できた中で最も地味な実例（24時間0件／1年8,500円／時給58〜78円）を基準点とし、0円で終わる可能性を明記した。本プランは「90日で月30万円を目指す計画」ではなく、**「公式データで裏付けの取れた2つの市場（AI×エンジニア受注＝単価3.5倍、Claude Code教材＝需要実証済み・個人供給の空白）に、検証可能な最小コストで同時に足場を置き、実測データで次の投資判断を行う計画」**である。5メソッドから受け継いだのは結果の数字ではなく工程だけであり、結果は自分の実測で置き換える——これが「数字が強い本ほど自分にも起きると錯覚する」罠に対する、本プランの回答である。
