# 戦国・国盗り 地図差し替え（旧国境界の塗り分け）設計書

- 作成日: 2026-05-31
- 対象: 既存ゲーム `sengoku-game/`（ブラウザ・ビルドレス）
- ステータス: 設計合意済み（実装計画づくりへ）

## 1. 概要とゴール

現在の地図は「地理座標に配置した円ノード（国＝丸）」方式。これを **実際の旧国境界で塗り分ける領地マップ**（信長の野望風）へ差し替える。各国を所有者の色で塗り、征服すると自色が地図上に広がる。

**非商用利用**前提で、CODH（人文学オープンデータ共同利用センター）の権威ある旧国境界データを使用する。

## 2. スコープ

### やること
- 66国それぞれを **実際の旧国境界ポリゴン** として描画し、所有者色で塗る
- クリックで国選択、選択国の枠を強調、国名ラベルを表示
- 所有者変更時に塗り色が変わる（征服で自色が広がる演出）
- 必須の **帰属クレジット表示**（ゲーム内＋README）
- 66国IDすべてにパスが存在することの自動チェック

### やらないこと
- エンジン（経済/合戦/AI/外交/勝敗）・データ（国ステータス）・パネル/ログ/ランキングUI・セーブ/ロードは**変更しない**
- 旧国の史実考証の厳密化（CODHデータの精度をそのまま採用）
- 兵力を地図上の大きさで表す表現（円半径エンコード）は廃止（兵力は情報パネルで確認）
- アニメーション演出（塗り替えのトゥイーン等）

## 3. データ源とライセンス

- **CODH「旧国・旧郡境界データセット」**（GeoJSON/TopoJSON/ベクトルタイル、85旧国＋806旧郡）。出典は「幕末明治地勢地図境界データ」（人間文化研究機構）。戦国〜江戸期の旧国に極めて近い。
  - 入手起点: https://geoshape.ex.nii.ac.jp/kg/ （`/resource/` 一覧・`/vector/` タイル・`/search/`）
- **ライセンス: CC BY-NC（表示・非商用）**。本ゲームは非商用利用に限定する。
- **必須クレジット**（ゲーム内フッターのクレジット欄＋README＋geo.js冒頭コメントに掲示）:
  > 『旧国・旧郡境界データセット』（CODH作成）「幕末明治地勢地図境界データ」（人間文化研究機構作成）を加工 doi:10.20676/00000454

## 4. アーキテクチャ：オフライン前処理＋ビルドレス・ランタイム

ゲーム本体はビルドレスを維持する。地図ジオメトリは **オフライン前処理で静的化** し、ランタイムは静的な `geo.js` を読むだけにする。

### 4.1 オフライン前処理（`C:\dev` ＝ Drive外で実行）
> Driveマウント上は `npm install` が失敗するため、ジオ処理ツール（mapshaper 等）は Drive外の `C:\dev` 配下で実行する。成果物の `geo.js` だけをゲームリポジトリにコピー＆コミットする。前処理スクリプト・原データはコミットしない（使い捨て）。

工程:
1. **取得**: CODHから旧国GeoJSON（＋近江分割用に旧郡GeoJSON）をダウンロード。
2. **ID対応付け（最大の山場）**: CODHの85旧国を現行の66国IDへ写像する `mapping`（旧国名→当方ID）を用意し、以下を処理:
   - **結合（union/dissolve）**: 当方が1国に束ねている地域を統合する。少なくとも次を想定:
     - 北海道11国 → `ezo`
     - 陸奥系（陸奥・陸中・陸前・磐城・岩代）→ `mutsu`
     - 出羽系（羽前・羽後）→ `dewa`
   - **分割**: 当方が分けている `omi_s`（南近江）/`omi_n`（北近江）は、CODHの**旧郡**を用いて近江国を南北に構成する（北＝浅井郡・伊香郡・坂田郡・東浅井等の北部郡、南＝甲賀・蒲生・野洲・栗太・滋賀等の南部郡。郡の南北割当表を mapping に含める）。
   - **対応表の網羅性チェック**: 当方66国すべてに対応ジオメトリが付くこと、CODH側の取りこぼし旧国がないことを前処理で検証。
3. **簡略化・投影・出力**: web向けに頂点を簡略化（mapshaper `-simplify`）し、共通のSVG座標系へ投影（`-proj` で適切な日本用投影、または経緯度を等緯度経度で線形変換）。各国の塗り用 `path d` 文字列と全体 `viewBox` を算出し、**`src/data/geo.js`** を生成:
   ```js
   // 帰属クレジット（CC BY-NC）コメントを冒頭に記載
   export const MAP_VIEWBOX = '0 0 1000 1200';
   export const GEO = {
     owari: 'M…Z',     // 国ID → 塗り用SVGパス
     mikawa: 'M…Z',
     // …66国すべて
   };
   ```
4. **重心算出**: ラベル配置用に各国の代表点（重心 or 代表点）も出力（`GEO_LABEL[id] = [x,y]`）。geo.js に含める。

### 4.2 ランタイム（ゲーム本体）
- **新規 `src/data/geo.js`**: `MAP_VIEWBOX` / `GEO`（id→path d）/ `GEO_LABEL`（id→[x,y]）。冒頭に帰属クレジットコメント。
- **`src/ui/render.js` の `renderMap` を書換**:
  - `<svg viewBox=MAP_VIEWBOX>` 内に、国ごとに `<path d=GEO[id] fill=所有者色 data-prov=id class="prov-fill">` を描画。
  - 国境は path の `stroke` で表現（隣接線は廃止）。
  - 選択国は強調（明るい/太い stroke、`class` に `selected`）。
  - 国名ラベルを `GEO_LABEL[id]` に小さく配置（`pointer-events:none`）。表示過多なら選択時のみ表示にフォールバック可。
  - 既存の円ノード描画コードは削除。
- **`index.html` / `styles.css`**: `.prov-fill`（stroke・hover・selected）スタイル、地図ラッパの調整、**クレジット欄**（フッター等に常時表示）。
- **`src/ui/input.js`**: 変更なし（クリック委譲は `closest('[data-prov]')` のため、円→pathでもそのまま機能）。
- **`src/data/provinces.js`**: 変更なし（`x,y` は地図描画に使わなくなるが、隣接 `neighbors` は攻略判定で引き続き使用するため削除しない）。
- **`src/main.js`**: 変更なし（`render(state, selected)` のインターフェース不変）。

## 5. データフロー（ランタイム）
`main.js` → `render(state, selected)` → `renderMap` が `GEO`/`GEO_LABEL` と `state.provinces[id].owner` を読み、所有者色で各 path を塗る。所有者が変われば次回 `render` で塗り色が変わる（征服で自色が広がる）。クリック → `input.js` が `data-prov` を拾い `onSelectProvince(id)` → 再描画で選択強調。

## 7. テスト方針
- **データテスト（node:test）**: `tests/geo.test.js` — `GEO` が `provinces.js` の全66 IDを過不足なくカバーし、各値が非空のパス文字列であること、`GEO_LABEL` も全IDを持ち各値が `MAP_VIEWBOX` 範囲内であることを検証。
- **手動ブラウザ検証（Playwright）**: 地図が日本の形になっている／国選択・強調／出陣で塗り替わる／クレジット表示／コンソールエラー0。
- エンジン/データ/セーブの既存テストは不変（地図はそれらに非依存）。

## 8. エラーハンドリング／エッジケース
- `GEO[id]` 欠落時: その国を描画スキップしコンソール警告（テストで事前検出するため本番では起きない想定）。
- 国名ラベルの重なり: 小フォント＋必要なら選択時のみ表示でフォールバック。
- 簡略化の度合い: ファイルサイズと形状認識性のバランス（過度な簡略化で形が崩れない範囲）。

## 9. リスクとフォールバック
- **CODH一括ダウンロード手段**が不明確な場合: `/kg/resource/` の各国GeoJSONを個別取得して結合、もしくはベクトルタイル/別ミラーから取得。
- **近江の郡分割**が綺麗にできない場合: 近江を南北に直線クリップする近似分割にフォールバック（海岸線・他国境界は正確なまま）。
- **投影スケール合わせ**: 既存レイアウトに依存しないよう、`MAP_VIEWBOX` はジオメトリのbboxから決定。
- 上記がいずれも困難な場合の最終フォールバック: 海岸線は正確（政府オープンデータの都道府県輪郭）に保ちつつ国境を近似する縮退案。ただし本設計は CODH 旧国データでの実装を第一とする。
