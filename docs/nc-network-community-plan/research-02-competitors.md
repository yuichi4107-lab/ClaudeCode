# 調査レポート②: 製造業マッチングサービスの競合状況と市場ギャップ

> 調査日: 2026-07-18

## 分類フレーム

町工場・中小加工業者と発注企業を結ぶサービスは、大きく5類型に分類できる。

1. **受発注プラットフォーム型**（見積り自動化・EC型）
2. **マッチング／仲介型**（コーディネーター・営業代行を介する）
3. **検索データベース／リード獲得型**（広告モデル）
4. **商社型**（在庫・製造委託を自社で抱える）
5. **コミュニティ・拠点型**（交流会・見学会・インキュベーション）

CADDiの事業転換が示す通り、「モノを動かす」プラットフォーム型は品質管理・納期・物流という重いオペレーションを抱えるため収益化が難しく、近年は「データ・情報の流通」に軸足を移す動きが目立つ。

## 主要プレイヤー

### CADDi（キャディ）— 受発注型→AIデータプラットフォームへ転換
- 図面から自動見積り→パートナー工場（600社超）へ製造委託、品質保証・納品まで自社で担うモデルでスタート（2017年創業）。収益源は仲介マージン。累計調達約257億円、従業員約700名。
- **2024年7月、主力の調達サービス「CADDi Manufacturing」を終了**し、図面データ活用クラウド「CADDi Drawer」＋AI見積「CADDi Quote」の「製造業AIデータプラットフォーム」へ全面転換。モノを扱う仲介は品質・納期・在庫・物流の負担が重く、スケールの阻害要因になったため。
- 出典: [caddi.com/press/20240716](https://caddi.com/press/20240716/), [日経xTECH](https://xtech.nikkei.com/atcl/nxt/column/18/00001/09546/)

### リンカーズ（Linkers）— コーディネーター仲介型
- 全国の経済団体・支援機関・診断士等を「コーディネーター」として組織化し、大手の技術ニーズと中小の技術シーズを人の目利きでマッチング。収益は大手企業・金融機関からの探索委託料/サブスク。Linkers.netに約28,000アカウント。
- 出典: [corp.linkers.net](https://corp.linkers.net/)

### J-GoodTech（ジェグテック）— 公的機関運営型
- 中小機構運営。登録約35,000〜40,000社（大企業約1,000・中小約28,000・海外約9,000）。年間約12,000件のマッチング成立。企業の利用は原則無料（国費運営）。公的信頼性と専門コーディネーター支援が強み。
- 出典: [jgoodtech.smrj.go.jp](https://jgoodtech.smrj.go.jp/pub/ja/)

### イプロス（Ipros）— リード獲得・広告型
- キーエンス100%子会社。製品・技術情報の掲載→資料請求・問い合わせをリード化する広告モデル。会員約193万人、出展企業約4.7万社。**営業利益率50%超**の高収益。マッチングというより「探される」マーケティングインフラ。
- 出典: [marketing.ipros.jp/aboutus](https://marketing.ipros.jp/aboutus/)

### Mitsuri（ミツリ）— 成功報酬型マーケットプレイス
- 金属加工特化。発注側無料、**受注側が成約時のみ成約金額の10%（上限10万円/件）**を支払う成功報酬型。利用4,500社超・累計取引15,000件超。オウンドメディアでSEO集客。
- 出典: [mitsu-ri.net](https://mitsu-ri.net/), [PR TIMES](https://prtimes.jp/main/html/rd/p/000000026.000037777.html)

### meviy（ミスミ）— 内製EC型
- 3D CADアップロードでAIが自動見積り、最短即日出荷。第三者工場のマッチングではなくミスミ自身の生産体制による**内製EC**。発注企業が代替として選ぶ選択肢であり、自動見積り技術のベンチマーク。
- 出典: [meviy.misumi-ec.com](https://meviy.misumi-ec.com/ja-jp/)

### ファクトリエ / sitateru — 工場直結・共創型（アパレル）
- ファクトリエ: 商社・卸を排し、工場が「希望工場価格」を自ら設定、その約2倍で消費者に直販するD2C。原価率50〜60%と工場側の取り分を厚くする共創モデル。国内600以上の工場と取引。「共感・物語」を軸にした関係構築の成功例。
- sitateru: アパレル企業と縫製工場（1,500社規模）をマッチング。クラウド生産管理（sitateru CLOUD）にも展開。
- 出典: [connect.panasonic.com](https://connect.panasonic.com/jp-ja/gemba/article/00211858), [sitateru.com](https://sitateru.com/)

### 地域金融機関系（信金・信組）— 対面商談会型
- 「ビジネスマッチングwithかながわ8信金」、信金中央金庫「よい仕事おこしフェア」等。与信情報を持つ金融機関の「信頼できる紹介」が強み。直接課金なし（融資・預金関係強化が目的）。デジタル基盤との連携が弱く、母数・スピードで劣る。
- 出典: [kanagawa-matching.8shinkin.jp](https://kanagawa-matching.8shinkin.jp/)

### コミュニティ・拠点型
- **浜野製作所 / Garage Sumida**: 墨田区の金属加工業が運営するスタートアップ支援施設。周辺町工場ネットワークのハブとして最適な製造パートナーを紹介。WHILL、OriHime等の支援実績。「中小企業が中小企業を育成する」モデル。
- **スミファ**: 墨田区の町工場一般公開イベント（2014年〜）。認知向上・ブランディングが主目的。
- **MOBIO（大阪）**: 公的支援拠点。約200ブース常設展示、交流イベント。
- **DMM.make AKIBA**: 会員企業600社・メンバー4,000名まで拡大したが**2024年4月に閉鎖**。物理拠点型コミュニティの収益的自立の難しさを示す代表例。
- 出典: [garage-sumida.jp](http://garage-sumida.jp/), [m-osaka.com](https://www.m-osaka.com/jp/), [akiba.dmm.com/blog/240430close](https://akiba.dmm.com/blog/240430close)

### その他
- カナメタ（直接マッチング）、NANASEデジタルマッチング（伴走型・600社）、zenmono（ものづくり特化CF、規模限定的）、プラっとものづくり（テクノア運営）など。

## コミュニティ要素を持つ事例の共通点

マッチング（取引成立）とコミュニティ（継続的な関係性・信頼醸成）の組み合わせは各所で試みられているが、**民間営利企業がコミュニティ機能単体で持続的に稼げている事例は少ない**。定量的に成果を出せているのは公的機関（J-GoodTech）や金融機関（信金）など非営利／準公的セクターが中心。

## 市場の空白（ギャップ）— 新規参入者がコミュニティ型マッチングを作る場合

1. **継続的関係の可視化・信頼スコア化の欠如**: 単発の見積り・受発注には強いが、複数回の取引実績・品質評価・納期遵守率を蓄積して「信頼スコア」として可視化する仕組みは弱い。
2. **中小企業同士の「横のつながり（共同受注・技術補完）」の欠如**: 既存サービスは発注↔工場の縦関係に特化。町工場同士が技術を補完し合い共同で大型案件を受注する「アライアンス形成」機能は、全国スケールのデジタルプラットフォームとしてほぼ手つかず。
3. **「モノを動かさない」軽量ポジションでの持続的収益モデルの不在**: 受発注仲介（重い）と広告リード型（薄い）の中間、「情報流通・コミュニティ運営に特化しつつ成約時のみ薄く課金する（仲介責任は負わない）」ポジションは、コミュニティ機能と組み合わせた形では手薄。
4. **地方・非首都圏向けデジタル×リアルのハイブリッド不足**: リアルコミュニティは墨田区・大阪など一部地域限定。東大阪・燕三条・諏訪等の町工場密集地を横串でつなぐ全国規模のデジタル×リアル融合は未成熟。
5. **後継者・人材（採用・技術継承）とマッチングの融合領域の空白**: 町工場最大の経営課題である後継者不足・技術継承に対し、「仕事」と「人（後継者・若手技術者・M&A）」のマッチングを一体化したサービスはほぼ存在しない。
