## 第3章　「聞き方」が9割 ― プロンプトの基本

### はじめに ― ChatGPTは「超優秀だけど察しが悪い」新人社員

ChatGPTを使い始めた方の多くが、最初にこうつぶやきます。

「なんか、思ってたのと違う回答が返ってくるんだよなぁ……」

安心してください。それはあなたのせいではありません。ただ、ちょっとした「聞き方のコツ」を知らないだけです。

ChatGPTは、ものすごく優秀ですが、こちらの事情を察してくれることはありません。上司が「あれ、やっといて」と言えば動いてくれるベテラン社員とは違います。イメージとしては、「めちゃくちゃ頭がいいけれど、入社初日で社内事情を何も知らない新人社員」に近い存在です。

この新人に的確に動いてもらうには、どうすればいいでしょうか？　答えはシンプルです。**具体的に、わかりやすく伝える**こと。この章では、その「伝え方」＝プロンプトの基本を、事務職の日常業務に即してていねいに解説していきます。

---

### プロンプトとは何か ― ChatGPTへの「お願いの仕方」

「プロンプト」という言葉を聞くと、なにやらIT用語のように感じるかもしれません。でも、むずかしく考える必要はまったくありません。

**プロンプトとは、ChatGPTに入力する文章のこと**です。つまり、あなたがChatGPTに送る「お願い」そのものです。

たとえば、「来週の会議の議事録のテンプレートを作って」と入力したとします。この文章がプロンプトです。

メールを書くときに、件名や宛名をきちんと書くのと同じように、プロンプトも「書き方」を少し工夫するだけで、返ってくる回答の質がまるで変わります。

ポイントは、**ChatGPTは入力された文章「だけ」を手がかりに回答を作る**ということです。あなたの職場の雰囲気も、上司の性格も、今抱えている仕事の締め切りも、書かなければ伝わりません。だからこそ、「聞き方＝プロンプト」がすべてを左右するのです。

---

### ダメなプロンプトと良いプロンプトの比較例

ここからは、実際にありがちな「ダメなプロンプト」と、少し工夫した「良いプロンプト」を比べてみましょう。同じ目的でも、書き方ひとつでChatGPTの回答がまるで違ってきます。

#### 比較例①　メールの下書き

**ダメなプロンプト：**

```
お礼のメールを書いて
```

**ChatGPTの回答例（ダメなプロンプトの場合）：**

> 件名：お礼
>
> ○○様
>
> いつもお世話になっております。
> 先日はありがとうございました。
> 今後ともよろしくお願いいたします。
>
> ○○より

……これでは、何のお礼なのかさっぱりわかりません。使い物にならないですよね。

**良いプロンプト：**

```
取引先の田中部長に、先日の工場見学のお礼メールを書いてください。
以下の内容を含めてください。
- 見学で特に印象に残った新しい生産ラインについて触れる
- 次回の打ち合わせ（4月15日 14時）の確認
- カジュアルすぎず、堅すぎない丁寧なビジネス文体
```

**ChatGPTの回答例（良いプロンプトの場合）：**

> 件名：先日の工場見学のお礼
>
> 田中部長
>
> いつも大変お世話になっております。株式会社○○の△△でございます。
>
> 先日はお忙しいなか、工場見学の機会をいただき誠にありがとうございました。
> 新しい生産ラインの自動化の仕組みを間近で拝見でき、大変勉強になりました。品質管理への徹底したお取り組みに感銘を受けた次第です。
>
> さて、次回のお打ち合わせは4月15日（火）14時からと伺っております。当日はご提案資料をお持ちいたしますので、ぜひご確認いただければ幸いです。
>
> 引き続きどうぞよろしくお願いいたします。

具体的な情報を渡すだけで、ここまで違います。

#### 比較例②　Excelの使い方を聞く

**ダメなプロンプト：**

```
Excelの関数教えて
```

**良いプロンプト：**

```
Excel初心者です。売上管理表で、B列に商品名、C列に金額が入っています。
商品名が「文房具」のものだけ合計したいです。
使うべき関数と、具体的な数式を教えてください。
データはB2:C100の範囲です。
```

**ChatGPTの回答例（良いプロンプトの場合）：**

> SUMIF関数を使います。以下の数式をお使いください。
>
> `=SUMIF(B2:B100,"文房具",C2:C100)`
>
> **解説：**
> - 第1引数（B2:B100）：条件を調べる範囲（商品名の列）
> - 第2引数（"文房具"）：合計する条件
> - 第3引数（C2:C100）：実際に合計する範囲（金額の列）
>
> この数式を、合計を表示したいセルに入力してください。

自分の状況を具体的に伝えれば、そのまま使える回答が返ってきます。

```
- 出席者：山田部長、佐藤課長、鈴木、高橋、私（田中）
- 欠席者：小林（出張のため）

【話し合った内容】
- 3月の売上は目標比95%で着地見込み
- 新規顧客5件獲得、うち2件は大型案件
- 来月のキャンペーン企画について佐藤課長から提案あり

【決定事項】
- キャンペーンの詳細は佐藤課長が来週金曜までに企画書作成

出力形式は、日時・出席者・議題・内容・決定事項・次回アクションの順でお願いします。
```

### プロンプトの基本テンプレート ― 4つの要素を押さえよう

ここまでの比較例で、「なるほど、具体的に書けばいいんだな」という感覚はつかめたでしょうか。では次に、いつでも使える「プロンプトの型」をご紹介します。

良いプロンプトには、だいたい次の**4つの要素**が含まれています。

| 要素 | 説明 | 例 |
|------|------|-----|
| **①役割** | ChatGPTにどんな立場で答えてほしいか | 「あなたはベテランの総務担当です」 |
| **②背景** | 今の状況や前提条件 | 「来月、社内イベントを企画しています」 |
| **③指示** | 具体的にやってほしいこと | 「企画書のたたき台を作ってください」 |
| **④出力形式** | どんな形で回答がほしいか | 「箇条書きで、A4一枚に収まる量で」 |

この4つを意識するだけで、プロンプトの質は格段に上がります。実際に使ってみましょう。

**テンプレート活用例：社内イベントの企画書**

```
【役割】あなたはベテランの総務担当者です。

【背景】当社（従業員50名の中小企業）では、6月に社内レクリエーションを
企画しています。予算は10万円、会場は社内の会議室を使用します。
昨年はバーベキューでしたが、今年は室内で行いたいと考えています。

【指示】社内レクリエーションの企画書のたたき台を作成してください。
3つのプラン候補を提案し、それぞれの概要・必要な準備物・
タイムスケジュールを含めてください。

【出力形式】各プランを見出し付きで、箇条書きを使って整理してください。
```

この型を覚えておけば、どんな場面でも「何を書けばいいかわからない」ということがなくなります。もちろん、毎回すべての要素を盛り込む必要はありません。簡単な質問なら「指示」だけでも十分です。大事なのは、**回答の精度を上げたいときにこの4つを思い出す**ことです。

もうひとつ、実務で頻繁に使うパターンもご紹介します。

**テンプレート活用例：文章の校正を依頼**

```
【役割】あなたはビジネス文書の校正のプロです。

【背景】以下は、取引先に送る挨拶状の文面です。

【指示】誤字脱字、敬語の間違い、不自然な表現をチェックして、
修正案を出してください。修正した箇所には★マークを付けてください。

【出力形式】原文と修正案を並べて表示してください。

---
（チェックしてほしい文章をここに貼る）
```

このように、テンプレートに当てはめるだけで、驚くほど的確な回答が返ってきます。

### 具体的に伝えるコツ ― 5W1Hを意識する

「具体的に書きましょう」と言われても、何をどこまで書けばいいか迷いますよね。そんなときに便利なのが、おなじみの**5W1H**です。

| 要素 | 意味 | プロンプトでの使い方 |
|------|------|---------------------|
| **Who**（誰が/誰に） | 対象者 | 「新入社員向けに」「上司に提出する」 |
| **What**（何を） | 成果物 | 「報告書を」「メールを」「リストを」 |
| **When**（いつ） | 期限・時期 | 「来週月曜の会議で使う」 |
| **Where**（どこで） | 場所・媒体 | 「社内メールで」「掲示板に貼る」 |
| **Why**（なぜ） | 目的 | 「残業削減のために」「新人教育のために」 |
| **How**（どのように） | 方法・形式 | 「箇条書きで」「表形式で」「300字以内で」 |

すべてを毎回書く必要はありませんが、「なんか思った回答と違うな」と感じたときは、この6つのうちどれかが欠けていないか振り返ってみてください。

**5W1Hを意識したプロンプト例：**

```
来週月曜の朝礼（When）で、部長（Who）に報告するための
先月の残業時間の集計結果の要約（What）を作ってください。
全社で残業時間を削減する取り組みの一環（Why）として使います。
スライド1枚に収まるように（How）、3つのポイントに絞って、
グラフの説明文として使える文体で書いてください。
```

5W1Hを意識して書くと、自然と具体的なプロンプトになります。最初は面倒に感じるかもしれませんが、慣れてくると無意識にできるようになります。そして、具体的なプロンプトで返ってきた正確な回答を見れば、「最初にちゃんと書いたほうがトータルで速い」と実感できるはずです。

### 「もっと○○して」で修正を重ねるテクニック

ここまで読んで、「毎回そんなに長いプロンプトを書くのは大変……」と思った方、ご安心ください。実は、**最初から完璧なプロンプトを書く必要はありません**。

ChatGPTの大きな強みは、**会話の流れを覚えていてくれる**ことです。つまり、最初にざっくり聞いて、その回答を見てから「もうちょっとこうして」と修正を重ねていけばいいのです。

これを「対話的にプロンプトを磨く」と言います。実際の流れを見てみましょう。

**ステップ1：まず、ざっくり聞いてみる**

```
社内研修のアンケートを作ってください。
```

ChatGPTが5問くらいのアンケートを出してきます。でも、少し物足りない。

**ステップ2：方向性を修正する**

```
もっと具体的にしてください。
研修の満足度だけでなく、講師の評価、テキストのわかりやすさ、
今後受けたい研修テーマについても聞きたいです。
設問数は10問くらいでお願いします。
```

回答が改善されますが、まだ調整したいところがある。

**ステップ3：形式を指定する**

```
ありがとうございます。以下の点を修正してください。
- 選択式（5段階評価）と自由記述を混ぜてください
- 回答時間の目安が5分以内に収まるようにしてください
- 最後に「その他ご意見・ご要望」の自由記述欄を追加してください
```

**ステップ4：仕上げ**

```
いい感じです！最後に以下を追加してください。
- 冒頭に「本アンケートは無記名です。率直なご意見をお聞かせください」
  という一文を入れる
- Googleフォームに貼り付けやすいように、設問と選択肢を
  わかりやすく区切ってください
```

このように、**対話を重ねるたびに回答が洗練されていく**のがChatGPTの醍醐味です。

修正を依頼するときに便利なフレーズをまとめておきます。

| やりたいこと | 使えるフレーズ |
|------------|--------------|
| もっと詳しくしたい | 「もっと詳しく説明してください」 |
| 短くしたい | 「300字以内にまとめてください」 |
| やさしい表現にしたい | 「専門用語を使わずに書き直してください」 |
| フォーマルにしたい | 「もっとかしこまった文体にしてください」 |
| 別の案がほしい | 「別のパターンを3つ出してください」 |
| 一部だけ変えたい | 「2番目の項目だけ修正してください」 |
| トーンを変えたい | 「もう少しカジュアルな表現にしてください」 |
| 情報を追加したい | 「ここに○○の情報も入れてください」 |

覚えておいてほしいのは、**「一発で完璧な回答を引き出そう」と気負わなくていい**ということです。会話しながら一緒に作り上げていく感覚で使うのが、ChatGPTとの上手な付き合い方です。

### やりがちな失敗パターンと対処法

ChatGPTを使い始めたばかりの方が陥りやすい失敗パターンを6つご紹介します。心当たりがあっても大丈夫。対処法を知っておけば、すぐに改善できます。

#### 失敗パターン①　丸投げしてしまう

**よくある例：**

```
いい感じの企画書を作って
```

**何が問題か：** 「いい感じ」の基準がChatGPTにはわかりません。人間同士でも「いい感じにして」では困りますよね。

**対処法：** 「誰向けか」「何の企画か」「どんな項目が必要か」を最低限伝えましょう。

---

#### 失敗パターン②　一度にたくさん聞きすぎる

**よくある例：**

```
来月の営業会議の議題案と、今期の売上グラフの作り方と、
新人の歓迎会の会場候補と、出張精算のやり方を教えて
```

**何が問題か：** 話題が4つも混ざっていると、どれも中途半端な回答になりがちです。

**対処法：** **1つのプロンプトには1つのテーマ**を心がけましょう。複数のことを聞きたいときは、ひとつずつ順番に聞くか、「まず1番目から」と指定してください。

---

#### 失敗パターン③　前提を伝えずに専門的な質問をする

**よくある例：**

```
KPIの設定方法を教えて
```

**何が問題か：** 業種も職種も規模もわからないので、一般的すぎる回答しか返ってきません。

**対処法：** 「中小企業の営業部門で」「事務職5人のチームで」など、自分の立場を添えましょう。

---

#### 失敗パターン④　ダメ出しだけして方向性を示さない

**よくある例：**

```
違います。もう一回やり直して。
```

**何が問題か：** 「何が」違うのかがわからないので、ChatGPTも困ってしまいます。

**対処法：** 「○○の部分が違います。△△に変えてください」と、**何をどう変えてほしいか**を具体的に伝えましょう。

---

#### 失敗パターン⑤　ChatGPTの回答をそのまま鵜呑みにする

**よくある例：** ChatGPTが出してきた数字やデータをそのまま報告書に使ってしまう。

**何が問題か：** ChatGPTは「もっともらしい文章を生成する」のが得意ですが、事実の正確性は保証されません。特に数値データや最新情報は間違っていることがあります。

**対処法：** 重要な数字やデータは必ず元の資料で裏取りしましょう。ChatGPTは「たたき台を作ってくれるアシスタント」であって、「データベース」ではありません。

---

#### 失敗パターン⑥　機密情報を入力してしまう

**よくある例：** 顧客の個人情報や社外秘の資料をそのまま貼り付ける。

**何が問題か：** ChatGPTに入力した内容がどのように扱われるかは、利用プランや設定によって異なります。会社のルールで禁止されている場合もあります。

**対処法：** 個人名は「A社のB様」、金額は「約○○円」のようにぼかして入力しましょう。自社のChatGPT利用ポリシーも確認しておくと安心です。

### Before/After ― 曖昧な質問 vs 具体的な質問の結果比較

ここで、同じ「業務日報のテンプレートを作る」という目的で、曖昧な質問と具体的な質問の結果がどれだけ変わるかを見てみましょう。

#### Before（曖昧な質問）

```
業務日報のテンプレートを作って
```

**ChatGPTの回答例：**

> **業務日報**
>
> 日付：
> 氏名：
>
> 【本日の業務内容】
>
> 【明日の予定】
>
> 【所感】

……シンプルすぎて、これだけでは使えません。

#### After（具体的な質問）

```
営業事務チーム（5名）で使う業務日報のテンプレートを作ってください。

【条件】
- 毎日の退勤前に5分で記入できる分量
- 記入項目：日付、氏名、本日の業務内容（箇条書き3〜5項目）、
  対応件数（電話・メール・来客それぞれ）、処理した書類の種類と件数、
  トラブルや相談事項、明日の優先タスク（上位3つ）
- 上司が一目で全員分を確認できるように、コンパクトにまとめる
- Excel（横向きA4）に貼り付けることを想定した表形式
```

**ChatGPTの回答例：**

> | 項目 | 内容 |
> |------|------|
> | **日付** | 2026年3月24日（火） |
> | **氏名** | （記入者名） |
> | **本日の業務内容** | ・受注処理 12件 ・見積書作成 5件 ・請求書発行 8件 ・電話対応 15件 |
> | **対応件数** | 電話：15件 ／ メール：23件 ／ 来客：2件 |
> | **処理書類** | 見積書 5件 ／ 請求書 8件 ／ 納品書 10件 |
> | **トラブル・相談** | A社の納期について確認中（佐藤課長に相談済み） |
> | **明日の優先タスク** | ①月末請求処理 ②B社見積回答 ③棚卸データ入力 |
>
> ※ 記入の目安：5分以内。箇条書きで簡潔に記載してください。

まったく同じ「業務日報を作って」という目的なのに、ここまで結果が変わります。**プロンプトに30秒かけるだけで、使える成果物が一発で手に入る**。このことをぜひ実感してください。

### 「やってみよう」コーナー ― 同じ依頼を3パターンの聞き方で試してみよう

ここまで読んだら、実際に手を動かしてみましょう。以下の課題を、3つのパターンで試してみてください。

**課題：「有給休暇の申請メールを書いてもらう」**

#### パターン1：ざっくり聞く

```
有給休暇の申請メールを書いて
```

まず、これで試してみてください。返ってきた回答を読んで、「もう少しこうだったらいいのに」と感じる点をメモしましょう。

#### パターン2：少し具体的に聞く

```
来週の金曜日に有給休暇を取りたいので、上司（鈴木課長）に
申請メールを書いてください。理由は私用です。
```

パターン1と比べて、どこが変わったでしょうか？

#### パターン3：テンプレートを使って聞く

```
【役割】あなたはビジネスメールの作成アシスタントです。

【背景】私は営業部の一般社員で、来週金曜日（3月27日）に
有給休暇を取得したいと考えています。理由は私用（通院）です。
当日の業務は同僚の高橋さんに引き継ぎ済みです。

【指示】直属の上司である鈴木課長宛に、有給休暇の申請メールを
書いてください。

【出力形式】
- 件名付きのメール形式
- 丁寧だが簡潔に（読むのに30秒以内）
- 引き継ぎ済みであることを明記
```

3つのパターンの回答を見比べてみてください。きっと、パターン3の回答がいちばんそのまま使えるものになっているはずです。

**振り返りのポイント：**

- パターン1→2→3で、回答がどう変わりましたか？
- パターン3で書いた「余計な30秒」は、本当に余計でしたか？
- もしパターン1の回答を手作業で修正するとしたら、何分かかりますか？

最初に具体的に伝えるほうが、結果的に時短になる。この感覚をつかめたら、この章の目標は達成です。

### さらに一歩進むためのヒント

基本テンプレートに慣れてきたら、次のテクニックも試してみてください。

**1. 出力例を先に見せる（Few-shotプロンプト）**

```
以下のような形式で、今月の業績サマリーを作ってください。

【出力例】
■ 売上：前月比 +5%（目標達成率 102%）
■ 新規顧客：3件（うち大型案件1件）
■ 課題：納期遅延が2件発生、原因は在庫管理の不備

では、以下のデータをもとに作成してください。
（データを貼り付け）
```

「こういう形で出してね」と見本を見せると、ChatGPTの出力がぐっと安定します。

**2. ステップバイステップで考えさせる**

```
当社の経費精算ルールを、新入社員向けのマニュアルにまとめたいです。
まず、必要な項目を箇条書きでリストアップしてください。
その後で、各項目の説明文を書いていきましょう。
```

複雑な作業は、一度に全部やらせるより、段階を分けて指示したほうがうまくいきます。

**3. 「やらなくていいこと」も伝える**

```
以下の文章を校正してください。
ただし、文体は変えないでください。
敬語の間違いと誤字脱字のみ指摘してください。
内容に関する提案は不要です。
```

「やってほしくないこと」を明記すると、余計な回答を防げます。

### 章末まとめ

この章では、ChatGPTへの「聞き方」＝プロンプトの基本を学びました。大事なポイントをおさらいしましょう。

**1. プロンプトとは、ChatGPTへの「お願い」の文章のこと**
- 聞き方ひとつで、返ってくる回答の質がまるで変わる

**2. 良いプロンプトの4要素**
- 役割（どんな立場で答えてほしいか）
- 背景（今の状況や前提条件）
- 指示（具体的にやってほしいこと）
- 出力形式（どんな形で回答がほしいか）

**3. 困ったら5W1Hを思い出す**
- Who, What, When, Where, Why, Howのうち、足りない情報を補うだけで回答が改善される

**4. 一発で完璧を目指さなくていい**
- 「もっと○○して」で修正を重ねていけばOK
- 会話しながら一緒に作り上げるのがChatGPTとの正しい付き合い方

**5. やりがちな失敗に気をつける**
- 丸投げ、情報の詰め込みすぎ、機密情報の入力には要注意
- ChatGPTの回答は「たたき台」。最終確認は自分の目で

次の章では、いよいよ具体的な事務業務での活用法に入っていきます。メール作成、議事録、データ整理など、明日からすぐに使えるテクニックを実践していきましょう。
