# 第5章 議事録の要約 ― 会議後の苦行から解放される

## 議事録作成が大変な理由

「会議が終わったあとの議事録作成が憂うつ……」

事務職として働いている方なら、一度はそう感じたことがあるのではないでしょうか。会議中に必死にメモを取り、席に戻ってからパソコンに向かい、あの発言はどういう意味だったか、この話題の結論はなんだったか、頭を悩ませながら文章を整えていく。30分の会議の議事録を作るのに、1時間以上かかってしまうことも珍しくありません。

議事録作成が大変な理由は、大きく3つあります。

**1. 何を残して何を省くかの判断が難しい**

会議ではさまざまな話題が飛び交います。雑談もあれば、本題から脱線する場面もあります。「この発言は議事録に残すべきだろうか？」と迷い始めると、あっという間に時間が過ぎてしまいます。

**2. 話し言葉を書き言葉に変換する手間**

会議中のメモや録音の文字起こしは、話し言葉のままです。「えーっと、あれですよね、やっぱりこっちの案のほうがいいんじゃないかなって思うんですけど」――こうした発言を、読みやすい文章に変換する作業は、地味に時間がかかります。

**3. 決定事項とTODOの整理が必要**

会議の議事録で最も大切なのは、「何が決まったのか」「誰が何をやるのか」です。しかし、会議中は話があちこちに飛ぶため、決定事項やTODOが会話の中に埋もれてしまいがちです。これらを漏れなく拾い上げるのは、なかなかの作業です。

こうした「会議後の苦行」から解放してくれるのが、ChatGPTです。この章では、手書きメモや録音テキストからChatGPTを使って議事録を作成する具体的な方法をお伝えします。

## ChatGPTに議事録要約を頼む基本パターン

ChatGPTに議事録を作ってもらうときの基本的な流れは、とてもシンプルです。

```
ステップ1: 会議メモ（または文字起こしテキスト）を用意する
ステップ2: ChatGPTに「こういう形式で議事録にまとめて」と指示する
ステップ3: 出力された議事録を確認・修正する
```

ポイントは「ステップ2」の指示（プロンプト）の出し方です。ここで具体的にどんな形式でまとめてほしいかを伝えると、ChatGPTは驚くほど的確に議事録を作ってくれます。

まずは、最もシンプルなプロンプトから見てみましょう。

### 基本プロンプト

```
以下の会議メモを議事録にまとめてください。

【会議メモ】
（ここにメモの内容を貼り付ける）
```

これだけでも、ChatGPTはそれなりの議事録を作ってくれます。ただし、この指示だと出力の形式がChatGPT任せになるため、毎回違うフォーマットで出てきてしまうことがあります。

そこで、もう少し具体的に指示を出してみましょう。

### 改良版プロンプト

```
以下の会議メモを議事録にまとめてください。

【出力形式】
- 会議名
- 日時
- 参加者
- 議題ごとの要点（箇条書き）
- 決定事項
- TODOリスト（担当者・期限つき）
- 次回会議の予定

【会議メモ】
（ここにメモの内容を貼り付ける）
```

このように「出力形式」を指定するだけで、ChatGPTの出力は格段に整理されたものになります。これが議事録作成における基本パターンです。

## 手書きメモから議事録を作成する方法

「会議中はパソコンを開かず、手書きでメモを取っている」という方も多いのではないでしょうか。手書きメモからChatGPTで議事録を作る場合、2つの方法があります。

### 方法1: 手書きメモを見ながらテキストに打ち直す

手書きのメモを見ながら、ざっくりとテキストに起こしてChatGPTに渡す方法です。「きれいな文章にしなくては」と思う必要はありません。箇条書きや単語の羅列でも大丈夫です。

たとえば、こんなメモでOKです。

```
・来月のイベントについて
  →4/15に決定、会場は本社3F会議室
  →案内チラシ　田中さん作成　4/5まで
  →受付担当　佐藤さん
・予算
  →飲食費5万円以内
  →備品は総務に確認（鈴木さん）
・次回打ち合わせ　4/1 14:00
```

きれいな文章になっていなくても、ChatGPTは文脈を読み取ってくれます。

### 方法2: 手書きメモの写真を送る

ChatGPTのスマートフォンアプリ（または有料版のPC版）では、画像を送信することができます。手書きメモの写真を撮影して送り、「この手書きメモを議事録にまとめてください」と指示する方法です。

```
この手書きメモの写真を読み取って、議事録にまとめてください。
読み取れない文字がある場合は「（判読不能）」と記載してください。

【出力形式】
- 会議名
- 議題ごとの要点（箇条書き）
- 決定事項
- TODOリスト（担当者・期限つき）
```

手書き文字の認識精度は100%ではありませんので、出力結果は必ず確認してください。特に人名や数字は間違いやすいポイントです。

> **ワンポイント**: 手書きメモの写真を送る場合は、できるだけ明るい場所で、文字がはっきり写るように撮影しましょう。斜めから撮ると認識精度が落ちます。

## 録音テキスト（文字起こし）から議事録を作成する方法

最近は、会議を録音して文字起こしツールでテキスト化する方も増えています。Microsoft Teamsの会議録機能や、無料の文字起こしアプリ（「Notta」「CLOVA Note」など）を使えば、会議の音声をそのままテキストにできます。

ただし、文字起こしテキストには独特の課題があります。

- 「えー」「あの」などのフィラー（つなぎ言葉）が大量に含まれる
- 発言者の区別が曖昧なことがある
- 誤変換が含まれている
- 話し言葉のため、読みにくい

こうしたテキストをそのまま読んで議事録を作るのは大変ですが、ChatGPTに任せれば一瞬です。

### 文字起こしテキスト用プロンプト

```
以下は会議の文字起こしテキストです。
これを読みやすい議事録にまとめてください。

【指示】
- フィラー（えー、あの、など）は除去してください
- 話し言葉を書き言葉に変換してください
- 発言の重複や脱線は省いてください
- 決定事項とTODOは明確に分けてください

【出力形式】
- 会議名
- 議題ごとの要点
- 決定事項
- TODOリスト（担当者・期限つき）
- 次回予定

【文字起こしテキスト】
（ここに文字起こしテキストを貼り付ける）
```

「フィラーを除去」「話し言葉を書き言葉に変換」といった指示を入れることで、文字起こし特有の読みにくさが解消された議事録が出力されます。

## 出力フォーマットの指定

議事録の「見た目」は、職場や用途によってさまざまです。ChatGPTは、指定したフォーマットに合わせて出力してくれます。ここでは、よく使われる3つのフォーマットをご紹介します。

### フォーマット1: 箇条書き形式

最もシンプルで汎用的なスタイルです。Slack（チャットツール）やメールで共有するときに適しています。

**プロンプト例:**

```
以下の会議メモを、箇条書き形式の議事録にまとめてください。
各議題の要点を3〜5個の箇条書きで簡潔にまとめてください。

【会議メモ】
（メモを貼り付ける）
```

**出力イメージ:**

```
■ 議題1: 来月のイベント企画
- 開催日は4月15日（火）に決定
- 会場は本社3階 大会議室を使用
- 案内チラシは田中さんが4月5日までに作成
- 受付担当は佐藤さん

■ 議題2: 予算について
- 飲食費は5万円以内に収める
- 備品の在庫は鈴木さんが総務に確認
- 追加予算が必要な場合は課長承認が必要
```

### フォーマット2: 表形式

決定事項やTODOを一覧で管理したいときに便利です。Excelに貼り付けて管理表にすることもできます。

**プロンプト例:**

```
以下の会議メモから、TODOリストを表形式で作成してください。

【表の列】
| No. | タスク内容 | 担当者 | 期限 | 備考 |

【会議メモ】
（メモを貼り付ける）
```

**出力イメージ:**

```
| No. | タスク内容 | 担当者 | 期限 | 備考 |
|-----|-----------|--------|------|------|
| 1 | 案内チラシの作成 | 田中 | 4/5 | デザインは前回踏襲 |
| 2 | 受付対応の準備 | 佐藤 | 4/14 | 受付名簿を事前作成 |
| 3 | 備品在庫の確認 | 鈴木 | 4/1 | 総務部に問い合わせ |
| 4 | 追加予算の申請 | 山田 | 4/3 | 課長承認が必要 |
```

> **ワンポイント**: ChatGPTが出力した表をExcelに貼り付けるには、表のテキストをコピーして、Excelの「貼り付け」→「テキストファイルウィザード」を使うか、一度Wordに貼り付けてからExcelにコピーすると簡単です。

### フォーマット3: 議事録テンプレート形式

会社で決められた議事録のフォーマットがある場合は、そのテンプレートをChatGPTに伝えて、その形式で出力してもらいましょう。

**プロンプト例:**

```
以下の会議メモを、下記のテンプレートに沿って議事録にまとめてください。

【議事録テンプレート】
━━━━━━━━━━━━━━━━━━━━
議事録
━━━━━━━━━━━━━━━━━━━━
■ 会議名:
■ 日時:
■ 場所:
■ 参加者:
■ 記録者:
━━━━━━━━━━━━━━━━━━━━
【議題1】○○について
　＜概要＞
　＜決定事項＞
　＜TODO＞
━━━━━━━━━━━━━━━━━━━━
【議題2】○○について
　＜概要＞
　＜決定事項＞
　＜TODO＞
━━━━━━━━━━━━━━━━━━━━
■ 次回会議:
■ 備考:
━━━━━━━━━━━━━━━━━━━━

【会議メモ】
（メモを貼り付ける）
```

自社のテンプレートがある場合は、そのフォーマットをそのままプロンプトに貼り付けてください。ChatGPTはテンプレートの構造を理解して、適切に情報を埋めてくれます。

## 決定事項・TODO・次回アクションを抽出するプロンプト

議事録の中でも特に重要なのが、「何が決まったのか（決定事項）」「誰が何をするのか（TODO）」「次に何をするのか（次回アクション）」の3つです。これらだけをピンポイントで抽出するプロンプトを覚えておくと、とても便利です。

### 決定事項・TODO抽出プロンプト

```
以下の会議メモから、次の3つを抽出してください。

1. 決定事項（会議で正式に決まったこと）
2. TODOリスト（担当者・期限を明記）
3. 次回アクション（次回会議までにやるべきこと、次回の議題）

それぞれ箇条書きで、簡潔にまとめてください。
判断が曖昧なもの（「検討する」「考えておく」など）は
「保留事項」として別にまとめてください。

【会議メモ】
（メモを貼り付ける）
```

このプロンプトのポイントは、「保留事項」というカテゴリを追加していることです。会議では、「まだ決まっていないけれど検討中」という話題がよくあります。これを決定事項と混ぜてしまうとトラブルのもとになるため、分けて管理するのがコツです。

**出力イメージ:**

```
【決定事項】
- イベント開催日は4月15日（火）に決定
- 会場は本社3階 大会議室
- 飲食費の上限は5万円

【TODOリスト】
- 田中さん: 案内チラシの作成（期限: 4/5）
- 佐藤さん: 受付名簿の準備（期限: 4/14）
- 鈴木さん: 備品在庫の確認（期限: 4/1）
- 山田さん: 追加予算の申請書作成（期限: 4/3）

【次回アクション】
- 次回打ち合わせ: 4月1日（火）14:00〜
- 議題: チラシのデザイン確認、備品リストの確定

【保留事項】
- 外部講師の招聘については引き続き検討
- 二次会の実施可否は参加人数確定後に判断
```

## 長い会議メモを分割して処理するテクニック

1時間を超えるような長い会議では、文字起こしテキストが数千文字、場合によっては1万文字を超えることがあります。ChatGPTには一度に入力できる文字数に上限がありますので（無料版は約2万文字程度）、長いテキストは分割して処理する必要があります。

### 分割処理の手順

**ステップ1: テキストを議題ごとに区切る**

まず、会議メモをざっくりと議題ごとに区切ります。文字起こしテキストの場合、話題が変わっているポイントを見つけて区切りましょう。

**ステップ2: 議題ごとにChatGPTで要約する**

```
以下は会議の文字起こしテキストのうち、「○○」についての部分です。
この部分を要約して、要点を箇条書きでまとめてください。
決定事項とTODOがあれば、分けて記載してください。

【テキスト】
（議題1の部分を貼り付ける）
```

これを議題ごとに繰り返します。

**ステップ3: 要約をまとめて議事録にする**

各議題の要約が出そろったら、最後にまとめて議事録に仕上げます。

```
以下は会議の各議題の要約です。
これを1つの議事録にまとめてください。

【フォーマット】
（テンプレートを指定）

【議題1の要約】
（ステップ2の出力を貼り付ける）

【議題2の要約】
（ステップ2の出力を貼り付ける）

【議題3の要約】
（ステップ2の出力を貼り付ける）
```

### もう一つの方法: 「続きを送る」テクニック

議題ごとに分けるのが面倒な場合は、テキストを文字数の上限に合わせて機械的に分割し、順番に送る方法もあります。

```
（1回目の送信）
これから会議の文字起こしテキストを3回に分けて送ります。
すべて送り終わったら「まとめてください」と指示しますので、
それまでは「受け取りました」とだけ返答してください。

【テキスト 1/3】
（前半部分を貼り付ける）
```

```
（2回目の送信）
【テキスト 2/3】
（中盤部分を貼り付ける）
```

```
（3回目の送信）
【テキスト 3/3】
（後半部分を貼り付ける）

すべて送り終わりました。
上記3つのテキストをまとめて、議事録を作成してください。
```

この方法なら、テキストのどこで区切っても大丈夫です。ChatGPTは前の会話の内容を覚えているので、すべてのテキストを踏まえて議事録を作ってくれます。

## 実践例: 30分の会議メモ → 議事録の完成例

ここからは、実際の会議メモを使った具体例をお見せします。以下の流れで進めていきます。

```
会議メモ（入力） → プロンプト → ChatGPTの出力（議事録）
```

### 【入力】会議メモの例

以下は、30分間の社内ミーティングのメモです。実際の会議で取りそうな、やや雑なメモを想定しています。

```
4月度 販促会議メモ
3/24 10:00-10:30 第2会議室
出席: 課長（高橋）、田中、佐藤、鈴木、山田（リモート）

・4月キャンペーンの件
  高橋課長から説明。春の新生活キャンペーンをやる
  期間は4/1〜4/30の1ヶ月間
  →前年は2週間だったけど今年は長めにやりたい
  田中さんから「チラシは前回のデザインを流用していいか？」
  →OK、ただしキャッチコピーは新しくする
  チラシ作成は田中さん、4/3の会議までに初稿を出す
  佐藤さんがSNS投稿を担当。週2回ペース
  インスタとXの両方でやる

・予算について
  前年実績15万円、今年は20万に増額された
  チラシ印刷費 5万
  SNS広告費 10万（田中さん「もう少し増やせないか」→要検討）
  残り5万は予備費
  鈴木さんが予算管理の表を作る→4/1まで

・新商品の販促
  5月発売の新商品Aのサンプルが届いた
  山田さんから商品説明
  パンフレット作成が必要→外注か内製か未定
  見積もりを取る必要あり→鈴木さんが2社に見積もり依頼（4/5まで）
```

## 注意点: ChatGPT議事録の落とし穴

ChatGPTの議事録作成はとても便利ですが、そのまま提出してはいけないポイントがあります。必ず確認すべき注意点をまとめました。

### 注意点1: 固有名詞の確認

ChatGPTは文脈から推測して人名や社名を補完することがありますが、間違っていることがあります。特に以下は要注意です。

- **人名**: 「たなか」が「田中」なのか「棚香」なのか、ChatGPTには判断できません
- **社名・商品名**: 正式名称と略称が混在している場合、意図しない表記になることがあります
- **日付**: 曜日の計算を間違えることがあります（例:「4月3日（木）」が本当に木曜日か）

> **対策**: 出力された議事録の固有名詞（人名・社名・商品名・日付）は、必ず目視で確認してください。

### 注意点2: ニュアンスの補正

ChatGPTは文章をきれいに整えてくれますが、ニュアンスが変わってしまうことがあります。

たとえば、会議メモに「SNS広告費、もう少し増やせないか→要検討」と書いてあった場合、ChatGPTが「SNS広告費の増額が検討されている」と書くと、まるで前向きに検討しているような印象になります。実際には「難しいかもしれないが一応検討する」くらいの温度感だったかもしれません。

> **対策**: 決定事項や保留事項のニュアンスが実際の会議と合っているか、確認しましょう。特に「決定」「検討」「保留」の使い分けは重要です。

### 注意点3: ChatGPTが「創作」することがある

ChatGPTには、入力されていない情報を補完してしまう性質があります。たとえば、メモに期限が書かれていないタスクに対して、ChatGPTが勝手に期限を設定してしまうことがあります。

> **対策**: 議事録に書かれている情報が、元のメモに実際に含まれていたかを確認してください。「あれ、こんな話をしたかな？」と思ったら要注意です。

### 注意点4: 機密情報の取り扱い

ChatGPTに会議メモを入力するということは、その内容をOpenAI社のサーバーに送信するということです。社外秘の情報や個人情報を含む会議メモを扱う場合は、会社のセキュリティポリシーを確認してください。

> **対策**: 機密性の高い会議の議事録をChatGPTで作成する場合は、以下のいずれかの方法を検討しましょう。
> - ChatGPTの設定で「チャット履歴とトレーニング」をオフにする
> - ChatGPT Team/Enterprise など、法人向けプランを利用する
> - 固有名詞をダミーに置き換えてから入力し、出力後に戻す

## Before/After: 議事録作成の時間と品質の変化

ChatGPTを使う前と後で、議事録作成がどのように変わるのかを比較してみましょう。

### Before: ChatGPTを使う前

| 項目 | 内容 |
|------|------|
| 作成時間 | 30分〜1時間 |
| 作業内容 | メモを読み返す→文章を組み立てる→体裁を整える→見直し |
| 品質のばらつき | 書く人によって大きく異なる |
| 決定事項の漏れ | 時々発生する |
| 心理的負担 | 「またか……」という気持ちになりがち |

### After: ChatGPTを使った後

| 項目 | 内容 |
|------|------|
| 作成時間 | 5〜10分（入力3分＋確認5分） |
| 作業内容 | メモを貼り付ける→プロンプトを送る→出力を確認・修正 |
| 品質のばらつき | フォーマットが統一されるため安定 |
| 決定事項の漏れ | 大幅に減少（ChatGPTが網羅的に抽出） |
| 心理的負担 | 「すぐ終わる」ので気軽に取り組める |

**時間の変化: 30〜60分 → 5〜10分（約80%短縮）**

ただし、ここで大切なのは「ChatGPTが作った議事録をそのまま提出しない」ことです。5分の確認作業が、品質を保つための最低限の投資だと考えてください。特に最初の数回は、ChatGPTの出力の傾向をつかむために、丁寧に確認することをおすすめします。慣れてくると、「ここは毎回ちゃんと出力されるから大丈夫」「ここは毎回確認が必要だな」というパターンがわかってきます。

## 「やってみよう」コーナー: 直近の会議メモで議事録を作ってみよう

ここまで読んで、「なるほど、便利そうだな」と思った方。思っているだけでは身につきません。ぜひ実際にやってみましょう。

### チャレンジ: 直近の会議メモを議事録にしてみよう

**手順:**

1. **直近の会議メモを用意する**
   - 手書きメモでも、パソコンのメモでも構いません
   - 最近の打ち合わせ、ミーティング、朝礼の内容など、なんでもOKです
   - 「ちょうどいいメモがない」という方は、この章の実践例のメモをそのまま使ってみてください

2. **以下のプロンプトをコピーして、ChatGPTに送信する**

```
以下の会議メモを議事録にまとめてください。

【出力形式】
- 会議名
- 日時
- 参加者
- 議題ごとの要点（箇条書き）
- 決定事項
- TODOリスト（担当者・期限つき）
- 保留事項（未決定のもの）
- 次回会議

話し言葉は書き言葉に変換し、簡潔にまとめてください。

【会議メモ】
（ここにあなたの会議メモを貼り付ける）
```

3. **出力された議事録を確認する**
   - 固有名詞（人名・日付など）は正しいですか？
   - 決定事項に漏れはありませんか？
   - 実際には決まっていないのに「決定事項」に入っているものはありませんか？
   - ニュアンスは合っていますか？

4. **必要に応じて修正する**
   - 間違いがあった場合は、ChatGPTに「○○の部分を△△に修正してください」と伝えましょう
   - フォーマットを変えたい場合は、「箇条書きではなく表形式に変えてください」などと指示してみましょう

### ステップアップ: 慣れてきたら試してみよう

- **自社のテンプレートを使う**: 会社で決められた議事録フォーマットがあれば、それをプロンプトに含めてみましょう
- **複数の会議で試す**: 打ち合わせ、定例会議、プロジェクト会議など、異なるタイプの会議で試してみると、それぞれに適したプロンプトがわかってきます
- **プロンプトを保存する**: うまくいったプロンプトは、テキストファイルやメモアプリに保存しておきましょう。次回からコピー＆ペーストで使えます

## 章末まとめ

この章では、ChatGPTを使って議事録を作成する方法を学びました。ポイントを振り返りましょう。

**基本の流れ**
- 会議メモ（手書きまたはテキスト）を用意する
- 出力形式を指定したプロンプトでChatGPTに送る
- 出力された議事録を確認・修正する

**プロンプトのコツ**
- 出力形式（箇条書き、表形式、テンプレート）を明確に指定する
- 「決定事項」「TODO」「保留事項」を分けるよう指示する
- 文字起こしテキストの場合は「フィラー除去」「話し言葉→書き言葉」を指示する

**長い会議メモの対処法**
- 議題ごとに分割して要約し、最後にまとめる
- または「続きを送る」テクニックで分割送信する

**必ず確認すべきこと**
- 固有名詞（人名、社名、日付）の正確性
- 決定事項と保留事項のニュアンス
- ChatGPTが「創作」していないか
- 機密情報の取り扱い

**効果**
- 議事録作成の時間が約80%短縮（30〜60分 → 5〜10分）
- フォーマットが統一され、品質が安定する
- 決定事項やTODOの漏れが大幅に減る

会議後の議事録作成は、多くの事務職の方にとって「やらなきゃいけないけど面倒」な仕事の代表格です。ChatGPTを使えば、その負担は劇的に軽くなります。まずは直近の会議メモで試してみてください。一度体験すれば、もう手作業には戻れなくなるはずです。
