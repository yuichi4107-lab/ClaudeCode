# 第9章 その他の活用シーン ― 翻訳、リサーチ、アイデア出し

## まだまだあるChatGPTの活用法

ここまでの章では、メール作成や議事録、Excel作業など、事務職の方が日常的に直面する業務でのChatGPT活用法をご紹介してきました。しかし、ChatGPTの実力はまだまだこんなものではありません。

「え、そんなこともできるの？」

そう思っていただけるような活用シーンが、実はたくさんあります。翻訳、リサーチ、アイデア出し、スケジュール作成、チェックリスト作成、文章の校正――。どれも事務職の方なら「あったら助かる」と感じる場面ばかりです。

この章では、これまでの章では取り上げきれなかった「その他の活用シーン」を一気にご紹介します。どれも難しい操作は不要です。ChatGPTに話しかけるだけで、あなたの仕事の幅がぐっと広がります。

それでは、一つずつ見ていきましょう。

## 翻訳・多言語対応

### なぜChatGPTで翻訳するのか

「翻訳ならGoogle翻訳があるじゃないか」と思われるかもしれません。たしかに、単純な翻訳であればGoogle翻訳やDeepLでも十分です。

しかし、ChatGPTの翻訳には大きな強みがあります。それは「文脈を理解した翻訳」ができることです。

たとえば、ビジネスメールの翻訳では、単に言葉を置き換えるだけでなく、相手との関係性や状況に合わせた表現を選んでくれます。「この場面ではもう少しフォーマルに」「ここはカジュアルにしたい」といった微調整も、日本語で指示するだけで対応してくれるのです。

### 英文メールの翻訳と返信作成

海外の取引先や本社から英文メールが届いた。内容は何となくわかるけれど、返信をどう書けばいいか迷ってしまう――。そんな経験はありませんか？

ChatGPTなら、受け取った英文メールの翻訳と、返信の作成を一度にお願いできます。

**プロンプト例：英文メールの翻訳と返信作成**

```
以下の英文メールを日本語に翻訳してください。
その後、以下の内容で英語の返信メールを作成してください。

【受信メール】
Dear Tanaka-san,

Thank you for your prompt response regarding the quarterly report.
We would like to schedule a meeting next week to discuss the budget
allocation for Q3. Would Tuesday or Wednesday work for your team?

Please let us know at your earliest convenience.

Best regards,
Michael Johnson

【返信内容】
・火曜日の午前中なら対応可能
・参加者は田中と鈴木の2名
・会議資料は月曜日までに送付する
・Zoomでの開催を希望
```

**出力例**

```
【日本語訳】
田中様

四半期報告書について迅速にご対応いただき、ありがとうございます。
来週、第3四半期の予算配分について話し合うための会議を設定したいと
考えております。火曜日か水曜日はいかがでしょうか？

お手すきの際にご連絡ください。

よろしくお願いいたします。
マイケル・ジョンソン

---

【英語返信メール】
Dear Michael,

Thank you for your email. Tuesday morning would work well for us.

Tanaka and Suzuki will be attending the meeting from our side.
We will send the meeting materials by Monday.

Would it be possible to hold the meeting via Zoom?
Please let us know the preferred time, and we will adjust accordingly.

Best regards,
Tanaka
```

このように、受け取ったメールの内容を正確に把握したうえで、ビジネスマナーに沿った返信を作成してくれます。自分で一から英文を書く必要がないので、大幅な時間短縮になります。

### 海外取引先向け文書の翻訳

メールだけでなく、契約書の概要や製品説明書、プレゼン資料の翻訳にも活用できます。

**プロンプト例：文書の翻訳**

```
以下の日本語文書を英語に翻訳してください。
ビジネス文書として適切なフォーマルな表現でお願いします。

【翻訳対象】
弊社の新サービス「クラウド在庫管理システム」のご紹介です。
本システムは、中小企業向けに開発されたクラウドベースの在庫管理
ソリューションです。導入にあたって特別なソフトウェアのインストールは
不要で、Webブラウザからすぐにご利用いただけます。

主な特徴：
・リアルタイムの在庫状況確認
・発注の自動化機能
・月次レポートの自動生成
・既存の会計ソフトとの連携
```

**出力例**

```
We are pleased to introduce our new service, the "Cloud Inventory
Management System." This system is a cloud-based inventory management
solution developed specifically for small and medium-sized enterprises.
No special software installation is required for implementation, and the
system can be accessed immediately through a web browser.

Key Features:
- Real-time inventory status monitoring
- Automated ordering functionality
- Automatic monthly report generation
- Integration with existing accounting software
```

### 翻訳のニュアンス調整（フォーマル／カジュアル）

同じ内容でも、相手や場面によって適切なトーンは変わります。ChatGPTなら、ニュアンスの調整も簡単です。

**プロンプト例：トーンの調整**

```
以下の日本語を英語に翻訳してください。
3つのトーンで作成してください。

「来週の会議に参加できません。申し訳ありません。」

1. フォーマル（上司・取引先向け）
2. 標準（同僚向け）
3. カジュアル（親しい同僚向け）
```

**出力例**

```
1. フォーマル（上司・取引先向け）
I regret to inform you that I will be unable to attend
the meeting next week. I sincerely apologize for any
inconvenience this may cause.

2. 標準（同僚向け）
Unfortunately, I won't be able to attend next week's
meeting. I apologize for the inconvenience.

3. カジュアル（親しい同僚向け）
Hey, I can't make it to the meeting next week. Sorry
about that!
```

このように、同じ内容でもトーンを変えるだけで印象がまったく変わることがわかります。場面に応じて使い分けられるのは、ChatGPT翻訳ならではの強みです。

> **ワンポイントアドバイス**
> 翻訳を依頼するときは、「誰に向けた文書か」「どんな場面で使うか」を添えると、より適切な翻訳になります。たとえば「アメリカの取引先に送るビジネスメールです」と一言添えるだけで、表現の精度がぐっと上がります。

## リサーチ・情報収集

### ChatGPTをリサーチアシスタントに

事務職の方でも、上司から「この業界の最近の動向をまとめておいて」と頼まれることはありませんか？あるいは、新しいプロジェクトの準備で情報収集が必要になることもあるでしょう。

ChatGPTは、膨大な情報をもとに要点を整理してくれる優秀なリサーチアシスタントです。ただし、一つ重要な注意点があります。ChatGPTの情報には学習データの時点という制限があり、最新のニュースや数値データについては不正確な場合があります。あくまで「概要の把握」や「調査の出発点」として活用し、重要な数字や最新情報は必ず公式サイトなどで確認するようにしましょう。

### 業界動向の概要調べ

**プロンプト例：業界動向の調査**

```
物流業界の最近のトレンドを、事務職の私にもわかるように
簡潔にまとめてください。以下の項目で整理してください。

・業界全体の方向性（3〜4つ）
・注目されているキーワード（5つ程度）
・事務職として知っておくと役立つポイント

専門用語には簡単な説明を付けてください。
```

**出力例**

```
【物流業界の最近のトレンド】

■ 業界全体の方向性
1. DX（デジタルトランスフォーメーション）の加速
   → 紙の伝票や手作業を、デジタルツールに置き換える動きが
     業界全体で進んでいます。

2. 2024年問題への対応
   → トラックドライバーの労働時間規制が強化され、人手不足が
     深刻化。効率化が急務となっています。

3. EC（ネット通販）需要の拡大
   → 個人向け配送の増加に伴い、倉庫管理や配送管理の
     仕組みが大きく変わりつつあります。

4. 環境対応（グリーン物流）
   → CO2排出削減に向けた取り組みが求められています。

■ 注目キーワード
・ラストワンマイル（届け先への最後の配送区間）
・自動配車システム（AIが最適なルートを計算）
・倉庫ロボット（商品のピッキングを自動化）
・フィジカルインターネット（物流ネットワークの共有化）
・リバースロジスティクス（返品・リサイクルの物流）

■ 事務職として知っておくと役立つポイント
・受発注業務のデジタル化が進むため、新しいシステムの
  操作を求められる場面が増える可能性があります。
・取引先との書類のやり取りが電子化されるケースが増えて
  います。電子帳簿保存法への対応も押さえておきましょう。
```

### 競合情報のまとめ

**プロンプト例：競合情報の整理**

```
上司から「A社、B社、C社のサービスを比較する表を作って」と
頼まれました。以下の情報を整理して、比較表の形にしてください。

【比較したい項目】
・サービス名
・主な特徴（3つ程度）
・料金体系（月額制/従量制など）
・導入のしやすさ
・サポート体制

※一般的な情報で構いません。具体的な企業名ではなく、
「クラウド型勤怠管理システム」を提供する3社を想定して、
A社・B社・C社として比較表を作成してください。
```

**出力例**

```
【クラウド型勤怠管理システム 比較表】

| 項目           | A社               | B社               | C社               |
|--------------|-------------------|-------------------|-------------------|
| サービス名      | 勤怠クラウドPro     | かんたん勤怠         | スマート打刻          |
| 特徴①        | 多機能・カスタマイズ性高 | シンプルで使いやすい    | スマホ対応に強い       |
| 特徴②        | 給与計算連携あり      | 初期費用が安い        | GPS打刻対応         |
| 特徴③        | 大企業向け          | 中小企業向け         | 外回り・現場向け       |
| 料金体系       | 月額制（1人500円〜）  | 月額制（1人300円〜）  | 従量制（打刻数に応じて） |
| 導入しやすさ    | △（設定に時間がかかる） | ◎（即日利用可能）     | ○（アプリDLで開始）   |
| サポート       | 電話・メール・訪問     | メール・チャット       | メール・電話          |
| おすすめの企業規模 | 100名以上          | 10〜50名           | 外勤スタッフが多い企業   |
```

表形式でまとめてもらえるので、そのまま上司への報告資料に使えます。もちろん、実在するサービスを比較する場合は、ChatGPTの出力をたたき台にして、各社の公式サイトで正確な情報を確認しましょう。

### 社内FAQの下書き作成

新入社員や異動者向けに、よくある質問と回答をまとめる作業も、ChatGPTに手伝ってもらえます。

**プロンプト例：社内FAQの下書き**

```
総務部として、新入社員向けの社内FAQを作成したいです。
以下のカテゴリーで、よくありそうな質問と回答を各3つずつ
作成してください。

カテゴリー：
1. 勤怠・休暇について
2. 経費精算について
3. 社内システムについて

回答は簡潔に、ですます調で書いてください。
各回答は3〜4文程度でお願いします。
```

**出力例**

```
【新入社員向け 社内FAQ】

■ 1. 勤怠・休暇について

Q1. 有給休暇はいつから取得できますか？
A. 入社後6か月が経過し、その期間の出勤率が8割以上であれば、
   10日間の有給休暇が付与されます。取得の際は、原則として
   3営業日前までに上長へ申請してください。

Q2. 遅刻・早退する場合はどうすればよいですか？
A. まず、始業前に上長へ電話またはチャットで連絡してください。
   出社後、勤怠システムで「遅刻届」または「早退届」を提出
   します。体調不良の場合は無理をせず、在宅勤務への切り替えも
   ご検討ください。

Q3. 夏季休暇や年末年始休暇は何日ありますか？
A. 夏季休暇は7月〜9月の間で3日間取得できます。年末年始は
   12月29日〜1月3日が会社の休業日です。詳しい日程は毎年
   10月頃に総務部からご案内します。

■ 2. 経費精算について

Q1. 経費精算の提出期限はいつですか？
A. 経費が発生した月の翌月5営業日以内に申請してください。
   期限を過ぎると、当月の精算に間に合わない場合があります。
   月末にまとめて処理するのではなく、こまめに申請することを
   おすすめします。

Q2. 領収書を紛失してしまった場合はどうすればよいですか？
A. まず、上長に報告してください。クレジットカードの利用明細
   など、支払いを証明できる書類があれば、代替書類として
   申請できる場合があります。詳しくは経理部にご相談ください。

Q3. 交通費は定期区間外のみ申請するのですか？
A. はい、通勤定期券の区間内の交通費は申請不要です。定期区間外
   の移動が発生した場合のみ、経費精算システムから申請して
   ください。経路は最も経済的なルートを選択してください。

■ 3. 社内システムについて

Q1. パスワードを忘れてしまいました。どうすればよいですか？
A. 情報システム部のヘルプデスク（内線: 9999）にご連絡
   ください。本人確認の後、パスワードリセットの手続きを
   行います。セキュリティのため、パスワードの使い回しは
   お控えください。

Q2. 社内Wi-Fiの接続方法を教えてください。
A. SSIDは「COMPANY-WORK」です。パスワードは入社時に配布
   された「ITセットアップガイド」に記載されています。接続
   できない場合は、情報システム部にお問い合わせください。

Q3. 自分のPCにソフトウェアをインストールしてもよいですか？
A. セキュリティの観点から、個人の判断でのインストールは禁止
   されています。業務上必要なソフトウェアがある場合は、
   情報システム部に申請してください。承認後、担当者が
   インストールを行います。
```

FAQ作成は地味に時間がかかる作業ですが、ChatGPTに下書きを作ってもらえば、あとは自社の実情に合わせて修正するだけで済みます。ゼロから考えるよりも、はるかに効率的です。

## アイデア出し・ブレインストーミング

### 一人ブレストの強い味方

「アイデアを出して」と言われても、一人ではなかなか思いつかない――。そんなときこそ、ChatGPTの出番です。ChatGPTは「壁打ち相手」として非常に優秀です。遠慮なくたくさんのアイデアを出してくれますし、「もっと別の方向で」と言えば違う角度から提案してくれます。

ここでのコツは、**最初から完璧なアイデアを求めないこと**です。まずはたくさん出してもらい、そこから良いものを選んで磨いていくのが効果的です。

### イベント企画のアイデア出し

**プロンプト例：社内イベントの企画**

```
社内の親睦を深めるためのイベントを企画しています。
以下の条件でアイデアを10個出してください。

【条件】
・参加人数: 30〜40名
・予算: 1人あたり3,000円程度
・時間: 平日の業務終了後（2〜3時間）
・場所: 社内の会議室または近隣の施設
・制約: お酒が飲めない人もいるので、飲み会以外で
・目的: 部署を超えた交流を促進したい

各アイデアには「概要」「おすすめポイント」「必要な準備」を
添えてください。
```

**出力例（一部抜粋）**

```
【社内親睦イベント アイデア10選】

1. チーム対抗クイズ大会
   概要: 部署混合のチームを作り、会社に関するクイズや
         一般常識クイズに挑戦する
   おすすめポイント: 準備が簡単で、自然と会話が生まれる。
                    チーム分けで普段話さない人と交流できる
   必要な準備: クイズの問題作成、チーム分け表、景品

2. 社内マルシェ（持ち寄りパーティー）
   概要: 各自が得意料理やおすすめのお菓子を持ち寄って、
         カジュアルな交流会を開催
   おすすめポイント: 食べ物をきっかけに会話が弾む。
                    手作りでなくても購入品でOKにすれば負担が少ない
   必要な準備: テーブル配置、紙皿・紙コップ、アレルギー確認

3. ボードゲーム大会
   概要: 人生ゲームやカードゲームなど、簡単なボードゲームを
         複数テーブルで同時進行
   おすすめポイント: 年齢・性別を問わず楽しめる。ルールが
                    簡単なゲームを選べば、誰でも参加しやすい
   必要な準備: ボードゲームの購入・レンタル、テーブル配置

（以下、4〜10のアイデアが続きます）
```

### 業務改善のアイデア出し

**プロンプト例：業務改善の提案**

```
総務部の事務作業で、以下の業務に時間がかかっています。
改善のアイデアを出してください。

【時間がかかっている業務】
・毎月の経費精算チェック（紙の領収書を1枚ずつ確認）
・備品の在庫管理（Excelで手動管理）
・会議室の予約管理（メールベース）
・社内通知の作成と配信（Word→PDF→メール添付）
・入退社手続きの書類準備（テンプレートから手作業でコピー）

それぞれの業務について、以下を提案してください。
1. すぐにできる改善（費用ゼロ〜低コスト）
2. 中期的な改善（ツール導入など）
3. 改善による期待効果（時間削減の目安）
```

このようなプロンプトを投げると、各業務について具体的な改善案が返ってきます。自分一人では思いつかなかった視点が見つかることも多く、上司への改善提案の材料としても活用できます。

### ネーミング案の生成

新しいプロジェクトや社内制度の名前を考えるのは、意外と難しいものです。ChatGPTにお願いすれば、短時間でたくさんの候補を出してくれます。

**プロンプト例：ネーミング案の生成**

```
社内の新しいメンター制度の名前を考えてください。

【制度の概要】
・先輩社員が新入社員の相談相手になる
・月1回のランチミーティングを実施
・業務の悩みだけでなく、キャリアの相談もOK
・堅苦しくなく、気軽に相談できる雰囲気を大切にしたい

【名前の方向性】
・親しみやすい、カタカナまたはひらがなの名前
・覚えやすく、社内で浸透しやすいもの
・20案ほど出してください
```

**出力例**

```
【メンター制度 ネーミング案】

■ 親しみやすさ重視
1. となりのセンパイ
2. ナナメの関係
3. しゃべりばランチ
4. メンとも
5. ほっとランチ

■ 成長・応援のイメージ
6. グローアップ・ランチ
7. ミライトーク
8. キャリアのたね
9. ステップアップ・カフェ
10. はじめの一歩サポート

■ つながり・絆のイメージ
11. つなぐランチ
12. ブリッジトーク
13. ワンチーム・ランチ
14. こころばし
15. パスをつなぐ

■ ユニークな方向性
16. ランチの処方箋

20. かけこみランチ
```

ネーミングは正解がないからこそ、たくさんの選択肢があると助かります。ここから候補を絞り込んで、チームで投票して決める――そんな進め方もおすすめです。

## その他の便利な使い方

### スケジュール案の作成

プロジェクトの大まかなスケジュールを立てるとき、何から始めれば良いか迷うことはありませんか？ ChatGPTに条件を伝えれば、たたき台となるスケジュール案を作成してくれます。

**プロンプト例：スケジュール案の作成**

```
以下の条件で、社内研修の準備スケジュールを作成してください。

【研修の概要】
・テーマ: 新入社員向けビジネスマナー研修
・実施日: 4月15日（火）
・参加者: 新入社員20名
・場所: 社内大会議室
・担当: 総務部（私を含め3名）

【準備すべきこと】
・研修内容の企画
・講師の手配（外部講師）
・会場の準備
・資料の作成・印刷
・参加者への案内
・備品（名札、筆記用具など）の準備
・当日のタイムテーブル作成

本日は3月1日です。
週単位でスケジュールを組んでください。
```

**出力例**

```
【新入社員ビジネスマナー研修 準備スケジュール】

■ 3月第1週（3/1〜3/7）: 企画・方針決定
  □ 研修のゴールと内容の骨子を決定
  □ 外部講師の候補をリストアップ・問い合わせ
  □ 大会議室の予約確認
  □ 予算の確認・上長への承認依頼

■ 3月第2週（3/8〜3/14）: 講師確定・詳細設計
  □ 外部講師の確定・契約手続き
  □ 研修プログラムの詳細を講師と打ち合わせ
  □ 当日のタイムテーブル（案）を作成

■ 3月第3週（3/15〜3/21）: 案内・資料準備開始
  □ 参加者への案内メール送付
  □ 研修資料の作成開始
  □ 必要な備品のリストアップ・発注

■ 3月第4週（3/22〜3/28）: 資料完成・リハーサル
  □ 研修資料の完成・上長レビュー
  □ 備品の納品確認
  □ 講師との最終打ち合わせ

■ 4月第1週（3/29〜4/4）: 最終準備
  □ 資料の印刷・製本
  □ 名札の作成
  □ 会場のレイアウト確認
  □ 当日の役割分担の確認

■ 4月第2週（4/7〜4/11）: 直前確認
  □ 参加者への最終リマインドメール送付
  □ 会場設営のリハーサル
  □ 備品・資料の最終チェック
  □ 当日のタイムテーブル最終版を関係者に共有

■ 4月15日（火）: 研修当日
  □ 会場設営（8:30〜）
  □ 受付開始（9:30〜）
  □ 研修実施（10:00〜17:00）

  □ アンケート回収
```

この出力をもとに、自社の事情に合わせて調整すれば、あっという間にスケジュール表の完成です。

### チェックリストの作成

漏れのないチェックリストを作るのは、地味ですが重要な作業です。ChatGPTに任せれば、自分では見落としがちな項目まで網羅したリストが手に入ります。

**プロンプト例：チェックリストの作成**

```
来客対応のチェックリストを作成してください。
以下の3つのフェーズに分けてください。

1. 来客前の準備
2. 来客当日の対応
3. 来客後のフォロー

各フェーズで5〜8項目程度、実務的な内容でお願いします。
担当者が確認しやすいように、□（チェックボックス）形式に
してください。
```

**出力例**

```
【来客対応チェックリスト】

■ 1. 来客前の準備
  □ 来訪者の氏名・人数・所属を確認
  □ 会議室の予約（人数に適したサイズ）
  □ 受付への来客情報の連絡（来訪者名・時間・案内先）
  □ 会議資料の準備・必要部数の印刷
  □ お茶・コーヒーなどの飲み物の在庫確認
  □ 会議室の清掃状態の確認（前日または当日朝）
  □ プロジェクターやモニターなど機器の動作確認
  □ 来訪者用の入館証・ゲストWi-Fi情報の準備

■ 2. 来客当日の対応
  □ 受付での出迎え（約束時間の5分前にはスタンバイ）
  □ 笑顔で挨拶し、会議室へご案内
  □ コートや荷物の預かりを申し出る
  □ 飲み物の提供（到着後すみやかに）
  □ 名刺交換のサポート（必要に応じて）
  □ 会議中の追加の飲み物提供
  □ 会議終了後、エレベーターまたは出口までお見送り

■ 3. 来客後のフォロー
  □ 会議室の片付け・原状復帰
  □ 忘れ物がないか確認
  □ 来訪者へのお礼メール送付（当日中が望ましい）
  □ 会議内容の議事録作成・関係者への共有
  □ 次回のアクション事項の確認・カレンダー登録
  □ 入館証の回収確認
```

このチェックリストをそのまま印刷して使うこともできますし、社内の共有フォルダに置いておけば、誰でも同じクオリティの来客対応ができるようになります。

### 文章の校正・誤字脱字チェック

社内文書やメールを送る前に、ChatGPTで校正をかけるのも効果的です。自分では気づきにくい誤字脱字や、わかりにくい表現を指摘してくれます。

**プロンプト例：文章の校正**

```
以下の社内通知文を校正してください。
誤字脱字、文法の誤り、わかりにくい表現があれば指摘して、
修正案を提示してください。

---
社員各位

お疲れ様です。総務部です。

来る12月25日（月）に、社内大掃除を実地いたします。
各部署から最低2名異常のの参加をお願いします。
当日はは動きやすい格好でお越し下さい。
掃除用具は総務部が用意しますが、各自で雑巾を
1枚お持ちいただけると幸甚です。

なお、詳細な割り当ては追って連絡します。
ご協力よろしくお願い致します。

総務部　山田
---
```

**出力例**

```
【校正結果】

修正箇所は以下の4点です。

1. 「実地」→「実施」
   ×「社内大掃除を実地いたします」
   ○「社内大掃除を実施いたします」
   ※「実地」は「現場で行う」という意味の別の言葉です。

2. 「2名異常のの」→「2名以上の」
   ×「最低2名異常のの参加」
   ○「最低2名以上の参加」
   ※「異常」は誤変換です。また「の」が重複しています。

3. 「当日はは」→「当日は」
   ×「当日はは動きやすい格好」
   ○「当日は動きやすい服装」
   ※「は」が重複しています。また「格好」より「服装」の方が
     ビジネス文書として適切です。

4. 「幸甚です」→「助かります」
   ×「お持ちいただけると幸甚です」
   ○「お持ちいただけると助かります」
   ※「幸甚」はかなり堅い表現で、社内通知にはやや不釣り合い
     です。もう少しカジュアルな表現がおすすめです。

---
【修正後の文章】

社員各位

お疲れ様です。総務部です。

来る12月25日（月）に、社内大掃除を実施いたします。
各部署から最低2名以上の参加をお願いします。
当日は動きやすい服装でお越しください。
掃除用具は総務部が用意しますが、各自で雑巾を
1枚お持ちいただけると助かります。

なお、詳細な割り当ては追ってご連絡いたします。
ご協力よろしくお願いいたします。

総務部　山田
```

校正は、自分で何度読み返しても見落としてしまうものです。ChatGPTに一度チェックしてもらうだけで、恥ずかしいミスを防げます。大切なメールや文書を送る前の「最終チェック係」として、ぜひ活用してみてください。

> **ワンポイントアドバイス**
> 校正を依頼するときは、「誤字脱字だけ直して」「表現も改善して」「ビジネス文書としての体裁もチェックして」など、チェックの範囲を指定すると、求めている精度の結果が返ってきます。

## Before/After: ChatGPTを使う前は思いつかなかった活用法

ここで、この章で紹介した活用法を「ChatGPTを使う前」と「使った後」で比較してみましょう。

### Before（ChatGPTなし）

| 作業 | やり方 | かかる時間 |
|------|--------|-----------|
| 英文メールの返信 | 辞書を引きながら自力で作成 | 30分〜1時間 |
| 業界動向のリサーチ | Webで記事を何本も読んでまとめる | 2〜3時間 |
| イベント企画 | 一人で考え込む、過去の事例を探す | 1〜2時間 |
| スケジュール作成 | 白紙から項目を洗い出す | 1時間 |
| チェックリスト作成 | 経験頼みで項目を並べる | 30分〜1時間 |
| 文章の校正 | 自分で何度も読み返す | 15〜30分 |

### After（ChatGPTあり）

| 作業 | やり方 | かかる時間 |
|------|--------|-----------|
| 英文メールの返信 | 要点を日本語で伝えてChatGPTが英文作成 | **5〜10分** |
| 業界動向のリサーチ | ChatGPTに概要を聞いて、要点を確認 | **15〜30分** |
| イベント企画 | ChatGPTに条件を伝えてアイデアを大量に出す | **10〜15分** |
| スケジュール作成 | 条件を伝えてたたき台を自動生成 | **5〜10分** |
| チェックリスト作成 | ChatGPTに網羅的なリストを出してもらう | **5〜10分** |
| 文章の校正 | ChatGPTに校正を依頼して指摘をもらう | **2〜3分** |

合計すると、これらの作業だけで**1日あたり数時間の節約**になる可能性があります。もちろん、ChatGPTの出力をそのまま使うのではなく、自分の目で確認・修正する時間は必要です。それでも、ゼロから作業するのに比べれば、圧倒的に効率的です。

大切なのは、「こんなことにも使えるんだ」と気づくことです。一つ活用法を見つけると、「あれにも使えるかも」「これもいけるかも」と、どんどんアイデアが広がっていきます。
