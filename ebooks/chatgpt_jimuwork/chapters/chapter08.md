## 第8章 データ整理・分類 ― 手作業の仕分けにさようなら

### この章で学ぶこと

毎日のように繰り返される、データの仕分け・整理・統一。コピー＆ペーストで一件ずつ直していく作業は、時間もかかれば神経もすり減ります。この章では、ChatGPTを「データ整理アシスタント」として活用する方法を、実際の事務作業に近いサンプルデータとともに具体的に解説します。

---

### 8-1. 事務職のデータ整理作業の実態

#### コピペ地獄と目視チェックの日々

事務職の方なら、こんな経験があるはずです。

- 営業担当者がバラバラの書き方で入力した住所データを、請求書発送のために統一する
- 取引先リストの会社名が「（株）」「株式会社」「㈱」と表記揺れしていて、名寄せが必要
- アンケートの自由回答欄を、報告書用に手作業でカテゴリに分ける
- 2つのExcelファイルに同じ人が別の名前で入っていて、重複を探す

これらの作業には共通点があります。「人間が見れば分かるけれど、Excelの関数だけでは難しい」ということです。VLOOKUP や IF 関数で対応できる範囲を超えていて、結局は目で見て一件ずつ判断し、手で直す――いわゆる「コピペ地獄」に陥ります。

#### なぜExcel関数だけでは限界があるのか

たとえば住所データの表記揺れを考えてみましょう。

| 入力データ | 問題点 |
|---|---|
| 東京都港区赤坂1-2-3 | 全角ハイフン |
| 東京都港区赤坂１丁目２番３号 | 漢数字＋丁目番号 |
| 港区赤坂1‐2‐3 | 都道府県なし＋別のハイフン |

これらを「東京都港区赤坂1-2-3」に統一するには、SUBSTITUTE関数を何重にもネストし、都道府県の有無を判定し、数字の全角半角を変換し……と、関数だけで対応しようとすると、とんでもなく複雑な数式になります。しかも、新しいパターンが出るたびに数式を修正しなければなりません。

ここで登場するのがChatGPTです。ChatGPTは「文脈を読んで判断する」ことが得意ですから、こうした表記揺れの統一や分類作業を、柔軟に手伝ってくれます。

---

### 8-2. ChatGPTにデータ整理を手伝ってもらう基本パターン

ChatGPTにデータ整理を頼むときの基本的な流れは、たった3ステップです。

**ステップ1: ルールを伝える**
「何をどう整理したいのか」を明確に指示します。

**ステップ2: データを渡す**
整理したいデータを、ChatGPTが理解しやすい形式で入力欄に貼り付けます。

**ステップ3: 出力形式を指定する**
結果をどんな形式で返してほしいのかを伝えます。Excelに貼り付けたいなら「表形式で」、プログラムに使うなら「CSV形式で」といった具合です。

この3ステップを意識するだけで、ChatGPTへの指示がぐっと的確になります。それでは、具体的なシーンごとに見ていきましょう。

### 8-3. シーン別プロンプト例と出力例

#### シーン1: 住所データの正規化（表記揺れの統一）

請求書の発送先住所がバラバラの書き方で入力されている――よくある悩みです。

**サンプルデータ（整理前）**

```
1, 東京都港区赤坂１丁目２番３号
2, 港区赤坂1-2-3
3, 東京都港区赤坂1―2―3
4, 東京都 港区赤坂 1-2-3
5, 東京都港区赤坂一丁目二番三号
```

**プロンプト例**

```
以下の住所データを、次のルールで正規化してください。

【ルール】
- 都道府県は必ず含める
- 数字は半角に統一
- 区切りは半角ハイフン（-）に統一（「丁目」「番」「号」→ ハイフン）
- 余分なスペースは削除
- 漢数字は算用数字に変換

【データ】
1, 東京都港区赤坂１丁目２番３号
2, 港区赤坂1-2-3
3, 東京都港区赤坂1―2―3
4, 東京都 港区赤坂 1-2-3
5, 東京都港区赤坂一丁目二番三号

番号付きで、正規化後の住所だけを返してください。
```

**ChatGPTの出力例**

```
1, 東京都港区赤坂1-2-3
2, 東京都港区赤坂1-2-3
3, 東京都港区赤坂1-2-3
4, 東京都港区赤坂1-2-3
5, 東京都港区赤坂1-2-3
```

5件すべてが同じ形式に統一されました。手作業なら1件ずつ確認しながら直す必要がありましたが、ChatGPTなら一瞬です。

**ポイント:** ルールを箇条書きで明示することで、ChatGPTの判断がブレにくくなります。「なんとなく統一して」ではなく、具体的な変換ルールを書きましょう。

#### シーン2: 名前リストの整理（姓名分割、フリガナ付与）

顧客リストのデータで、姓と名が1つのセルにまとまっている。あるいは、フリガナが入っていない。こうした「あと一手間」が必要な名前データの整理も、ChatGPTの得意分野です。

**サンプルデータ（整理前）**

```
山田太郎
鈴木 花子
田中一郎
佐藤　美咲
高橋健太
```

**プロンプト例**

```
以下の人名を、次の形式で整理してください。

【出力形式】
姓 | 名 | セイ | メイ

- 姓と名を分割してください
- フリガナ（カタカナ）を付けてください
- 区切りは半角パイプ（|）でお願いします
- ヘッダー行も付けてください

【データ】
山田太郎
鈴木 花子
田中一郎
佐藤　美咲
高橋健太
```

**ChatGPTの出力例**

```
姓 | 名 | セイ | メイ
山田 | 太郎 | ヤマダ | タロウ
鈴木 | 花子 | スズキ | ハナコ
田中 | 一郎 | タナカ | イチロウ
佐藤 | 美咲 | サトウ | ミサキ
高橋 | 健太 | タカハシ | ケンタ
```

**注意:** ChatGPTは一般的な読み方でフリガナを推測します。珍しい読み方の名前（例：「一郎」を「かずお」と読む場合）は、正しく推定できないことがあります。出力後に必ず目視で確認し、間違いがあれば修正してください。100%の正確性が求められる場面では、ChatGPTの出力はあくまで「下書き」と考えるのが安全です。

9. 研修の機会をもっと増やしてほしい
10. 通勤手当の上限を上げてほしい

以下のアンケート自由回答を分類してください。

の表形式でお願いします。

【データ】

**サンプルデータ（整理前）**

A003,田中一郎,D10,2021/07/01,tanaka@example.com
A004,佐藤美咲,D30,2018/04/01,sato@example.com

```
以下のCSVデータを、次のルールで変換してください。

【変換ルール】

#### シーン5: 重複データの検出ルール作成

2つのリストを突き合わせて重複を見つけたい場面。名前の書き方が微妙に違う場合、Excelの完全一致検索では見つけられません。

**サンプルデータ（整理前）**

```
【リストA: 既存顧客】
1, 山田 太郎, ヤマダタロウ
2, 鈴木 花子, スズキハナコ

2, 伊藤 美咲, イトウミサキ
3, たなか 一郎, タナカ イチロウ
4, 渡辺 健一, ワタナベケンイチ
```

**プロンプト例**

```
以下の2つのリストを比較して、同一人物と思われるデータを見つけてください。

【判定基準】
- 漢字氏名またはフリガナが一致（スペースの有無、ひらがな/カタカナの違いは無視）
- 完全一致でなくても、高い確率で同一人物と思われるものを検出

【出力形式】
リストA番号 | リストB番号 | 判定理由

該当なしの場合は「重複なし」と回答してください。

【リストA: 既存顧客】
1, 山田 太郎, ヤマダタロウ
2, 鈴木 花子, スズキハナコ
3, 田中 一郎, タナカイチロウ
4, 高橋 健太, タカハシケンタ

【リストB: 新規問い合わせ】
1, やまだ太郎, ヤマダ タロウ
2, 伊藤 美咲, イトウミサキ
3, たなか 一郎, タナカ イチロウ
4, 渡辺 健一, ワタナベケンイチ
```

**ChatGPTの出力例**

```
リストA番号 | リストB番号 | 判定理由

### 8-4. データをChatGPTに渡す際のフォーマット

ChatGPTにデータを渡すとき、形式によって処理の精度が変わります。おすすめのフォーマットを紹介します。

#### 表形式（パイプ区切り）

少量のデータを見やすく渡したいときに向いています。

```
名前 | 部署 | 電話番号
山田太郎 | 営業部 | 03-1234-5678
鈴木花子 | 経理部 | 03-2345-6789
```

**メリット:** 見た目が分かりやすく、ChatGPTが列の対応関係を正しく認識しやすい。
**デメリット:** データ量が多いと入力が大変。

#### CSV形式（カンマ区切り）

Excelからコピーしたデータや、システムからエクスポートしたデータをそのまま渡すときに便利です。

```
名前,部署,電話番号
山田太郎,営業部,03-1234-5678
鈴木花子,経理部,03-2345-6789
```

**メリット:** Excelからそのままコピーしやすい。大量データに向いている。
**デメリット:** データ内にカンマが含まれると、列がずれる可能性がある。

#### タブ区切り形式（TSV）

Excelのセルをそのままコピーして貼り付けると、実はタブ区切りになります。ChatGPTはこの形式もきちんと認識してくれます。

```
名前	部署	電話番号
山田太郎	営業部	03-1234-5678
鈴木花子	経理部	03-2345-6789
```

**メリット:** Excelから直接コピー＆ペーストできる。最も手軽。
**デメリット:** 見た目ではタブかスペースか区別しにくい。

#### どの形式を選ぶ？

迷ったら、次の基準で選びましょう。

| 状況 | おすすめの形式 |
|---|---|
| Excelからコピーしてすぐ貼りたい | タブ区切り（そのままコピペ） |
| 加工ルールも一緒に伝えたい | 表形式（パイプ区切り） |
| データ量が多い・システム連携 | CSV形式 |

いずれの形式でも、**ヘッダー行（列名）を必ず付ける** ことが重要です。ヘッダーがないと、ChatGPTは「この列が何を意味するか」を推測しなければならず、誤った処理をする可能性があります。

### 8-5. 大量データの分割処理テクニック

ChatGPTには、一度に処理できるテキスト量に上限があります。数千行のデータを一度に貼り付けると、途中で回答が途切れたり、後半のデータが処理されなかったりすることがあります。

#### 目安: 一度に渡すのは50行程度まで

経験上、表形式のデータであれば **50行程度** までなら安定して処理してくれます。100行を超えると、出力が途中で切れるリスクが高まります。

#### 分割処理の手順

大量データを処理する場合は、次の手順で分割しましょう。

**手順1: ルールを先に伝える**

```
これから住所データの正規化をお願いします。
データは複数回に分けて送ります。

【ルール】
- 都道府県は必ず含める
- 数字は半角に統一
- 区切りは半角ハイフンに統一
- 番号付きで結果だけ返してください

準備ができたら「了解しました」と返してください。
```

**手順2: データを50行ずつ送る**

```
【第1回: 1〜50行目】
1, 東京都港区赤坂１丁目２番３号
2, 港区赤坂1-2-3
...（50行目まで）
```

**手順3: 結果を受け取ったら、次のデータを送る**

```
ありがとうございます。続きをお願いします。

【第2回: 51〜100行目】
51, 大阪府大阪市北区梅田1-1-1
52, 大阪市北区梅田１丁目１番１号
...
```

#### 分割処理のコツ

- **番号を通しで振っておく**: 分割しても何行目のデータか分かるようにしましょう
- **ルールは最初に一度だけ伝える**: 毎回ルールを書き直す必要はありません。ChatGPTは会話の文脈を覚えています
- **結果はその都度Excelに貼り付ける**: 全部まとめてから貼ると、順番がずれるリスクがあります

### 8-6. ChatGPTの出力をExcelに貼り付ける方法

ChatGPTの出力をExcelで使うための具体的な手順を紹介します。

#### パターン1: 表形式の出力をそのまま貼る

ChatGPTが表形式で出力した場合、そのままコピーしてExcelに貼り付けると、1つのセルに全部入ってしまうことがあります。確実にセルに分けるには、次の方法を使います。

**方法A: CSV形式で出力してもらう**

プロンプトの最後に「CSV形式（カンマ区切り）で出力してください」と加えます。出力をメモ帳に貼り付けて「.csv」の拡張子で保存し、Excelで開けば、自動的にセルに分かれます。

**具体的な手順:**

1. ChatGPTの出力をコピーする
2. メモ帳（Notepad）を開く
3. 貼り付ける
4. 「名前を付けて保存」で、ファイル名を「データ.csv」にする（このとき「ファイルの種類」を「すべてのファイル」にして、文字コードを「UTF-8」にする）
5. 保存したファイルをExcelで開く

**方法B: タブ区切りで出力してもらう**

「タブ区切りで出力してください」と指示すると、ChatGPTの出力をそのままExcelに貼り付けたときに、セルが自動的に分かれます。

**具体的な手順:**

1. ChatGPTの出力をコピーする
2. Excelを開いて、セルA1を選択する
3. そのまま貼り付ける（Ctrl + V）

タブ区切りの場合、Excelが自動的に列を認識してくれるので、最も簡単な方法です。

#### パターン2: 「区切り位置」機能を使う

すでにExcelに貼り付けたあとで、1つのセルにデータがまとまってしまった場合は、Excelの「区切り位置」機能を使います。

1. データが入っている列を選択する
2. 「データ」タブ →「区切り位置」をクリックする
3. 「コンマやタブなどの区切り文字によってフィールドごとに区切られたデータ」を選ぶ
4. 区切り文字（カンマ、タブなど）を選んで「完了」

この方法を覚えておくと、ChatGPTの出力に限らず、さまざまなデータの取り込みに使えます。

### 8-7. 注意点 ― 安全にデータを扱うために

ChatGPTをデータ整理に使うときには、いくつかの重要な注意点があります。

#### 個人情報の取り扱い

**最も重要な注意点です。** ChatGPTに入力したデータは、原則としてOpenAI社のサーバーに送信されます。

- **氏名・住所・電話番号・メールアドレス** などの個人情報を含むデータは、そのまま送らないでください
- 社内規定やプライバシーポリシーで、外部AIサービスへのデータ送信が禁止されていないか、必ず確認しましょう

**個人情報を含むデータを処理したい場合の対処法:**

1. **ダミーデータで手順を確認する**: まず架空のデータでプロンプトと出力形式を確認し、うまくいくことを確認してから、本番データは手元で処理する
2. **匿名化してから渡す**: 名前を「A氏」「B氏」に、住所を「〇〇県△△市」に置き換えてから送る
3. **ChatGPT Team / Enterprise プランを利用する**: 会社でこれらのプランを契約している場合、入力データがモデルの学習に使用されないことが保証されています。社内のIT部門に確認しましょう
4. **API経由で利用する**: OpenAI APIはデフォルトで入力データを学習に使用しません。技術に詳しい同僚やIT部門に相談してみてください

#### 大量データの制限

- ChatGPTが一度に処理できるデータ量には上限があります（8-5節参照）
- 出力が途中で切れた場合は「続きをお願いします」と入力すれば、途中から再開してくれます
- ただし、再開時にデータがずれることがあるため、行番号を振っておくことが大切です

#### 正確性の限界

- ChatGPTの出力は **100%正確とは限りません**
- 特に以下のケースでは誤りが起きやすいです:
  - 珍しい人名の読み方
  - 存在しない住所の補完（ChatGPTが「それらしい」住所を作ってしまうことがある）
  - 曖昧な分類の判断
- 必ず出力結果を目視でチェックする習慣をつけましょう

#### 再現性の課題

- 同じプロンプトで同じデータを渡しても、ChatGPTの回答が毎回完全に同じとは限りません
- 業務で使う場合は、一度うまくいったプロンプトをメモ帳やExcelに保存しておき、テンプレートとして再利用すると便利です

### 8-8. Before/After: データ整理作業の時間と精度の変化

ChatGPTを活用することで、データ整理作業がどう変わるのか、3つの典型的なケースで比較してみましょう。

#### ケース1: 住所データの正規化（200件）

| | 手作業 | ChatGPT活用 |
|---|---|---|
| 所要時間 | 約2時間 | 約20分（分割送信4回＋確認） |
| 精度 | 見落としが5〜10件程度 | ほぼ統一（要確認は2〜3件） |
| 作業者の負担 | 集中力が必要、疲労大 | 確認作業のみ |

#### ケース2: アンケート自由回答の分類（100件）

| | 手作業 | ChatGPT活用 |
|---|---|---|
| 所要時間 | 約1.5時間 | 約15分（分割送信2回＋確認） |
| 精度 | 分類者によるばらつき大 | 基準が一貫している |
| 作業者の負担 | 判断に迷う回答で時間消費 | 迷う回答だけ確認すればよい |

#### ケース3: 2つのリストの名寄せ（各50件）

| | 手作業 | ChatGPT活用 |
|---|---|---|
| 所要時間 | 約1時間 | 約10分 |
| 精度 | 表記揺れの見落としリスク | 表記揺れも検出可能 |
| 作業者の負担 | 2つのリストを見比べる苦行 | 候補リストの確認のみ |

**合計すると、3つのケースだけで約4.5時間が約45分に短縮されます。** 浮いた時間で、データの分析や報告書の作成など、より価値の高い仕事に取り組めるようになります。

もちろん、これらは目安です。データの複雑さやプロンプトの精度によって結果は変わります。しかし「時間が半分以下になる」という感覚は、多くの事務職の方が実感できるはずです。

### 8-9. 「やってみよう」コーナー: サンプルデータで住所の表記揺れを統一してみよう

それでは、実際にChatGPTを使ってデータ整理を体験してみましょう。

#### 練習課題

以下の10件の住所データを、統一された形式に整理してください。

**サンプルデータ（練習用）**

```

2, 新宿区西新宿2-8-1

9, 愛知県名古屋市中村区名駅１丁目１番４号

#### ステップ1: プロンプトを組み立てよう

以下の要素を含むプロンプトを作ってみましょう。

- **ルール**: 都道府県を含める、数字は半角、区切りは半角ハイフン、スペース削除、漢数字→算用数字
- **データ**: 上の10件をそのまま貼り付け
- **出力形式**: 番号付きで正規化後の住所だけ返す

#### ステップ2: ChatGPTに送信しよう

組み立てたプロンプトとサンプルデータをChatGPTに送信してみましょう。

#### ステップ3: 結果を確認しよう

期待される出力は以下の通りです。

```

2, 東京都新宿区西新宿2-8-1
3, 東京都新宿区西新宿2-8-1

同じ住所の表記が、すべて統一されていることを確認できましたか？

#### チャレンジ課題

余裕がある方は、次の追加指示をプロンプトに加えてみてください。

- 「正規化前と正規化後を並べて表形式で出力してください」

- 「都道府県ごとにグループ分けして出力してください」

指示を追加するだけで、出力の形式や内容が柔軟に変わることを体感できるはずです。

### 8-10. 章末まとめ

この章では、事務職の定番作業である「データ整理・分類」をChatGPTに手伝ってもらう方法を学びました。

#### 押さえておきたいポイント

1. **基本の3ステップ**: ルールを伝える → データを渡す → 出力形式を指定する
2. **5つの活用シーン**:
   - 住所データの正規化（表記揺れの統一）
   - 名前リストの整理（姓名分割、フリガナ付与）
   - カテゴリ分類（アンケート自由回答の分類）
   - CSVデータの加工・変換
   - 重複データの検出
3. **データの渡し方**: 表形式、CSV、タブ区切りのいずれか。ヘッダー行は必ず付ける
4. **大量データは分割**: 50行程度ずつ分けて送る。行番号を振っておく
5. **Excelへの貼り付け**: CSV保存→Excel読み込み、またはタブ区切り→直接貼り付け
6. **個人情報に注意**: 外部AIに個人情報を送る前に、社内ルールを必ず確認する
7. **出力は必ず確認**: ChatGPTの結果は「下書き」。最終チェックは人間の目で行う
