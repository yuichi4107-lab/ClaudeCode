## 第6章 Excel数式の相談相手 ― VLOOKUPもIF関数も怖くない

### 「あの関数、なんだっけ？」を繰り返す毎日

Excelで作業をしていると、こんな場面に何度も出くわしませんか。

- 「別のシートにある商品名を引っ張ってきたいんだけど、あの関数なんだっけ……」
- 「条件に合うデータだけ合計したい。SUMIFだっけ、SUMIFSだっけ？」
- 「IF関数を3つ重ねたいけど、カッコの閉じ方がわからない……」

そのたびにGoogle検索をして、解説サイトを3つ4つ開いて、自分のケースに当てはまる書き方を探して――気がつけば30分が過ぎている。そんな経験、きっと一度や二度ではないはずです。

この「検索→読解→応用」にかかる時間こそ、ChatGPTが劇的に短縮してくれる領域です。ChatGPTに自分の状況を伝えれば、ほんの数秒でぴったりの数式を返してくれます。しかも「なぜその関数を使うのか」まで解説付きです。

この章では、事務職の方がExcel作業で遭遇しやすい場面を取り上げ、ChatGPTに相談するときの具体的なプロンプトと、返ってきた回答をExcelに適用する手順をセットでご紹介します。読み終わるころには、「Excel関数の悩みはまずChatGPTに聞く」が当たり前の習慣になっているはずです。

---

### ChatGPTにExcel数式を聞く基本パターン

ChatGPTにExcelの数式を聞くとき、覚えておきたいのはたった1つのフォーマットです。

```
Excelで【やりたいこと】をしたいです。
データは以下のような構成です。
- 【列や範囲の説明】
- 【条件やルールの説明】
数式を教えてください。
```

ポイントは3つあります。

1. **「やりたいこと」を自分の言葉で書く** ― 関数名を知らなくてもOKです。「別のシートから名前を持ってきたい」「条件に合う行だけ数えたい」のように、日本語で書けば十分です。
2. **データの構成を伝える** ― 「A列に商品コード、B列に商品名が入っています」のように、どの列に何があるかを書きましょう。
3. **条件やルールを明記する** ― 「商品コードが一致するもの」「金額が10,000円以上のもの」など、絞り込みの条件があれば添えてください。

この3点を押さえるだけで、ChatGPTはかなり正確な数式を返してくれます。それでは具体的なシーン別に見ていきましょう。

### シーン1: VLOOKUP/XLOOKUPの使い方を教えてもらう

#### よくある困りごと

「受注リスト」のシートに商品コードだけ入っていて、「商品マスタ」のシートから商品名と単価を引っ張ってきたい。VLOOKUPという関数を使うらしいが、引数の意味がよくわからない――。

#### プロンプト例

```
Excelで、Sheet1のA列に商品コード（A2から下に入力）があります。
Sheet2には、A列に商品コード、B列に商品名、C列に単価が入った商品マスタがあります。
Sheet1のB列に、商品コードをキーにしてSheet2から商品名を取得したいです。
VLOOKUP関数での書き方を教えてください。
初心者向けに、引数の意味も1つずつ説明してください。
```

#### ChatGPTの回答例

> Sheet1のB2セルに以下の数式を入力してください。
>
> ```
> =VLOOKUP(A2,Sheet2!A:C,2,FALSE)
> ```
>
> **引数の意味：**
> | 引数 | 値 | 意味 |
> |------|------|------|
> | 検索値 | A2 | 検索したい商品コード（Sheet1のA2セル） |
> | 範囲 | Sheet2!A:C | 検索対象の表（Sheet2のA列～C列全体） |
> | 列番号 | 2 | 範囲の中で左から何列目を返すか（B列＝2列目＝商品名） |
> | 検索の型 | FALSE | 完全一致で検索する |
>
> 単価も取得したい場合は、Sheet1のC2セルに以下を入力してください。
>
> ```
> =VLOOKUP(A2,Sheet2!A:C,3,FALSE)
> ```
>
> 列番号を「3」に変えるだけで、C列（単価）を取得できます。

#### Excelでの適用手順

1. Sheet1のB2セルをクリックします。
2. 上の数式バーに `=VLOOKUP(A2,Sheet2!A:C,2,FALSE)` を貼り付けます。
3. Enterキーを押すと、A2の商品コードに対応する商品名が表示されます。
4. B2セルの右下にカーソルを合わせ、小さな「＋」マーク（フィルハンドル）が出たら下にドラッグしてコピーします。

#### XLOOKUPを使いたい場合

Microsoft 365やExcel 2021以降をお使いなら、より新しいXLOOKUP関数も使えます。以下のプロンプトで聞いてみましょう。

```
先ほどのVLOOKUPと同じことを、XLOOKUP関数で書き直してください。
VLOOKUPとの違いも簡単に教えてください。
```

ChatGPTは次のような数式を返してくれます。

> ```
> =XLOOKUP(A2,Sheet2!A:A,Sheet2!B:B,"該当なし")
> ```
>
> **VLOOKUPとの違い：**
> - 列番号を数える必要がない（返したい列を直接指定できる）
> - 検索列が左端でなくてもOK
> - 見つからなかったときの表示を指定できる（上の例では「該当なし」）

### シーン2: IF関数のネスト（入れ子）を作ってもらう

#### よくある困りごと

テストの点数に応じて「A」「B」「C」「D」の評価を自動で出したい。IF関数を重ねればできるらしいけど、カッコだらけになって途中で混乱する――。

#### プロンプト例

```
ExcelのIF関数で、セルB2の点数に応じて評価を表示したいです。
- 90点以上 → "A"
- 70点以上 → "B"
- 50点以上 → "C"
- 50点未満 → "D"
ネスト（入れ子）のIF関数を作ってください。
数式の読み方も教えてください。
```

#### ChatGPTの回答例

> C2セルに以下の数式を入力してください。
>
> ```
> =IF(B2>=90,"A",IF(B2>=70,"B",IF(B2>=50,"C","D")))
> ```
>
> **数式の読み方（内側から順に）：**
> 1. まずB2が90以上か確認 → 「A」
> 2. 90未満なら、70以上か確認 → 「B」
> 3. 70未満なら、50以上か確認 → 「C」
> 4. どれにも当てはまらなければ → 「D」
>
> カッコの数は、IFの数と同じ3つです。最後にまとめて「)))」と閉じます。

#### Excelでの適用手順

1. C2セルに数式を貼り付けます。
2. Enterキーを押して結果を確認します（例: B2が85なら「B」と表示されます）。
3. C2セルを下方向にコピーして、全員分の評価を一括で出します。

#### さらにIFS関数が使える場合

Microsoft 365やExcel 2019以降なら、IFS関数を使うとネストが不要になります。

```
同じ条件をIFS関数で書き直してください。
```

> ```
> =IFS(B2>=90,"A",B2>=70,"B",B2>=50,"C",TRUE,"D")
> ```
>
> IFS関数はIF関数のネストが不要で、条件と結果のペアを左から順に並べるだけです。最後の `TRUE,"D"` は「どの条件にも当てはまらない場合」を意味します。

### シーン3: SUMIFS/COUNTIFSの条件指定

#### よくある困りごと

売上データから「東京支店」の「4月分」だけを合計したい。SUMIFは1条件だけらしいし、SUMIFSの書き方がわからない――。

#### プロンプト例

```
Excelの売上データが以下の構成です。
- A列: 日付（例: 2025/4/1）
- B列: 支店名（例: 東京、大阪、名古屋）
- C列: 売上金額

このデータから「東京」の「2025年4月」の売上合計を求める数式を教えてください。
```

#### ChatGPTの回答例

> 以下のSUMIFS関数を使います。
>
> ```
> =SUMIFS(C:C,B:B,"東京",A:A,">="&DATE(2025,4,1),A:A,"<"&DATE(2025,5,1))
> ```
>
> **引数の意味：**
> | 引数 | 意味 |
> |------|------|
> | C:C | 合計する範囲（売上金額） |
> | B:B,"東京" | 条件1：支店名が「東京」 |
> | A:A,">="&DATE(2025,4,1) | 条件2：日付が2025/4/1以降 |
> | A:A,"<"&DATE(2025,5,1) | 条件3：日付が2025/5/1より前 |
>
> これで「東京支店の2025年4月分」の売上合計が求められます。

#### 件数を数えたい場合

同じ条件で「何件あるか」を知りたいときは、こう聞きましょう。

```
同じ条件で、件数を数えるCOUNTIFS関数も教えてください。
```

> ```
> =COUNTIFS(B:B,"東京",A:A,">="&DATE(2025,4,1),A:A,"<"&DATE(2025,5,1))
> ```
>
> SUMIFSの「合計する範囲」がなくなっただけで、条件部分はまったく同じです。

#### Excelでの適用手順

1. 集計結果を表示したいセル（例: E2）に数式を貼り付けます。
2. Enterキーを押すと、条件に合致する売上の合計金額が表示されます。
3. 月を変えたい場合は、DATE関数の中の数字を書き換えるだけです。

### シーン4: 日付計算（営業日計算、月末日など）

#### よくある困りごと

「納品日から5営業日後の支払期限を自動で出したい」「月末日を求めたい」など、日付がらみの計算は意外と難しいものです。

#### プロンプト例①：営業日計算

```
ExcelでA2セルに納品日が入っています。
この日から5営業日後の日付を求める数式を教えてください。
土日を除いた営業日で計算したいです。
```

#### ChatGPTの回答例

> ```
> =WORKDAY(A2,5)
> ```
>
> WORKDAY関数は、指定した日付から土日を除いた営業日数分だけ先の日付を返します。
>
> **祝日も除きたい場合：**
> 祝日リストをSheet2のA列に入力しておき、以下のように第3引数で指定します。
>
> ```
> =WORKDAY(A2,5,Sheet2!A:A)
> ```

#### プロンプト例②：月末日

```
ExcelでA2セルに日付（例: 2025/4/15）が入っています。
その月の月末日を求める数式を教えてください。
```

#### ChatGPTの回答例

> ```
> =EOMONTH(A2,0)
> ```
>
> EOMONTH関数の第2引数は「何ヶ月後の月末か」です。
> - 0 → 当月の月末
> - 1 → 翌月の月末
> - -1 → 前月の月末

#### プロンプト例③：経過月数

```
ExcelでA2に入社日、B2に今日の日付が入っています。
入社からの経過月数（切り捨て）を求める数式を教えてください。
```

#### ChatGPTの回答例

> ```
> =DATEDIF(A2,B2,"M")
> ```
>
> DATEDIF関数の第3引数を変えると、年数("Y")、日数("D")も求められます。
>
> ※ DATEDIF関数はExcelのヘルプに載っていない「隠し関数」ですが、正常に動作します。

#### Excelでの適用手順

1. 結果を表示したいセルに数式を貼り付けます。
2. 結果が数値（シリアル値）で表示された場合は、セルの書式設定で「日付」を選んでください。
3. 右クリック → 「セルの書式設定」→「日付」→ 好みの表示形式を選択 → OK。

### シーン5: 文字列操作（結合、分割、置換）

#### よくある困りごと

「姓」と「名」が別々のセルに入っているのを1つにまとめたい、住所から都道府県だけ抜き出したい、全角カナを半角にしたい――。文字列の操作は関数の種類が多くて覚えきれません。

#### プロンプト例①：文字列の結合

```
ExcelでA2に姓（例: 田中）、B2に名（例: 太郎）が入っています。
C2に「田中 太郎」のように姓と名をスペースで区切って結合したいです。
数式を教えてください。
```

#### ChatGPTの回答例

> 方法は2つあります。
>
> **方法1：&演算子を使う**
> ```
> =A2&" "&B2
> ```
>
> **方法2：CONCAT関数を使う（Excel 2019以降）**
> ```
> =CONCAT(A2," ",B2)
> ```
>
> どちらも結果は「田中 太郎」になります。シンプルな結合なら方法1が手軽です。

#### プロンプト例②：文字列の分割

```
ExcelのA2セルに「東京都千代田区丸の内1-1-1」のような住所が入っています。
先頭の都道府県名（例: 東京都）だけを取り出す数式を教えてください。
「都」「道」「府」「県」のいずれかで区切りたいです。
```

#### ChatGPTの回答例

> 都道府県名の文字数は2～4文字で、以下の数式で対応できます。
>
> ```
> =IF(MID(A2,3,1)="県",LEFT(A2,3),IF(MID(A2,3,1)="都",LEFT(A2,3),IF(MID(A2,3,1)="府",LEFT(A2,3),IF(MID(A2,4,1)="県",LEFT(A2,4),LEFT(A2,3)))))
> ```
>
> ただし、この数式は複雑なので、もっとシンプルにしたい場合は都道府県リストを別シートに用意してVLOOKUPで照合する方法もあります。ご希望であればそちらもご案内します。

このように、ChatGPTは代替案まで提示してくれます。「もっとシンプルにしたい」と追加で聞けば、別のアプローチも教えてもらえます。

#### プロンプト例③：文字列の置換

```
ExcelのA列に電話番号が「03-1234-5678」の形式で入っています。
ハイフンを除去して「0312345678」にする数式を教えてください。
```

#### ChatGPTの回答例

> ```
> =SUBSTITUTE(A2,"-","")
> ```
>
> SUBSTITUTE関数は、指定した文字を別の文字に置き換えます。
> 第3引数を「""」（空文字）にすることで、ハイフンを削除できます。

#### Excelでの適用手順

1. 結果を表示したいセルに数式を貼り付けます。
2. 数式が正しく動いたら、セルの右下をドラッグして下方向にコピーします。
3. 元のデータが不要になった場合は、結果の列をコピー → 「値として貼り付け」をして数式を確定させましょう。

### データの状況を説明して最適な関数を提案してもらう

ここまでは「VLOOKUPで」「IF関数で」と関数名を指定してChatGPTに聞くパターンでした。しかし実は、**関数名を知らなくてもまったく問題ありません**。自分のデータの状況と「やりたいこと」を伝えるだけで、ChatGPTが最適な関数を選んでくれます。

#### プロンプト例

```
Excelで以下のようなデータがあります。

【データの構成】
- A列: 社員番号（例: E001）
- B列: 氏名（例: 田中太郎）
- C列: 部署（例: 営業部）
- D列: 入社日（例: 2020/4/1）
- E列: 月間売上（例: 500000）

【やりたいこと】
1. 営業部の社員だけの月間売上の平均を求めたい
2. 入社3年以上の社員が何人いるか数えたい
3. 月間売上が最も高い社員の氏名を表示したい

それぞれの数式を教えてください。
```

#### ChatGPTの回答例

> **1. 営業部の月間売上の平均**
> ```
> =AVERAGEIF(C:C,"営業部",E:E)
> ```
> AVERAGEIF関数は、条件に合うデータだけの平均を求めます。
>
> **2. 入社3年以上の社員数**
> ```
> =COUNTIF(D:D,"<="&DATE(YEAR(TODAY())-3,MONTH(TODAY()),DAY(TODAY())))
> ```
> 今日の日付から3年前の日付を計算し、それ以前に入社した社員を数えます。
>
> **3. 月間売上が最も高い社員の氏名**
> ```
> =INDEX(B:B,MATCH(MAX(E:E),E:E,0))
> ```
> MAX関数で最大値を求め、MATCH関数でその行番号を特定し、INDEX関数で氏名を返します。

このように、「やりたいこと」を日本語で伝えるだけで、自分では思いつかなかった関数の組み合わせを教えてもらえます。これがChatGPTをExcelの相談相手として使う最大のメリットです。

### エラーの原因を聞く方法

Excelの数式を入力した結果、`#N/A`や`#VALUE!`などのエラーが表示されて困った経験はありませんか。エラーの意味をネットで調べても、原因の特定に時間がかかることが少なくありません。ChatGPTなら、エラーの状況を伝えるだけで原因と対処法を教えてくれます。

#### プロンプト例①：#N/Aエラー

```
ExcelでVLOOKUP関数を使っています。
数式: =VLOOKUP(A2,Sheet2!A:C,2,FALSE)
一部のセルで #N/A エラーが出ます。
考えられる原因と対処法を教えてください。
```

#### ChatGPTの回答例

> `#N/A`エラーは「検索値が見つからない」ときに発生します。主な原因は以下の通りです。
>
> **原因1：データの前後にスペースがある**
> - A2の商品コードやSheet2のコードに余分なスペースが含まれている場合があります。
> - 対処法：`=VLOOKUP(TRIM(A2),Sheet2!A:C,2,FALSE)` のようにTRIM関数で空白を除去します。
>
> **原因2：データ型が違う（文字列 vs 数値）**
> - A2が数値でSheet2が文字列（またはその逆）の場合、一致しません。
> - 対処法：`=VLOOKUP(TEXT(A2,"0"),Sheet2!A:C,2,FALSE)` のようにTEXT関数で揃えます。
>
> **原因3：本当にデータが存在しない**
> - Sheet2に該当するコードがない場合です。
> - 対処法：IFERROR関数でエラー時の表示を指定します。
> ```
> =IFERROR(VLOOKUP(A2,Sheet2!A:C,2,FALSE),"該当なし")
> ```

#### プロンプト例②：#VALUE!エラー

```
ExcelでSUMIFS関数を使っています。
数式: =SUMIFS(D:D,A:A,">="&"2025/4/1")
#VALUE! エラーが出ます。原因を教えてください。
```

#### ChatGPTの回答例

> 日付を文字列として直接指定しているのが原因です。Excelは日付の比較にシリアル値を使うため、DATE関数で指定してください。
>
> **修正後：**
> ```
> =SUMIFS(D:D,A:A,">="&DATE(2025,4,1))
> ```

#### エラー対処のコツ

ChatGPTにエラーを相談するときは、以下の情報を含めると的確な回答が得やすくなります。

1. **使っている数式の全文** ― 数式バーに表示されているものをそのままコピーして貼り付ける
2. **エラーの種類** ― `#N/A`、`#VALUE!`、`#REF!`、`#NAME?`、`#DIV/0!` など
3. **どのセルで発生するか** ― 「すべてのセルでエラー」か「一部のセルだけ」か
4. **データの具体例** ― 可能であれば、エラーが出るセルの値とエラーが出ないセルの値を1つずつ伝える

### ピボットテーブルの作り方を教えてもらう

ピボットテーブルは数式ではありませんが、Excelで集計を行う強力な機能です。「名前は聞いたことがあるけど使ったことがない」という方も、ChatGPTに手順を聞けば簡単に始められます。

#### プロンプト例

```
Excelでピボットテーブルを作りたいです。初めて使います。

データの構成：
- A列: 日付
- B列: 支店名（東京、大阪、名古屋）
- C列: 商品カテゴリ（食品、飲料、日用品）
- D列: 売上金額
データは2行目から100行目まであります。

支店別・カテゴリ別の売上合計を見たいです。
操作手順をステップバイステップで教えてください。
```

#### ChatGPTの回答例

> **ピボットテーブルの作成手順：**
>
> 1. データ範囲（A1:D100）内の任意のセルをクリックします
> 2. メニューの「挿入」タブ →「ピボットテーブル」をクリックします
> 3. 「テーブルまたは範囲を選択」が選ばれていることを確認し、範囲がA1:D100になっていることを確認 → OK
> 4. 新しいシートにピボットテーブルの枠が表示されます
> 5. 右側の「ピボットテーブルのフィールド」で以下のようにドラッグします
>    - 「支店名」→「行」エリアにドラッグ
>    - 「商品カテゴリ」→「列」エリアにドラッグ
>    - 「売上金額」→「値」エリアにドラッグ
> 6. 自動的に支店別×カテゴリ別の売上合計が表示されます
>
> **ヒント：**
> - 「値」エリアの集計方法は、デフォルトで「合計」になっています
> - 平均に変えたい場合は、値エリアの「合計/売上金額」をクリック →「値フィールドの設定」→「平均」を選択

このように、操作手順を1ステップずつ教えてもらえるので、初めてでも迷わず進められます。途中でわからなくなったら「ステップ4まで進みましたが、右側にフィールド一覧が表示されません」のように状況を伝えて追加質問しましょう。

### 「こういうことがしたい」→ 関数を教えてもらう逆引きアプローチ

ChatGPTが最も力を発揮するのは、この「逆引き」のアプローチです。事務の現場では「こういう結果がほしい」はわかるけれど、「どの関数を使えばいいか」がわからないことがほとんどです。

#### 逆引きプロンプトのテンプレート

```
Excelで以下のことをしたいです。関数名がわからないので教えてください。

【現在のデータの状態】
（どの列に何が入っているか）

【ほしい結果】
（こういう値が表示されてほしい、という具体例）

【補足・条件】
（あれば記載）
```

#### 実践例①：重複チェック

```
Excelで以下のことをしたいです。関数名がわからないので教えてください。

【現在のデータの状態】
A列に注文番号が500行分入っています。

【ほしい結果】
B列に、その注文番号が重複しているかどうかを「重複あり」「OK」で表示したい。

【補足・条件】
同じ注文番号が2回以上出てきたら「重複あり」と表示したいです。
```

#### ChatGPTの回答例

> B2セルに以下の数式を入力し、下方向にコピーしてください。
>
> ```
> =IF(COUNTIF(A:A,A2)>1,"重複あり","OK")
> ```
>
> **仕組み：**
> - COUNTIF(A:A,A2) → A列全体の中でA2と同じ値が何個あるか数える
> - 2個以上あれば「重複あり」、1個（自分自身だけ）なら「OK」

#### 実践例②：条件付きで最新の日付を取得

```
Excelで以下のことをしたいです。

【現在のデータの状態】
- A列: 顧客名
- B列: 注文日

同じ顧客名が複数行にあります。

【ほしい結果】
「田中商事」の最新の注文日を1つのセルに表示したい。
```

#### ChatGPTの回答例

> ```
> =MAXIFS(B:B,A:A,"田中商事")
> ```
>
> MAXIFS関数は、条件に合うデータの中から最大値を返します。日付はExcel内部では数値なので、最大値＝最新日付になります。
>
> ※ 結果が数値で表示された場合は、セルの書式を「日付」に変更してください。

#### 実践例③：名簿をフリガナ順に並べ替えるための補助列

```
Excelで以下のことをしたいです。

【現在のデータの状態】
A列に漢字の氏名が入っています（例: 田中太郎）。
入力時にフリガナ情報が入っています。

【ほしい結果】
B列にフリガナを自動で取り出したい。
```

#### ChatGPTの回答例

> ```
> =PHONETIC(A2)
> ```
>
> PHONETIC関数は、セルに入力されたときのフリガナ情報を取り出します。
>
> **注意：** コピー＆ペーストで入力されたデータにはフリガナ情報がないため、この関数では取得できません。その場合は手入力が必要です。

### 数式相談の注意点

ChatGPTにExcelの数式を教えてもらうとき、以下の点に気をつけましょう。

#### 1. セル番地は自分の環境に合わせる

ChatGPTが返す数式の中のセル番地（A2、B:Bなど）は、あくまで回答例です。自分のExcelファイルでデータが入っている列や行が違う場合は、適宜書き換えてください。

**対策：** プロンプトの中で「A列に〇〇、B列に〇〇が入っている」と自分のファイルの構成を伝えれば、そのまま使える数式が返ってきます。

#### 2. 動作確認は必ず行う

ChatGPTの数式は非常に正確ですが、100%ではありません。特に以下のケースでは結果をよく確認しましょう。

- データに空白セルが混在している場合
- 数値と文字列が混在している場合
- 日付の書式が統一されていない場合

**対策：** 数式を入力したら、まず結果が正しいとわかっているデータで検算してください。手計算で「この行は500円のはず」とわかっている行の結果を確認するだけで十分です。

#### 3. Excel のバージョンに注意

XLOOKUP、IFS、MAXIFS、CONCAなどの新しい関数は、Excel 2019以降やMicrosoft 365でしか使えません。古いバージョンを使っている場合は、プロンプトにバージョンを書き添えましょう。

```
Excel 2016を使っています。XLOOKUP関数は使えないので、
使える関数だけで数式を教えてください。
```

#### 4. 機密データは送らない

数式の相談自体には個人情報は不要です。「A列に社員番号、B列に氏名」のように列の内容を伝えるだけで十分で、実際のデータを貼り付ける必要はありません。前の章でも触れましたが、社外秘のデータや個人情報は入力しないように気をつけましょう。

### 「やってみよう」コーナー: 手元のExcelファイルの困りごとを相談してみよう

ここまで読んで「なるほど、便利そうだ」と思っていただけたら、ぜひ今すぐ試してみましょう。以下のステップで実践できます。

#### ステップ1: 困っているExcelファイルを1つ開く

今まさに作業中のファイルでも、「あとでやろう」と後回しにしていたファイルでも構いません。

#### ステップ2: 困りごとを言葉にする

「何をしたいのか」を日本語で書いてみてください。例えば：

- 「A列の商品名とB列の個数から、C列に単価を掛けた合計を出したい」
- 「重複しているデータに色を付けたい」
- 「入力された日付が土日なら『休日』と表示したい」

#### ステップ3: 以下のテンプレートに当てはめてChatGPTに質問する

```
Excelで【やりたいこと】をしたいです。

データの構成：
- A列: 【内容】
- B列: 【内容】
- C列: 【内容】

数式を教えてください。初心者向けに解説もお願いします。
```

#### ステップ4: 返ってきた数式をExcelに貼り付けて試す

数式バーに貼り付けてEnterキーを押すだけです。うまくいったら下方向にコピーしましょう。

#### ステップ5: うまくいかなかったらChatGPTに追加質問する

エラーが出たとき、期待と違う結果になったときは、その状況をそのまま伝えてください。

```
先ほどの数式を入力したら #VALUE! エラーが出ました。
A2セルには「2025/4/1」、B2セルには「東京」が入っています。
原因を教えてください。
```

ChatGPTは文脈を覚えているので、「先ほどの数式」と言うだけで通じます。まるで隣の席にいるExcelに詳しい同僚に相談するような感覚です。

**1つだけお願いがあります。** 最初は、答え合わせができる簡単な例で試してください。「この行の合計は100になるはず」のように手計算で確認できるケースから始めると、ChatGPTの回答を信頼できるかどうかを自分で判断する力がつきます。

### 章末まとめ

この章では、ChatGPTをExcel数式の相談相手として活用する方法を学びました。最後にポイントを振り返りましょう。

**基本の聞き方**
- 「やりたいこと」「データの構成」「条件」の3点を伝えるだけで、適切な数式が返ってくる
- 関数名を知らなくてもOK。日本語で「こういうことがしたい」と伝えれば十分

**シーン別の活用**
- VLOOKUP/XLOOKUP：別シートからデータを引っ張ってくる
- IF関数のネスト：条件分岐の数式を自動生成してもらう
- SUMIFS/COUNTIFS：複数条件の集計・件数カウント
- 日付計算：営業日計算、月末日、経過期間
- 文字列操作：結合、分割、置換

**応用テクニック**
- データの状況を伝えて最適な関数を「逆引き」で提案してもらう
- エラーが出たら、数式・エラーの種類・データの例をセットで質問する
- ピボットテーブルの操作手順もステップバイステップで教えてもらえる

**注意点**
- セル番地は自分のファイルに合わせて調整する
- 結果は必ず検算で確認する
- Excelのバージョンによって使えない関数がある
- 実際のデータ（個人情報や機密情報）はChatGPTに送らない

次の章では、Excelだけでなく、メール文面やビジネス文書の作成をChatGPTに手伝ってもらう方法を見ていきます。「書く」作業の時間短縮は、事務職の方にとって大きな武器になるはずです。
