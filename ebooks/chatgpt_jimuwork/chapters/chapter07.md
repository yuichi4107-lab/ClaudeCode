## 第7章 報告書・資料のたたき台作成 ― ゼロから書かなくていい

### 「白紙の恐怖」― ゼロから文章を書く辛さ

月曜の朝、パソコンを開いてWordの新規文書を立ち上げる。真っ白な画面にカーソルが点滅している――。

「さて、先月の月次報告書を書かなきゃ……」

そう思いながら、気がつけば10分、20分と時間が過ぎていく。何から書き始めればいいのか分からない。頭の中にはぼんやりとした内容があるのに、それを文章にする最初の一歩がどうしても踏み出せない。

この「白紙の恐怖」、事務職として働いている方なら一度は経験があるのではないでしょうか。

報告書、提案書、マニュアル、企画書――。事務職の仕事には、意外と「文書を作る」場面が多くあります。しかし、多くの方は「文章を書くプロ」として採用されたわけではありません。データ入力や経理処理、電話対応といった業務がメインなのに、いつの間にか「あの資料、作っておいて」と頼まれる。

実は、文書作成で最も大変なのは「ゼロから書き始める」瞬間です。一度書き始めてしまえば筆が乗ることもありますが、最初の一行が出てこない。構成をどうしよう、言い回しはこれでいいのか、必要な項目を漏らしていないか――考えることが多すぎて、手が止まってしまいます。

ある調査によると、ビジネスパーソンが資料作成にかける時間のうち、約3割は「何を書くか考える時間」、つまり実際にキーボードを叩く前の時間だと言われています。

ここでChatGPTの出番です。ChatGPTは「ゼロから書く」という最も辛い部分を代わりにやってくれます。完璧な完成品を作ってくれるわけではありませんが、「たたき台」――つまり、あなたが手を加えるための素材を素早く用意してくれるのです。

たたき台があれば、あとは「ここを直そう」「この数字を入れ替えよう」「この表現はもう少し柔らかくしよう」と修正していくだけ。ゼロから書くのと、既にある文章を直すのとでは、心理的な負担がまるで違います。

この章では、事務職の皆さんが日常的に作成する文書について、ChatGPTに「たたき台」を作ってもらうテクニックを、具体的なプロンプト例と出力例とともに紹介していきます。


### ChatGPTにたたき台を作ってもらう基本パターン

たたき台を作ってもらうとき、押さえておきたい基本のパターンがあります。以下の「5つの要素」をプロンプトに含めると、精度の高いたたき台が出てきます。

**たたき台プロンプトの5要素**

1. **文書の種類**: 何を作りたいのか（報告書、提案書、マニュアルなど）
2. **目的・読み手**: 誰に向けて、何のために書くのか
3. **盛り込みたい内容**: キーワードやトピックを箇条書きで
4. **分量・形式の指定**: 文字数、見出し構造、箇条書きの有無など
5. **トーン・文体**: かしこまった文体か、カジュアルか

この5要素を意識するだけで、「なんか違う……」という出力が大幅に減ります。

**基本のプロンプトテンプレート**

```
以下の条件で【文書の種類】のたたき台を作成してください。

■目的: 【何のために書くか】
■読み手: 【誰が読むか】
■盛り込みたい内容:
- 【項目1】
- 【項目2】
- 【項目3】
■形式: 【見出し付き / 箇条書き中心 / A4で○枚程度 など】
■文体: 【です・ます調 / である調 / カジュアル など】
```

それでは、このテンプレートを使って、具体的なシーン別のプロンプトと出力例を見ていきましょう。


### シーン別プロンプト例と出力例

#### シーン1: 月次報告書のたたき台

月次報告書は毎月作成するものなので、一度プロンプトのパターンを作ってしまえば、あとは数字や内容を差し替えるだけで使い回せます。

**プロンプト例**

```
以下の条件で月次報告書のたたき台を作成してください。

■目的: 総務部の2025年4月の業務実績を部長に報告する
■読み手: 総務部長
■盛り込みたい内容:
- 備品管理: 発注件数42件、コスト前月比5%削減
- 社内イベント: 新入社員歓迎会を4/10に実施、参加率85%
- 設備メンテナンス: 空調点検完了、照明LED化を3フロア完了
- 来月の予定: 防災訓練（5/15）、オフィスレイアウト変更（5月下旬）
- 課題: 備品発注システムの老朽化、更新検討が必要
■形式: 見出し付き、A4で2枚程度
■文体: です・ます調、ビジネス文書として適切なトーン
```

**ChatGPTの出力例**

```

2025年4月度

1. 業務実績サマリー
2025年4月度における総務部の主要業務について、以下のとおり
ご報告いたします。

2. 備品管理業務
4月の備品発注件数は42件でした。コスト管理の徹底により、
発注コストは前月比5%の削減を達成しております。引き続き、
適正在庫の維持とコスト最適化に努めてまいります。

3. 社内イベント運営
4月10日に新入社員歓迎会を開催いたしました。参加率は85%と
高い水準を記録し、新入社員と既存社員の交流促進に寄与
しました。参加者アンケートでは概ね好評をいただいております。

4. 設備メンテナンス
（1）空調設備の定期点検を計画どおり完了いたしました。
   異常箇所はなく、良好な状態を維持しております。
（2）照明LED化工事について、3フロア分の施工が完了しました。
   省エネ効果の測定は次月以降に実施予定です。

5. 来月の主要予定
・5月15日: 全社防災訓練の実施
・5月下旬: 3階オフィスのレイアウト変更工事

6. 課題と今後の対応
現在使用している備品発注システムの老朽化が顕著になって
きております。操作性の低下やデータ処理速度の遅延が
見られるため、システム更新の検討を開始したいと考えております。
次月の報告にて、更新に向けた調査結果をご報告する予定です。

```

このまま提出できるレベルではありませんが、「構成」と「文章の骨格」はしっかりしています。あとは実際の数字を再確認し、部長が気にしそうなポイントを加筆すれば完成です。


#### シーン2: 業務改善提案書

「こうしたら良くなるのに」というアイデアはあっても、それを提案書の形にまとめるのは意外と大変です。ChatGPTに骨格を作ってもらいましょう。

**プロンプト例**

```
以下の条件で業務改善提案書のたたき台を作成してください。

■目的: 紙の経費精算を廃止し、クラウド型経費精算システムを
  導入することを提案する
■読み手: 経理部長、管理本部長
■盛り込みたい内容:
- 現状の問題点: 紙の申請書の紛失、承認に平均3日かかる、
  月末に経理部に業務が集中
- 提案内容: クラウド型経費精算システム（例: マネーフォワード等）の導入
- 期待効果: 承認時間の短縮（3日→即日）、ペーパーレス化、
  経理部の月末残業削減（推定30%減）
- 概算コスト: 月額5万円程度（50名利用の場合）
- 導入スケジュール案: 3ヶ月（検討1ヶ月、設定1ヶ月、試行1ヶ月）
■形式: 見出し付き、A4で2〜3枚、図表は不要
■文体: です・ます調、説得力のあるトーン
```

**ChatGPTの出力例**

```

経費精算業務のデジタル化について

■提案日: 2025年○月○日
■提案者: ○○部 ○○

1. 提案の概要
現在、紙ベースで運用している経費精算業務について、クラウド型
経費精算システムの導入を提案いたします。本提案により、業務
効率の大幅な改善とコスト削減が見込まれます。

2. 現状の課題

（1）申請書の紛失リスク

（2）承認プロセスの長期化
  紙の申請書を物理的に回覧するため、申請から承認完了まで
  平均3営業日を要しています。出張や外出の多い承認者がいる
  場合、さらに日数がかかることもあります。

（3）月末の業務集中
  月末締めに合わせて申請が集中するため、経理部では毎月
  月末から翌月初にかけて長時間の残業が発生しています。

3. 提案内容
クラウド型経費精算システム（マネーフォワード クラウド経費等）を
導入し、申請・承認・集計の全工程をデジタル化することを
提案いたします。

主な機能:
・スマートフォンからのレシート撮影・申請
・オンラインでの承認（外出先からも対応可能）
・会計ソフトとの自動連携
・リアルタイムでの経費データ集計

4. 期待される効果
・承認期間の短縮: 平均3日 → 即日〜翌日
・ペーパーレス化: 年間約○○枚の紙を削減
・経理部の残業削減: 月末残業を推定30%削減
・申請書紛失の解消: データはクラウド上で管理

5. 概算コスト
・月額利用料: 約50,000円（50名利用、1名あたり1,000円/月）
・初期設定費用: 約100,000円（導入支援含む）
・年間コスト: 約700,000円

※現行の紙代・印刷代・保管コスト・残業代の削減分を考慮すると、
 実質的な負担増は最小限と見込まれます。

6. 導入スケジュール（案）
・第1月目: システム選定・比較検討、社内稟議
・第2月目: システム設定、マスタ登録、テスト
・第3月目: 一部部署での試行運用、全社展開準備

等が必要でしたら、別途ご用意いたします。

以上
```

提案書のように「相手を説得する」文書は、構成がとても重要です。ChatGPTは「課題→提案→効果→コスト→スケジュール」という説得力のある流れを自動的に組み立ててくれます。

#### シーン4: マニュアル・手順書の骨格

新しい業務の手順書を作るのは、特に時間がかかる作業です。ChatGPTに骨格を作ってもらい、そこに具体的な操作画面のスクリーンショットや注意点を追加していく方法が効率的です。

**プロンプト例**

```
以下の条件で業務マニュアルのたたき台を作成してください。

■目的: 新入社員向けの「来客対応マニュアル」を作成する
■読み手: 新入社員（社会人1年目）
■盛り込みたい内容:
- 来客があったときの基本的な流れ
- 受付での対応（挨拶、名前の確認、担当者への連絡）
- 会議室への案内
- お茶出しの手順
- 担当者不在時の対応
- 緊急・クレーム対応の場合のエスカレーション
■形式: 見出し付き、手順は番号付きリストで
■文体: です・ます調、新入社員が安心して読めるよう丁寧に
```

**ChatGPTの出力例**

```
来客対応マニュアル
― 新入社員向け ―

はじめに
このマニュアルは、来客対応の基本的な流れと注意点をまとめた
ものです。最初は緊張するかもしれませんが、このマニュアルに
沿って対応すれば大丈夫です。分からないことがあれば、遠慮なく
先輩社員に聞いてください。

1. 来客対応の全体の流れ
  ① 受付で来客をお迎えする
  ② 担当者に連絡する
  ③ 会議室にご案内する
  ④ お茶をお出しする
  ⑤ お見送りをする

2. 受付での対応
  2-1. お客様が来社されたら
  ① 立ち上がり、笑顔でお迎えします。
  ②「いらっしゃいませ。本日はどのようなご用件でしょうか」と
    お声がけします。
  ③ お客様の会社名とお名前を確認します。
    「恐れ入りますが、お名前とご所属をお伺いできますか」
  ④ アポイントの有無を確認します。
    「○○とのお約束でしょうか」

  2-2. 担当者への連絡
  ① 内線電話で担当者に連絡します。
    「○○株式会社の○○様がお見えです」
  ② 担当者が来るまでの間、お客様にお待ちいただきます。
    「ただいま担当の○○を呼んでまいります。
     少々お待ちいただけますでしょうか」

3. 会議室への案内
  ① 「ご案内いたします。こちらへどうぞ」とお声がけします。
  ② お客様の2〜3歩前を歩き、時折振り返りながら案内します。
  ③ 会議室のドアを開け、上座をお勧めします。
    「こちらにお掛けになってお待ちください」

4. お茶出しの手順
  ① 人数分のお茶を用意します（来客 + 自社の出席者分）。
  ② お盆に載せて会議室へ向かいます。
  ③ ノックして入室します。
  ④ お客様から先にお出しします（上座の方から順に）。
  ⑤ 「失礼いたします」と一礼して退室します。

  【ポイント】
  ・お茶は右側からお出しするのが基本です
  ・茶托はお盆の上でセットしてからお出しします

5. 担当者が不在の場合
  ① 「申し訳ございません。あいにく○○は席を外しております」
    とお伝えします。
  ② 以下のいずれかの対応をお客様にご確認します。
    ・お待ちいただく（所要時間の目安をお伝えする）
    ・伝言を承る
    ・折り返しのご連絡を差し上げる
  ③ お客様の連絡先を正確にメモし、担当者に伝えます。

6. 緊急時・クレーム対応
  お客様がお怒りの場合やクレームの場合は、以下の手順で対応
  してください。
  ① まずは落ち着いて、お客様のお話を最後まで傾聴します。
  ② 「ご迷惑をおかけして申し訳ございません」とお詫びします。
  ③ 自分で判断せず、速やかに上司または先輩に引き継ぎます。
    「担当の者に代わりますので、少々お待ちいただけますか」

  ※ 一人で抱え込まないでください。エスカレーションは
   「迷惑をかけること」ではなく「正しい対応」です。

おわりに
慣れないうちは戸惑うことも多いと思いますが、大切なのは
「丁寧に、誠実に対応すること」です。回数を重ねるうちに
自然とスムーズに対応できるようになります。
```

手順書は「番号付きリスト」で書いてもらうのがコツです。「箇条書きで」とだけ指定すると順序がぼやけますが、「手順は番号付きリストで」と指定することで、実際の動きに沿った分かりやすい手順書になります。


#### シーン5: 企画書のたたき台

社内の企画書も、構成を考えるのに時間がかかるものです。ChatGPTに骨格を作ってもらい、そこにアイデアを肉付けしていきましょう。

**プロンプト例**

```
以下の条件で企画書のたたき台を作成してください。

■目的: 社内コミュニケーション活性化のための
  「ランチシャッフル制度」を企画・提案する
■読み手: 人事部長、総務部長
■盛り込みたい内容:
- 背景: リモートワーク増加で部署間の交流が減っている
- 企画内容: 月1回、異なる部署のメンバー4〜5人で

```

```
お疲れ様です。○○です。
```

走り書きのメモが、きちんとした報告メールに変わりました。このテクニックは「メモ→報告書」「メモ→議事録」「メモ→社内通知」など、さまざまな場面で応用できます。

### 既存資料のリライト・ブラッシュアップ

たたき台を「ゼロから作る」だけでなく、「既にある文書を改善する」のもChatGPTの得意分野です。

**使い方1: 分かりにくい文章を分かりやすくする**

```
以下の文章を、ITに詳しくない社員にも分かりやすいように
書き直してください。専門用語は避けるか、使う場合は
カッコ内に説明を添えてください。

【元の文章】
本システムはSaaS型のクラウドサービスであり、オンプレミス環境
からのマイグレーションに際しては、API連携によるデータの
エクスポート/インポートが必要となります。SSO認証基盤との
統合については、別途SAML設定が必要です。
```

**ChatGPTの出力例**

```
【書き直し後】
この新しいシステムは、インターネット上で動くサービスです
（自社のサーバーにインストールする必要はありません）。

現在のシステムから新しいシステムへデータを移す作業が必要に
なります。データの移行は、システム同士を連携させる仕組みを
使って行います。

また、現在の社内ログインの仕組み（一度のログインで複数の
システムを使えるようにする仕組み）と連携させるには、
別途設定作業が必要です。
```

**使い方2: 堅すぎる文章をやわらかくする**

```
以下の社内通知文を、もう少しカジュアルで親しみやすいトーンに

個別に受診勧奨を行います。
```

**ChatGPTの出力例**

```
【書き直し後】
皆さんへ

今年度の健康診断のお知らせです！

以下の日程で健康診断を実施します。対象の方は必ず受けて

```

リライトは「元の文章をコピー＆ペーストして、どう直してほしいかを伝える」だけなので、とても簡単です。「もっと短くして」「箇条書きに変えて」「英語に翻訳して」なども自在にできます。


### 上司のフィードバックを反映して修正してもらう

資料を提出して上司から「ここを直して」と言われたとき、その修正作業もChatGPTに手伝ってもらえます。

**プロンプト例**

```
以下の報告書に対して、上司から下記のフィードバックをもらい
ました。フィードバックを反映した修正版を作成してください。

【元の報告書】
（ここに報告書の全文を貼り付ける）

【上司からのフィードバック】
1. 冒頭に「結論」を入れてほしい。何が言いたいのか
   最初に分かるように。
2. 数字のところ、前年比も入れて。
3. 「課題」のセクションが弱い。具体的なリスクと
   対策案も書いて。
4. 全体的にもう少し短くまとめて。冗長な表現を削って。
```

**ChatGPTの出力例のポイント**

ChatGPTは、上記4つの指示を的確に反映してくれます。

- 冒頭に「本報告の要旨」というセクションが追加される
- 数字に「（前年比○%増）」が補記される（※ただし架空の数字になるので自分で正確な値に差し替える必要があります）
- 課題セクションに「想定されるリスク」と「対策案」が追記される
- 全体的に冗長な表現が削られ、コンパクトになる

**やり取りを重ねるのがコツ**

一度で完璧にならなくても大丈夫です。「もう少し結論を強調して」「3つ目の対策案をもっと具体的に」と追加で指示すれば、どんどん修正してくれます。ChatGPTとの会話は「上司とのやり取りの予行練習」のようなものです。何回修正をお願いしても嫌な顔をしません。


### Word形式での出力指定（見出し構造、箇条書き等）

ChatGPTで作ったたたき台をWordに貼り付けるとき、ちょっとした工夫で作業効率がぐんと上がります。

### 注意点 ― たたき台を使うときに気をつけること

ChatGPTのたたき台はとても便利ですが、そのまま提出するのは危険です。以下の点に必ず注意してください。

**1. 数値・固有情報は必ず自分で確認する**

ChatGPTは「それっぽい数字」を入れてくることがあります。たとえば「売上前年比12%増」という数字が出力に含まれていても、それはChatGPTが推測で入れたものかもしれません。

実際の数字は、必ず社内の資料やシステムで確認してから記入してください。プロンプトに正確な数字を含めていた場合でも、出力で数字が変わっていないか再確認する習慣をつけましょう。

**2. 社名・人名・日付を確認する**

固有名詞も要注意です。プロンプトに入力した社名や人名が、出力で微妙に変わっていることがまれにあります。特に正式名称（「株式会社○○」と「○○株式会社」の違いなど）は注意深く確認してください。

**3. 社外秘の情報の取り扱い**

ChatGPTに入力した情報は、OpenAI社のサーバーに送信されます。社外秘の情報や個人情報を含む文書のたたき台を作るときは、会社のセキュリティポリシーを確認してください。

対策として、以下の方法があります。

- 具体的な数字や固有名詞を「○○」「XX」などのダミーに置き換えてからChatGPTに入力し、出力後に正しい情報を自分で入れる
- 会社がChatGPT Enterprise版やAzure OpenAI Serviceを導入している場合は、そちらを使う（入力データが学習に使われない設定になっています）
- ChatGPTの設定で「チャット履歴とトレーニング」をオフにする

**4. 著作権への意識**

ChatGPTの出力をそのまま外部に公開する文書（プレスリリース、Webサイトの記事など）に使う場合は、著作権の観点からも注意が必要です。社内文書であれば問題になるケースは少ないですが、公開文書の場合は自分の言葉で十分に書き直すようにしましょう。

**5. 「たたき台」であることを忘れない**

最も大切なのは、ChatGPTの出力はあくまで「たたき台」だということです。あなたの業務知識、会社の事情、読み手の性格――こうした「現場の文脈」は、ChatGPTには分かりません。

たたき台に「あなたならではの視点」を加えることで、初めて価値のある文書になります。ChatGPTは優秀なアシスタントですが、最終的な品質を担保するのは、あなた自身です。


### Before/After: 資料作成の時間とクオリティの変化

ChatGPTをたたき台作成に活用すると、具体的にどのくらい変わるのでしょうか。典型的なBefore/Afterを見てみましょう。

**月次報告書の場合**

| 項目 | Before（従来） | After（ChatGPT活用） |
|---|---|---|
| 構成を考える | 20分 | 2分（プロンプト入力） |
| 下書きを書く | 40分 | 5分（出力を確認） |
| 修正・仕上げ | 20分 | 25分 |
| **合計** | **80分** | **32分** |

所要時間が約60%削減されています。特に「構成を考える」「下書きを書く」の時間が劇的に短縮されるのが特徴です。

**業務改善提案書の場合**

| 項目 | Before（従来） | After（ChatGPT活用） |
|---|---|---|
| 構成を考える | 30分 | 3分 |
| 下書きを書く | 60分 | 5分 |
| 情報収集・確認 | 30分 | 30分 |
| 修正・仕上げ | 30分 | 30分 |
| **合計** | **150分** | **68分** |

提案書のように構成力が問われる文書では、時間削減の効果がさらに大きくなります。

**クオリティ面の変化**

時間だけでなく、クオリティ面でも変化があります。

- **構成の漏れが減る**: ChatGPTは一般的なビジネス文書の構成を網羅的に提案してくれるため、「あの項目を書き忘れた」というミスが減ります。
- **表現の幅が広がる**: 自分一人で書いていると表現がワンパターンになりがちですが、ChatGPTの出力をベースにすることで、新しい言い回しや構成を学べます。
- **心理的な負担が軽減する**: 「白紙からのスタート」がなくなるため、資料作成に対するストレスが大幅に減ります。「また報告書か……」が「サクッと作ろう」に変わります。


### 「やってみよう」コーナー: 来週の報告書のたたき台を作ってみよう

さあ、実際に手を動かしてみましょう。以下のステップで、来週提出する報告書（または直近で作成予定の文書）のたたき台を作ってみてください。

**ステップ1: 書く文書を決める**

来週提出する予定の文書を1つ選びましょう。月次報告書、議事録、提案書、マニュアル、何でもOKです。

**ステップ2: 情報を箇条書きで整理する**

その文書に盛り込みたい内容を、思いつくままに箇条書きで書き出してください。きれいにまとめる必要はありません。メモ書きレベルで大丈夫です。

**ステップ3: プロンプトを作る**

この章で紹介した「5要素テンプレート」に沿って、プロンプトを作りましょう。

```
以下の条件で【文書の種類】のたたき台を作成してください。

■目的:
■読み手:
■盛り込みたい内容:
-
-
-
■形式:
■文体:
```

**ステップ4: ChatGPTに送信する**

作ったプロンプトをChatGPTに送信してください。出力が返ってきたら、まずはざっと目を通しましょう。

**ステップ5: 修正して仕上げる**

出力されたたたき台をWordなどに貼り付けて、以下の点を修正・加筆してください。

- 数字は正確なものに置き換える
- 固有名詞（会社名、人名、部署名）を正しいものにする
- 自分の言葉で補足したい部分を加筆する
- 不要な部分は削除する
- 全体を通して読み、違和感のある箇所を修正する

**ステップ6: 振り返る**

完成したら、以下の点を振り返ってみましょう。

- ゼロから書いた場合と比べて、どのくらい時間が節約できましたか？
- たたき台があることで、心理的な負担は軽くなりましたか？
- 次回はプロンプトをどう改善すれば、もっと良いたたき台が出そうですか？

この「作って→直して→振り返る」のサイクルを繰り返すうちに、プロンプトの精度がどんどん上がり、修正にかかる時間もどんどん短くなっていきます。


### 章末まとめ

この章のポイントを振り返りましょう。

**1. ゼロから書かなくていい**

ChatGPTに「たたき台」を作ってもらえば、真っ白な画面と格闘する必要はありません。構成も文章もまずはChatGPTに任せて、あなたは「修正・加筆」に集中しましょう。

**2. 5要素をプロンプトに含める**

良いたたき台を得るために、プロンプトには以下の5つを含めましょう。
- 文書の種類
- 目的・読み手
- 盛り込みたい内容
- 分量・形式の指定
- トーン・文体

**3. さまざまな文書に応用できる**

月次報告書、業務改善提案書、プレゼン資料のアウトライン、マニュアル・手順書、企画書――事務職で作成するほぼすべての文書で、ChatGPTのたたき台作成が活用できます。

**4. 箇条書きメモから文章化できる**

走り書きのメモや箇条書きの情報をChatGPTに渡すだけで、読みやすいビジネス文書に変換してくれます。

**5. 既存資料のリライトもお手のもの**

「分かりにくい→分かりやすく」「堅い→やわらかく」「長い→短く」など、既存の文書の改善もChatGPTに依頼できます。

**6. 上司のフィードバック反映も効率的に**

フィードバックの内容をそのままChatGPTに伝えれば、修正版を作ってくれます。何度修正をお願いしても大丈夫です。

**7. 数値と固有情報は自分で確認**

ChatGPTの出力に含まれる数字、社名、人名、日付は必ず自分で確認してください。たたき台はあくまでたたき台です。最終チェックは人間の仕事です。

**8. セキュリティと著作権に配慮する**

社外秘の情報を入力する際は会社のポリシーを確認しましょう。ダミーデータに置き換えてから入力する方法も有効です。
