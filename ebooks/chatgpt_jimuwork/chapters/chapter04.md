## 第4章 メール作成・添削 ― もう文面で30分悩まない

### メール作成、実は「見えない残業」になっていませんか？

「この書き方で失礼にならないかな……」
「催促したいけど、角が立たない言い方ってどうすれば……」
「お詫びメール、何度書き直しても自信が持てない……」

事務職の皆さんなら、一度はこんな経験があるのではないでしょうか。

ある調査によると、ビジネスパーソンがメールの作成・確認に費やす時間は、1日あたり平均で約1時間〜1時間半と言われています。特に事務職は、社内外問わず多くの人とやり取りをする立場です。上司への報告、取引先へのお礼、他部署への依頼、ときにはクレーム対応のお詫びまで――メールの種類は多岐にわたります。

問題は、メールの「内容」を考える時間よりも、「書き方」に悩む時間のほうが長いということです。伝えたいことは頭の中にあるのに、それをどう文章にすればいいのかで手が止まってしまう。これは決して文章力がないからではありません。ビジネスメールには独特の「型」や「マナー」があり、それを毎回ゼロから組み立てようとすると、どうしても時間がかかるのです。

ここでChatGPTの出番です。

ChatGPTは、ビジネスメールの「型」を大量に学習しています。あなたが「誰に」「何を」「どんなトーンで」伝えたいかを指示するだけで、すぐに適切な文面を作成してくれます。あなたの仕事は、出来上がった文面をサッと確認して、必要に応じて微調整するだけ。これだけで、メール作成にかかる時間を大幅に短縮できます。

この章では、事務職の皆さんが日常的に書くメールのパターンごとに、ChatGPTへの具体的な指示の出し方（プロンプト）と、その出力例を紹介していきます。読み終わるころには、「メールで30分悩む」という習慣とはお別れできるはずです。


### ChatGPTにメールを書いてもらう基本パターン

まず、ChatGPTにメールを作成してもらうときの「基本の型」を押さえておきましょう。次の4つの要素を伝えるだけで、実用レベルのメールが出力されます。

**メール作成プロンプトの基本4要素:**

| 要素 | 説明 | 例 |
|------|------|-----|
| 誰に送るか | 相手の立場・関係性 | 取引先の担当者、社内の上司、他部署の同僚 |
| 何を伝えるか | メールの目的・用件 | 打ち合わせのお礼、資料送付の依頼 |
| どんなトーンか | 文体の丁寧さ | フォーマル、やや丁寧、カジュアル |
| 補足情報 | 具体的な固有名詞など | 日時、会社名、商品名 |

これを踏まえた「基本プロンプト」はこのような形になります。

```
以下の条件でビジネスメールを作成してください。

- 送信先: ○○（関係性）
- 目的: ○○
- トーン: ○○
- 補足: ○○

件名と本文の両方を書いてください。
```

たったこれだけです。特別なテクニックは必要ありません。では、ここからは具体的なシーン別に見ていきましょう。


### シーン1: お礼メール

事務職で最も頻繁に書くメールのひとつが、お礼メールです。打ち合わせの後、資料をいただいた後、来社いただいた後など、場面はさまざまです。

**プロンプト例:**

```
以下の条件でビジネスメールを作成してください。

- 送信先: 取引先（ABC商事）の田中様
- 目的: 本日の打ち合わせのお礼と、次回の打ち合わせ日程の確認
- トーン: 丁寧・フォーマル
- 補足: 本日14時に弊社で打ち合わせを行った。次回は来週水曜の15時で仮決定している。
  打ち合わせでは新商品の販売計画について話し合った。

件名と本文の両方を書いてください。
```

**出力例:**

```
件名: 本日のお打ち合わせのお礼（次回日程のご確認）

ABC商事
田中様

いつもお世話になっております。
株式会社○○の△△でございます。

本日はお忙しい中、弊社までお越しいただき
誠にありがとうございました。

新商品の販売計画について、貴重なご意見を
いただけましたこと、大変参考になりました。

さて、次回のお打ち合わせにつきまして、
来週水曜日（○月○日）15時にて
仮決定とさせていただいておりますが、
ご都合はいかがでしょうか。

問題ございませんようでしたら、
あらためて正式なご案内をお送りいたします。

今後ともどうぞよろしくお願いいたします。

――――――――――――――――
株式会社○○
△△（名前）
TEL: 000-0000-0000
Email: xxxxx@example.com
――――――――――――――――
```

このように、基本4要素を伝えるだけで、適切な敬語を使った自然なお礼メールが完成します。「○○」や「△△」の部分を自分の情報に置き換えるだけで、すぐに送信できるレベルです。

**ワンポイント:** 毎回自分の署名を入力するのが面倒な場合は、ChatGPTに最初に「私の署名は以下のとおりです」と伝えておくと、それ以降のメールに自動で署名を入れてくれます。


### シーン2: 依頼メール

他部署への資料作成の依頼や、取引先への見積もり依頼など、「お願いごと」を含むメールは書き方に気を使います。相手に快く引き受けてもらえるような文面をChatGPTに作ってもらいましょう。

**プロンプト例:**

```
以下の条件でビジネスメールを作成してください。

- 送信先: 社内の経理部・鈴木さん（同期で普段からやり取りがある）
- 目的: 来月の部門予算の実績データをExcelで共有してほしい
- トーン: 丁寧だけど堅すぎない（社内メール）
- 補足: 来週金曜の部門会議で使う資料に含めたい。
  できれば今週中にもらえると助かる。

件名と本文の両方を書いてください。
```

**出力例:**

```
件名: 【お願い】来月分の部門予算実績データの共有について

鈴木さん

お疲れさまです。営業部の△△です。

来週金曜日の部門会議で使用する資料を
準備しておりまして、来月分の部門予算の
実績データ（Excel形式）をいただけないでしょうか。

資料の作成スケジュールの関係で、
今週中にご共有いただけると大変助かります。

お忙しいところ恐れ入りますが、
よろしくお願いいたします。

△△
```

社内メールらしい、親しみのあるトーンでありながら、依頼内容と期限が明確に伝わる文面になっています。


### シーン3: お詫びメール

お詫びメールは最も書くのが難しいメールのひとつです。誠意を伝えながらも、事実関係を正確に説明し、再発防止策まで盛り込む必要があります。

**プロンプト例:**

```
以下の条件でビジネスメールを作成してください。

- 送信先: 取引先（株式会社山田製作所）の佐藤部長
- 目的: 納品物の数量間違いのお詫びと対応策の連絡
- トーン: 非常に丁寧・誠意を込めて
- 補足:
  - 3月15日に納品した部品A（型番: X-100）の数量が、
    発注の500個に対して450個しかなかった
  - 不足分50個は3月20日までに追加納品する予定
  - 原因は出荷時の検品ミス
  - 再発防止策としてダブルチェック体制を導入する

件名と本文の両方を書いてください。
```

**出力例:**

```
件名: 【お詫び】納品数量の不足について（部品A: X-100）

株式会社山田製作所
佐藤部長

平素より大変お世話になっております。
株式会社○○の△△でございます。

このたびは、3月15日にお届けいたしました
部品A（型番: X-100）につきまして、
ご発注いただいた500個に対し450個のお届けとなり、
50個の不足が生じましたこと、
心よりお詫び申し上げます。

佐藤部長をはじめ、貴社の皆さまに
多大なるご迷惑をおかけしましたことを
深くお詫び申し上げます。

■ 不足分の対応について
不足分の50個につきましては、
3月20日（水）までに追加納品させていただく
手配を進めております。
納品日時が確定しましたら、
あらためてご連絡いたします。

■ 原因と再発防止策について
今回の原因は、出荷時の検品作業における
確認ミスであると判明いたしました。
今後このようなことのないよう、
出荷前のダブルチェック体制を新たに導入し、
管理を徹底してまいります。

重ねてお詫び申し上げますとともに、
今後とも変わらぬお引き立てを賜りますよう
お願い申し上げます。

――――――――――――――――
株式会社○○
△△（名前）
TEL: 000-0000-0000
Email: xxxxx@example.com
――――――――――――――――
```

お詫びメールは、構成がとても重要です。ChatGPTは「お詫び → 事実説明 → 対応策 → 原因と再発防止 → 結び」という定番の流れを自動的に組み立ててくれます。自分で書くと「どこから書けばいいんだろう」と悩みがちですが、ChatGPTなら一瞬です。


### シーン4: 催促メール（角が立たない表現）

催促メールは、事務職にとって最も気を使うメールかもしれません。「早く返事がほしい」という気持ちを伝えながら、相手の気分を害さないようにする――この絶妙なバランスをChatGPTに任せてしまいましょう。

**プロンプト例:**

```
以下の条件でビジネスメールを作成してください。

- 送信先: 取引先（株式会社グリーンフーズ）の高橋様
- 目的: 1週間前にお送りした見積書への回答を催促したい
- トーン: 角が立たないように丁寧に。あくまで確認という体裁で。
- 補足:
  - 3月10日に見積書（見積番号: Q-2024-0315）をメールで送付済み
  - 3月17日が社内の回答期限だったが、返信がない
  - 見積書がちゃんと届いているかの確認も兼ねたい

件名と本文の両方を書いてください。
```

**出力例:**

```
件名: お見積書の件につきまして（ご確認のお願い）

株式会社グリーンフーズ
高橋様

いつもお世話になっております。
株式会社○○の△△でございます。

先日は弊社の提案にご関心をお寄せいただき、
ありがとうございます。

さて、3月10日にメールにてお送りいたしました
お見積書（見積番号: Q-2024-0315）につきまして、
その後ご確認いただけましたでしょうか。

念のため、メールが届いていない可能性も
ございますので、確認のご連絡を差し上げた次第です。

ご不明な点やご要望等がございましたら、
お気軽にお申し付けください。
内容の調整も柔軟に対応させていただきます。

お忙しいところ恐れ入りますが、
ご確認のほどよろしくお願い申し上げます。

――――――――――――――――
株式会社○○
△△（名前）
TEL: 000-0000-0000
Email: xxxxx@example.com
――――――――――――――――
```

ポイントは、プロンプトに**「角が立たないように」「確認という体裁で」**と明記したことです。ChatGPTはこうした指示を忠実に反映してくれるため、「催促」ではなく「確認」のニュアンスで仕上がっています。「メールが届いていない可能性もございますので」というクッション表現も自動的に入っているのがさすがです。

**催促メールのプロンプトで使える便利なフレーズ集:**

- 「角が立たない表現にしてください」
- 「催促ではなく確認のトーンでお願いします」
- 「相手が忙しいことに配慮した文面にしてください」
- 「プレッシャーを与えない程度に期限を伝えてください」

これらをプロンプトに一言添えるだけで、文面のニュアンスが大きく変わります。


### シーン5: 社外向けフォーマルなメール

新規取引の挨拶、セミナーの案内、契約更新のお知らせなど、特にフォーマルさが求められる社外向けメールも、ChatGPTの得意分野です。

**プロンプト例:**

```
以下の条件でビジネスメールを作成してください。

- 送信先: 新規取引先の候補企業（株式会社テクノスター）の山本常務
- 目的: 先日の展示会での名刺交換のお礼と、改めての面談のお願い
- トーン: 非常にフォーマル。初めてのやり取りにふさわしい丁寧さで。
- 補足:
  - 3月12日に東京ビッグサイトで開催された「ITソリューション展2024」で名刺交換
  - 弊社のクラウド在庫管理サービスに興味を示してくださった
  - 30分程度のオンライン面談を希望

件名と本文の両方を書いてください。
```

**出力例:**

```
件名: 「ITソリューション展2024」でのご挨拶の御礼（面談のお願い）

株式会社テクノスター
常務取締役 山本様

突然のご連絡にて失礼いたします。
株式会社○○ 営業部の△△と申します。

先日、東京ビッグサイトにて開催されました
「ITソリューション展2024」の会場にて
お名刺を頂戴いたしました。
ご多用のところお時間をいただき、
誠にありがとうございました。

展示会では、弊社のクラウド在庫管理サービスに
ご関心をお寄せいただいたと伺い、
大変ありがたく存じます。

つきましては、弊社サービスの詳細について
あらためてご説明の機会を頂戴できればと存じます。
オンラインにて30分程度のお時間をいただければ、
貴社のご状況に合わせた活用のご提案が
できるかと存じます。

もしご検討いただけるようでしたら、
山本様のご都合のよい日時をいくつか

ご多忙のところ誠に恐縮ではございますが、
何卒よろしくお願い申し上げます。

――――――――――――――――

△△（名前）
TEL: 000-0000-0000
Email: xxxxx@example.com
――――――――――――――――
```

初めてのやり取りにふさわしい、格式のある文面になっています。自分で一から書こうとすると「失礼にならないかな」「この敬語は正しいかな」と不安になりがちですが、ChatGPTは敬語のルールをきちんと踏まえた文面を作ってくれます。


### 既存メールの添削・リライトを依頼する

ChatGPTの活用法は、メールをゼロから作成することだけではありません。自分で書いたメールを添削してもらったり、もっと良い表現にリライトしてもらうこともできます。むしろ、この使い方のほうが実務では重宝するかもしれません。

**添削を依頼するプロンプト例:**

```
以下のビジネスメールを添削してください。
不自然な敬語、わかりにくい表現、改善できる点があれば
修正して、修正箇所の理由も教えてください。

---
件名: 資料の件

佐藤様

お世話になります。田中です。

先日お話しした資料ですが、作成しましたので送ります。
確認していただいて、問題なければ教えてください。
修正があれば対応します。

よろしくお願いします。

田中
---
```

**出力例:**

```
以下のとおり添削いたしました。

【添削後】

件名: 先日ご依頼いただいた資料の送付について

佐藤様

いつもお世話になっております。田中でございます。

先日ご依頼いただいておりました資料が
完成いたしましたので、本メールに添付いたします。

お手すきの際にご確認いただき、
内容に問題がなければその旨ご一報いただけますと幸いです。
修正点がございましたら、対応させていただきますので
お気軽にお申し付けください。

何卒よろしくお願いいたします。

田中

【修正箇所と理由】

1. 件名「資料の件」→「先日ご依頼いただいた資料の送付について」
   → 件名は具体的なほうが、相手が内容を把握しやすくなります。

2. 「お世話になります」→「いつもお世話になっております」
   → 現在進行形の「おります」のほうがビジネスメールでは一般的です。

3. 「送ります」→「本メールに添付いたします」
   → 「送ります」はやや口語的です。
     添付なのか別送なのかも明確にしました。

4. 「確認していただいて」→「お手すきの際にご確認いただき」
   → 相手の状況に配慮する一言を加えることで、
     より丁寧な印象になります。

5. 「問題なければ教えてください」→「問題がなければその旨ご一報いただけますと幸いです」
   → 「教えてください」は敬語としてやや不十分です。
```

このように、添削理由も一緒に表示してくれるので、自分の文章力の向上にもつながります。何度か繰り返すうちに、「ああ、ここはこう書けばいいんだ」という感覚が自然と身についていきます。

**リライトを依頼するプロンプト例:**

```
以下のメールを、もっと簡潔でわかりやすい文章に
リライトしてください。要点は変えずに、
読みやすさを重視してください。

---
（ここに自分で書いたメールを貼り付ける）
---
```


### トーンの調整 ― 「もっとカジュアルに」「もっと丁寧に」

同じ内容のメールでも、送る相手によってトーンを変える必要があります。取引先に送るなら丁寧に、社内の親しい同僚に送るならカジュアルに。この調整もChatGPTに任せられます。

**方法1: 最初から指定する**

プロンプトの「トーン」の部分で、細かく指定します。

```
トーンの指定例:
- 「非常にフォーマル。取引先の役員に送るレベル」
- 「丁寧だけど堅すぎない。社内メールとして自然なレベル」
- 「親しい同僚に送る感じ。カジュアルでOK」
- 「新入社員が先輩に送る感じ。丁寧だけど初々しさを残して」
```

**方法2: 作成後に調整する**

ChatGPTが作成したメールを読んで「ちょっと堅いな」と思ったら、次のように追加の指示を出せます。

**プロンプト例:**

```
ありがとうございます。
このメールをもう少しカジュアルなトーンに
書き直してください。
社内の気心知れた同僚に送るイメージです。
```

**出力例（カジュアル版）:**

```
件名: 予算データのお願い

鈴木さん

お疲れさまです！

来週金曜の部門会議の資料作成で
使いたいのですが、来月分の部門予算の
実績データ（Excel）をもらえますか？

今週中だと助かります！

お手数おかけしますが、よろしくお願いします。

△△
```

**プロンプト例（逆にもっと丁寧にしたい場合）:**

```
このメールをもっと丁寧なトーンに書き直してください。
相手は取引先の部長クラスです。
```

このように、ChatGPTとの会話の中でトーンを自在に調整できます。一度作ったメールをベースに、何パターンか作って比較するのも良い方法です。


### 要点メモから文章化するテクニック

メールの内容が複雑なとき、「文章で説明しようとすると混乱する」ということはありませんか？ そんなときは、伝えたい要点を箇条書きでメモしてChatGPTに渡すだけで、きちんとした文章に仕上げてくれます。

**プロンプト例:**

```
以下の箇条書きメモをもとに、
```

### 注意点: 最終チェックは必ず自分で

ChatGPTは非常に優秀なメール作成アシスタントですが、万能ではありません。以下の点については、送信前に必ず自分の目で確認してください。

**1. 固有名詞の正確性**

ChatGPTは、あなたが入力した情報をもとにメールを作成します。会社名、人名、商品名、日付などの固有名詞が正しいかどうかは、あなた自身が確認する必要があります。特に人名の漢字間違いは致命的です。

**2. 事実関係の正確性**

ChatGPTが「それっぽい」内容を補足してくることがあります。自分が伝えていない情報が含まれていないか確認しましょう。たとえば、プロンプトに書いていない約束事や条件が勝手に追加されていることがまれにあります。

**3. 社内ルールとの整合性**

メールの書き方に社内ルール（件名のフォーマット、CCの入れ方のルールなど）がある場合は、それに合わせて修正が必要です。ChatGPTは社内ルールを知りません。

**4. 添付ファイルの確認**

「添付いたします」と書いてあるのに添付を忘れる――これはChatGPTのせいではなく、よくある人為ミスです。送信前に必ず確認しましょう。

**5. 感情的な内容への注意**

クレーム対応やトラブル対応のメールでは、ChatGPTが作る文面が「きれいすぎる」ことがあります。状況によっては、もう少し踏み込んだ言葉や、自分自身の気持ちを加えたほうが誠意が伝わることもあります。テンプレート的な文面がかえって逆効果になる場面もあるので、状況に応じた判断は人間にしかできません。

**チェックリスト（送信前に確認）:**

- [ ] 宛先（TO/CC/BCC）は正しいか
- [ ] 相手の会社名・部署名・氏名に間違いはないか
- [ ] 日付・時間・場所などの事実関係は正確か
- [ ] 自分が伝えていない情報が勝手に追加されていないか
- [ ] 添付ファイルは付いているか
- [ ] 社内のメールルールに沿っているか
- [ ] 全体のトーンは適切か


### Before/After: メール作成にかかる時間と品質の変化

ここで、ChatGPTを活用する前と後で、メール作成がどう変わるかを具体的に比較してみましょう。

**Before（ChatGPTなし）:**

| 作業 | かかる時間 |
|------|-----------|
| お礼メール | 10〜15分 |
| 依頼メール | 15〜20分 |
| お詫びメール | 20〜30分 |
| 催促メール | 15〜25分 |
| 社外フォーマルメール | 20〜30分 |
| **1日5通書いた場合の合計** | **約1時間〜2時間** |

**After（ChatGPT活用）:**

| 作業 | かかる時間 |
|------|-----------|
| お礼メール | 2〜3分（プロンプト入力＋確認） |
| 依頼メール | 3〜5分 |
| お詫びメール | 5〜8分（慎重な確認含む） |
| 催促メール | 3〜5分 |
| 社外フォーマルメール | 5〜8分 |
| **1日5通書いた場合の合計** | **約20〜30分** |

**時間の削減効果: 1日あたり約30分〜1時間30分の節約**

1か月（20営業日）に換算すると、約10〜30時間。つまり、まるまる1〜4日分の仕事時間が浮く計算です。

しかも、品質面でも変化があります。

| 項目 | Before | After |
|------|--------|-------|
| 敬語の正確さ | 自信がないまま送ることも | 適切な敬語が自動で使われる |
| 文章の構成 | 思いつくまま書いて後から修正 | 最初から論理的な構成 |
| トーンの一貫性 | メールによってバラつきあり | 指示どおりのトーンで統一 |
| 心理的負担 | 「この書き方で大丈夫かな」と不安 | 確認作業に集中できる |

メールの品質が上がり、かかる時間が減り、心理的な負担も軽くなる。これがChatGPTを「メール作成アシスタント」として使う最大のメリットです。


### 「やってみよう」コーナー: 実際に催促メールを作ってみよう

ここまで読んで「なるほど、便利そうだな」と思った方、ぜひ実際にやってみましょう。実際に手を動かすと、驚くほど簡単だということが実感できるはずです。

**お題:**

> あなたは事務職として働いています。2週間前に社外の取引先（株式会社サンライズ・営業部の中村様）にアンケートの回答を依頼するメールを送りましたが、まだ返信がありません。回答期限は1週間前に過ぎています。角が立たないように催促のメールを書いてください。

**ステップ1: 要点を整理する**

まず、メールに必要な情報を箇条書きで整理しましょう。

- 宛先: 株式会社サンライズ 営業部 中村様
- 用件: アンケート回答の催促
- 状況: 2週間前に依頼済み、回答期限を1週間過ぎている
- トーン: 角が立たない、確認ベース

**ステップ2: プロンプトを書く**

ChatGPTに、次のように入力してみてください。

```
以下の条件でビジネスメールを作成してください。

- 送信先: 取引先（株式会社サンライズ）営業部の中村様
- 目的: 2週間前に依頼したアンケートの回答を催促したい
- トーン: 角が立たないように。催促ではなく、
  確認・リマインドという形にしてください。
- 補足:
  - アンケート依頼メールは2週間前に送付済み
  - 回答期限は1週間前に過ぎている
  - アンケートは今後のサービス改善に活用する予定
  - 回答にかかる時間は5分程度であることも伝えたい

件名と本文を作成してください。
```

**ステップ3: 出力を確認する**

ChatGPTが作成したメールを読んで、以下をチェックしましょう。

- [ ] 催促のトーンが柔らかいか（攻撃的な表現がないか）
- [ ] 必要な情報がすべて含まれているか
- [ ] 自分が伝えていない内容が追加されていないか
- [ ] 件名は内容がわかりやすいか

**ステップ4: トーンを調整してみる**

出来上がったメールが「少し丁寧すぎるな」と感じたら、こう追加してみてください。

```
もう少しカジュアルにしてください。
普段からやり取りがある相手なので、
堅すぎず、それでいて丁寧さは保ってください。
```

逆に「もう少し丁寧にしたい」と思ったら、こう伝えます。

```
もう少しフォーマルなトーンにしてください。
相手は役職者なので、より格式のある表現をお願いします。
```

**ステップ5: 自分の言葉を足す**

最後に、ChatGPTが作った文面に、あなた自身の一言を加えてみましょう。たとえば、以前のやり取りで話題になったことに触れたり、相手の近況を気遣う一文を加えたりすると、テンプレート感が消えて、人間味のあるメールになります。

この「ChatGPTで土台を作り → 自分の言葉を足す」という流れが、最も効率的で、かつ温かみのあるメールを作るコツです。


### 章末まとめ

この章では、ChatGPTを使ったメール作成・添削の方法を学びました。最後に、重要なポイントを振り返りましょう。

**基本の4要素を伝えるだけで、実用レベルのメールが完成する**

「誰に」「何を」「どんなトーンで」「補足情報」の4つを指示するだけです。特別なプロンプトのテクニックは不要です。

**シーン別のプロンプトを使い分ける**

お礼、依頼、お詫び、催促、フォーマル――場面に応じた指示の出し方を身につけると、どんなメールでも対応できるようになります。

**添削・リライト機能も活用する**

ゼロから作るだけでなく、自分が書いたメールの改善にも使えます。修正理由も教えてくれるので、自分の文章力も向上します。

**トーン調整は一言で指示できる**

「もっとカジュアルに」「もっと丁寧に」と伝えるだけで、同じ内容のメールをさまざまなトーンで書き直してくれます。

**箇条書きメモからの文章化が便利**

忙しいときは要点を箇条書きで渡すだけでOK。電話メモの文章化にも応用できます。

**最終チェックは必ず自分で行う**

固有名詞、事実関係、社内ルール、添付ファイルの確認は人間の仕事です。ChatGPTはあくまでアシスタントであり、送信ボタンを押す責任はあなた自身にあります。
