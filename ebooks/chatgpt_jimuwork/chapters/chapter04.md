## 第4章 メール作成・添削 ― もう文面で30分悩まない

### メール作成、実は「見えない残業」になっていませんか？

「この書き方で失礼にならないかな……」
「催促したいけど、角が立たない言い方ってどうすれば……」
「お詫びメール、何度書き直しても自信が持といよう……」

事務職の皆さんなら、一度はこんな経験があるのではないでしょうか。

ある調査によると、ビジネスパールの作成・確認に費やす時間は、1日あたり平均で約1時間〜1時間半と言われています。特に事務職は、社内外問わず多くの人とやり取りをする立場です。上司への報告、取引先へのお礼、他部署への依頼、ときにはクレーム対応のお詫びまで――メールの種類は多岐るわたります。

問題は、メールの「内容」を考える時間よりも、「書き方」に悩む時間のほうが長いということです。伝えたいことは頭の中にあるのに、それをどう文章にすればいいのかで手が止まってしまう。これは決して文章力がないからではありません。ビジネスメールには独特の「型」や「マナー」があり、それを毎回ゼロから組み立てようとすると、どうしても時間がかかるのです。

ここでChatGPTの出番です。

ChatGPTは、ビジネスメールの「型」を大量に学習しています。あなたが「誰に」「何を」「どんなトーンで」伝えたいかを指示するだけで、すぐに適切な文面を作成してくれます。あなたの仕事は、出来上がった文面をサッと確認して、必要に応じて微調整するだけ。これだけで、メール作成にかかる時間を大幅に短縮できます。

この章では、事務職の皆さんが日常的に書くメールのパターンごとに、ChatGPTへの具体的な指示の出し方（プロンプト）と、その出力例を紹介していきます。読み終わるころには、「メールで30分悩む」という習慣とはお別れできるはずです。


### ChatGPTにメールを書いてもらう基本パターン

まず、ChatGPTにメールを作成してもらうときの「基本の型」を押さえておきましょう。次の4つの要素を伝えるだけで、実用レベルのメールが出力されます。

**メール作成プロンプトの基本4要素:**

| 要素 | 説明 | 例 |
|------|------|-----|
| 誰に送るか | 相手の立場・関係性 | 取引先の担当者、社内の上司、他部署の同僚 |
| 何を伝えるか | メールの目的・用件 | 打ち合わせのお礼、資料送付の依頼 |
| どんなトーンか | 文体の丁寧さ | フォーマル、やや丁寧、カジュアル |
| 補足情報 | 具体的な固有名詞など | 日時、会社名、商品名 |

これを踏まえた「基本プロンプト」はこのような形になります。

```
以下の条件でビジネスメールを作成してください。

- 送信先: ○○（関係性）
- 目的: ○○
- トーン: ○○
- 補足: ○○

件名と本文の両方を書いてください。
```

たったこれだけです。特別なテクニックは必要ありません。では、ここからは具体的なシーン別に見ていきましょう。


### シーン1: お礼メール

事務職で最も頻繁に書くメールのひとつが、お礼メールです。打ち合わせの後、資料をいただいた後、来社いただいた後など、場面はさまざまです。

**プロンプト例:**

```
以下の条件でビジネスメールを作成してください。

- 送信先: 取引先（ABC商事）の田中様
- 目的: 本日の打ち合わせのお礼と、次回の打ち合わせ日程の確認
- トーン: 丁寧・フォーマル
- 補足: 本日14時に弊社で打ち合わせを行った。次回は来週水曜の15時で仮決定している。
  打ち合わせでは新商品の販売計画について話し合った。

件名と本文の両方を書いてください。
```

**出力例:**

```
件名: 本日のお打ち合わせのお礼（次回日程のご確認）

ABC商事
田中様

いつもお世話になっております。
株式会社○○の△△でございます。

本日はお忙しい中、弊社までお越しいただき
誠にありがとうございました。

新商品の販売計画について、貴重なご意見を
いただけましたこと、大変参考になりました。

さて、次回のお打ち合わせにつきまして、
来週水曜日（○月○日）15時にて
仮決定とさせていただいておりますが、
ご都合はいかがでしょうか。

問題ございませんようでしたら、
あらためて正式なご案内をお送りいたします。

今後ともどうぞよろしくお願いいたします。

―――――――――――――――
株式会社○○
△△（名前）
TEL: 000-0000-0000
Email: xxxxx@example.com
――――――――――――――――
```

このように、基本4要素を伝えるだけで、適切な敬語を使った自然なお礼メールが完成します。「○○」や「△△」の部分を自分の情報に置き換えるだけで、すぐに送信できるレベルです。

**ワンポイント:** 毎回自分の署名を入力するのが面倒な場合は、ChatGPTに最初に「私の署名は以下のとおりです」と伝えておくと、それ以降のメールに自動で署名を入れてくれます。


### シーン2: 依頼メール

他部署への資料作成の依頼や、取引先への見積もり依頼など、「お願いごと」を含むメールは書き方に気を使います。相手に快く引き受けてもらえるような文面をChatGPTに作ってもらいましょう。

**プロンプト例:**

```
以下の条件でビジネスメールを作成してください。

- 送信先: 社内の経理部・鈴木さん（同期で普段からやり取りがある）
- 目的: 来月の部門予算の実績データをExcelで共有してほしい
- トーン: 丁寧だけど堅すぎない（社内メール）
- 補足: 来週金曜の部門会議で使う資料に含めたい。
  できれば今週中にもらえると助かる。

件名と本文の両方を書いてください。
```

**出力例:**

```
件名: 【お願い】来月分の部門予算実績データの共有について

鈴木さん

お疲れさまです。営業部の△△です。

来週金曜日の部門会議で使用する資料を
準備しておりまして、来月分の部門予算の
実績データ（Excel形式）をいただけないでしょうか。

資料の作成スケジュールの関係で、
今週中にご共有いただけると大変助かります。

お忙しいところ恐れ入りますが、
よろしくお願いいたします。

△△
```

社内メールらしい、親しみのあるトーンでありながら、依頼内容と期限が明確に伝わる文面になっています。
