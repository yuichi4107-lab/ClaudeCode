## 第1章　ChatGPTって何？ ― 怖くない、まずは触ってみよう

「AI」と聞いて、どんなイメージが浮かびますか？

映画に出てくるロボット？　人間の仕事を奪う冷たい機械？　それとも、なんだかよくわからないけど難しそうなもの？

安心してください。この章を読み終わるころには、「なんだ、そういうことか」と思っていただけるはずです。そして、実際にChatGPTに最初の質問を投げかけるところまで、一緒にやっていきましょう。

難しい専門用語は使いません。パソコンでExcelの関数が使えるくらいのスキルがあれば、まったく問題ありません。

---

### そもそも「AI」って何なの？

AI（エーアイ）は「Artificial Intelligence」の略で、日本語では「人工知能」と訳されます。

……と書くと、もうそれだけで「難しそう」と感じてしまいますよね。

ですので、もっと身近な例えで説明させてください。

**AIは「ものすごく優秀な予測変換」です。**

スマートフォンで文字を入力しているとき、次に打ちそうな言葉を予測して候補を出してくれますよね。「お疲れ」と打つと「お疲れさまです」と表示される、あれです。

AIがやっていることの本質は、あれと同じです。ただし、予測の範囲がものすごく広い。文章の続きを予測する、質問に対する答えを予測する、画像の中に何が写っているかを予測する――そういったことを、人間が教えた膨大な量のデータをもとにして行っています。

もう少し具体的に言うと、私たちの身の回りにはすでにたくさんのAIが使われています。

- **スマホの音声アシスタント**（SiriやGoogleアシスタント）に話しかけると答えてくれる
- **ネット通販のおすすめ商品**が「あなたへのおすすめ」として表示される
- **メールの迷惑メールフィルター**が、怪しいメールを自動で振り分けてくれる
- **カーナビ**が渋滞情報を考慮して最適なルートを教えてくれる

どれも「AIが判断している」と意識することなく、日常的に使っていますよね。つまり、AIは「すでに私たちの生活に溶け込んでいる道具」なのです。

新しい道具が登場したとき、最初は誰でもちょっと不安に感じます。でも、使ってみたら「なんだ、便利じゃない」となる。電子レンジも、スマートフォンも、最初はそうだったはずです。

AIも、まったく同じです。

---

### ChatGPTとは何か ― あなた専用の「超優秀アシスタント」

さて、「AI」がなんとなくわかったところで、本題の「ChatGPT」（チャットジーピーティー）の話に入りましょう。

ChatGPTは、アメリカのOpenAI（オープンエーアイ）という会社が開発したAIツールです。2022年11月に公開されて以来、世界中で爆発的に広まりました。

使い方はとてもシンプルです。

**チャット（文字のやりとり）で質問すると、AIが答えてくれる。**

LINEで友だちにメッセージを送るような感覚で、質問や相談を文字で入力すると、AIが文章で返事をしてくれます。それだけです。

たとえば、こんなふうに使えます。

> **あなた：**
> 取引先への年末のご挨拶メールの文面を考えてください。丁寧な表現でお願いします。

> **ChatGPT：**
> 以下に年末のご挨拶メールの文例をお作りしました。
>
> 件名：年末のご挨拶
>
> ○○株式会社
> ○○様
>
> 平素より大変お世話になっております。
> 株式会社○○の○○でございます。
>
> 早いもので、本年も残すところあとわずかとなりました。
> 本年も格別のお引き立てを賜り、厚く御礼申し上けます。
>
> 来年もより一層のサービス向上に努めてまいりますので、
> 変わらぬご愛顧のほど、よろしくお願い申し上げます。
>
> 皆様のご健勝とご多幸を心よりお祈り申し上げます。
> どうぞよいお年をお迎えください。

「えっ、こんなにちゃんとした文章が一瞬で出てくるの？」と驚かれた方も多いのではないでしょうか。

ChatGPTのすごいところは、**相手が人間かAIか、やりとりしているうちに忘れてしまうくらい自然な日本語で返してくれる**ところです。敬語もきちんと使えますし、こちらの意図を汲み取って回答してくれます。

ただし、ここで一つ大事なことをお伝えしておきます。

**ChatGPTは「何でも知っている完璧な存在」ではありません。**

あくまで「膨大なテキストデータから学習して、それっぽい答えを生成するツール」です。ときどき間違った情報をもっともらしく返すこともあります（これを「ハルシネーション」＝幻覚と呼びます）。ですので、重要な情報は必ず自分で確認する習慣をつけましょう。

この点さえ押さえておけば、ChatGPTは本当に頼りになるアシスタントです。

### ChatGPTに「できること」と「できないこと」

ChatGPTを使いこなすためには、得意なことと苦手なことを知っておくのが大切です。ここで整理しておきましょう。

#### できること（得意なこと）

| できること | 具体例 |
|---|---|
| **文章の作成・添削** | メール文面の作成、議事録の要約、報告書の下書き |
| **アイデア出し** | 企画のブレインストーミング、キャッチコピーの案出し |
| **文章の翻訳** | 英語メールの翻訳、海外の資料の要点まとめ |
| **情報の整理・要約** | 長い文章を箇条書きにまとめる、ポイントを抽出する |
| **Excel関数の相談** | 「こういうことがしたいんだけど、どの関数を使えばいい？」に答える |
| **定型作業のサポート** | テンプレートの作成、文章のフォーマット変換 |
| **壁打ち相手** | 考えがまとまらないとき、対話しながら整理する |

#### できないこと（苦手なこと）

| できないこと | 理由 |
|---|---|
| **最新のニュースや情報の提供** | 学習データには時点があり、リアルタイムの情報は持っていない場合がある |
| **社内の機密情報の把握** | あなたの会社の内部情報は知らない（教えない限り） |
| **100%正確な回答の保証** | 前述のとおり、もっともらしい間違いをすることがある |
| **感情を持った対応** | 共感しているように見えても、実際に感情があるわけではない |
| **物理的な作業** | 当たり前ですが、コピーを取りに行ったり、電話をかけたりはできない |
| **法的・医療的な専門判断** | あくまで参考情報であり、専門家の判断に代わるものではない |

ポイントは、**「ChatGPTは下書きを作る達人」**だと思うことです。

完璧な最終成果物をいきなり出してもらうのではなく、「まず叩き台を作ってもらって、自分で仕上げる」という使い方が、もっとも効果的です。

料理に例えると、ChatGPTは食材の下ごしらえをしてくれるアシスタントです。野菜を洗って切って、調味料を計量して並べてくれる。でも、最終的な味つけや盛りつけは、料理人であるあなたが行う。そういう関係です。

### 「AIに仕事を奪われる」への本音の回答

さて、ここで避けては通れない話題に触れておきましょう。

**「AIが進化したら、事務職の仕事はなくなるのでは？」**

この不安を抱えている方は、本当に多いと思います。テレビやネットでも「AIに奪われる仕事ランキング」なんて記事をよく見かけますよね。

正直にお答えします。

**単純な入力作業や転記作業のような「誰がやっても同じ結果になる仕事」は、確かに減っていく可能性があります。**

しかし、それは「事務職がなくなる」という意味ではありません。

考えてみてください。電卓が登場したとき、そろばんで計算していた人の仕事はなくなりましたか？　Excelが登場したとき、経理の仕事はなくなりましたか？

なくなったのは「手作業で計算する」という作業であって、「数字を管理して経営判断に役立てる」という仕事そのものはなくなっていません。むしろ、道具が進化したことで、より高度なことができるようになりました。

AIも同じです。

**なくなるのは「作業」であって、「仕事」ではない。**

そして、ここが重要なのですが――

**AIを使いこなせる事務職の人材は、これからますます重宝されます。**

なぜなら、AIは万能ではないからです。AIが出した文章をチェックする人、AIに的確な指示を出せる人、AIの出力を社内の文脈に合わせて調整できる人――そういう人材が、これから求められるのです。

つまり、「AIに仕事を奪われる」のではなく、**「AIを使える人と使えない人の差が広がる」**というのが、より正確な表現です。

この本を手に取ったあなたは、すでに「使える側」への第一歩を踏み出しています。

### 事務職がAIを使う3つのメリット

では、具体的にChatGPTを使うとどんないいことがあるのか。事務職の方にとってのメリットを3つに整理してみましょう。

#### メリット1：時短 ― 「あの作業」が一瞬で終わる

事務職の日常には、「やらなきゃいけないけど、時間がかかる作業」がたくさんありますよね。

- 定例会議の議事録をまとめる
- 取引先へのお礼メールを書く
- 報告書のフォーマットを整える
- 英語の資料を翻訳する

こうした作業にChatGPTを使うと、**これまで30分かかっていた作業が5分で終わる**、ということが普通に起こります。

浮いた25分で、もっと大事な仕事に集中できる。あるいは、定時で帰れる日が増える。これは大きなメリットです。

#### メリット2：品質向上 ― 「ちゃんとした文章」が書ける

「この表現で失礼にならないかな……」「もっといい言い回しはないかな……」

ビジネス文書を書くとき、こんなふうに悩んだ経験はありませんか？

ChatGPTは、ビジネスメールや報告書の文面を作るのがとても得意です。敬語の使い方、適切な表現の選び方、文章の構成――こうしたことを、一瞬でやってのけます。

もちろん、最終的には自分の目で確認して、必要に応じて修正します。でも、ゼロから書くのと、良い下書きがある状態から仕上げるのとでは、かかる労力がまるで違います。

**「自分では思いつかなかった表現」を提案してもらえる**のも、大きなポイントです。文章力そのものが向上していく効果もあります。

#### メリット3：ストレス軽減 ― 「困った……」が減る

事務職の仕事で地味にストレスになるのが、「やり方がわからない」「誰に聞いていいかわからない」という場面です。

- 「このExcel関数、どう書けばいいんだっけ？」
- 「このビジネス用語、どういう意味？」
- 「クレーム対応のメール、どう書けば角が立たない？」

こうした「ちょっとした困りごと」を、ChatGPTにいつでも気軽に相談できます。

人間の同僚に聞くと「今忙しいんだけど……」と思われるかも、と気を遣ってしまうこと、ありますよね。ChatGPTは何時でも、何回聞いても嫌な顔をしません（そもそも顔がありませんが）。

**「聞ける相手がいつもそばにいる」という安心感**は、日々の仕事のストレスを確実に軽減してくれます。

### 「やってみよう」コーナー：ChatGPTに最初の質問をしてみよう

さあ、ここからは実際にChatGPTを使ってみましょう。「百聞は一見にしかず」です。

#### ステップ1：ChatGPTにアクセスする

1. パソコンまたはスマートフォンのブラウザ（Google Chrome、Microsoft Edgeなど）を開きます
2. アドレスバーに **https://chat.openai.com** と入力してアクセスします
3. 「Sign up」（サインアップ＝新規登録）をクリックします
4. メールアドレスを入力するか、Googleアカウントでログインします
5. 画面の指示に従って登録を完了します

無料プランでも十分に使えますので、まずは無料で始めてみましょう。

> **ワンポイント：** 会社のパソコンで使う場合は、会社のルールを事前に確認してください。会社によってはAIツールの使用に関するガイドラインを設けているところもあります。また、**お客様の個人情報や社外秘の情報は入力しない**ようにしましょう。これについては後の章でもう少し詳しくお話しします。

#### ステップ2：最初の質問をしてみよう

登録が完了したら、画面の下のほうに文字を入力する欄（メッセージボックス）があります。ここに質問を打ち込んで、送信ボタンを押すだけです。

最初の質問として、こんなことを聞いてみましょう。

>

取引先の山田様への日程変更のお願いメールを書いてください。

**【プロンプト例 3】Excel関数について聞く**

```
Excelで、A列に商品コードが入っていて、別のシートに商品コードと商品名の一覧があります。
A列の商品コードから自動的に商品名を表示させたいのですが、どの関数を使えばいいですか？
初心者にもわかるように教えてください。
```

**【ChatGPTの出力例】**

> VLOOKUP関数（ブイルックアップ関数）を使うのがおすすめです。
>
> **VLOOKUPとは：** 指定した値を別の表から探して、対応するデータを取ってくる関数です。
>
> **書き方：**
> ```
> =VLOOKUP(検索する値, 探す範囲, 何列目を返すか, 検索方法)
> ```
>
> **具体例：**
> A2セルに商品コードが入っていて、「商品マスタ」シートのA列に商品コード、B列に商品名がある場合：
>
> ```
> =VLOOKUP(A2, 商品マスタ!A:B, 2, FALSE)
> ```
>
> - `A2` → 検索したい商品コードが入っているセル
> - `商品マスタ!A:B` → 商品コードと商品名の一覧がある範囲
> - `2` → 2列目（商品名）を返す
> - `FALSE` → 完全に一致するものだけを探す
>
> まずはこの式をB2セルに入れて、うまくいくか試してみてください。

どうでしょうか。どの質問も、まるで詳しい先輩に相談しているような感覚で答えが返ってきますよね。

ここで、上手に質問するためのちょっとしたコツをお伝えします。

#### 質問のコツ ― 3つのポイント

1. **具体的に聞く** ― 「メールを書いて」より「取引先への日程変更のお願いメールを書いて」のほうが、良い回答が返ってきます

2. **条件を伝える** ― 「丁寧な表現で」「箇条書きで」「200文字以内で」など、希望する条件を添えましょう

3. **やり直しOK** ― 気に入らなかったら「もう少しカジュアルにしてください」「もっと短くしてください」と追加で指示できます。何度でもやり直せるのがChatGPTの良いところです

> **ワンポイント：** ChatGPTへの質問や指示のことを「プロンプト」と呼びます。この本では今後もこの言葉を使いますので、覚えておいてくださいね。「プロンプト＝ChatGPTへの指示」、それだけです。

#### チャレンジ！ 3つの質問を試してみよう

では、練習として以下の3つの質問を、実際にChatGPTに送ってみてください。

**チャレンジ 1：**
```
ビジネスメールで使える、丁寧なお断りの表現を5つ教えてください。
```

**チャレンジ 2：**
```
「売上が前年比120%に達した」ことを上司に報告する文章を、3行以内で書いてください。
```

**チャレンジ 3：**

```

3つとも試してみましたか？　おめでとうございます。あなたはもう「ChatGPTを使える人」です。

最初の一歩を踏み出すのが、一番大変です。でも、もうその一歩は踏み出しました。あとは、少しずつ使い方を広げていくだけです。

### 第1章のまとめ

この章で学んだことを振り返りましょう。

**1. AIとは？**
- 「ものすごく優秀な予測変換」のようなもの
- すでにスマホやネット通販など、私たちの生活に溶け込んでいる
- 新しいけれど、怖がる必要はない

**2. ChatGPTとは？**
- チャット形式で質問すると、AIが文章で答えてくれるツール
- LINEで友だちにメッセージを送るような感覚で使える
- 無料プランから始められる

**3. ChatGPTにできること・できないこと**
- 得意：文章作成、翻訳、要約、アイデア出し、Excel関数の相談
- 苦手：最新ニュース、100%正確な回答の保証、感情を持った対応
- 「下書きを作る達人」として活用するのがベスト

**4. 「AIに仕事を奪われる」への回答**
- なくなるのは「作業」であって「仕事」ではない
- AIを使える人と使えない人の差が広がる
- この本を読んでいる時点で「使える側」への一歩を踏み出している

**5. 事務職がAIを使う3つのメリット**
- 時短：30分の作業が5分に
- 品質向上：プロレベルの文章が書ける
- ストレス軽減：いつでも気軽に相談できる相手がいる

**6. 質問のコツ**
- 具体的に聞く
- 条件を伝える
- 気に入らなければ何度でもやり直せる
