# P2結果レポート — 勝率モデル vs 人気ベースライン（OOS）

- 実施日: 2026-06-07
- 判定: **FAIL（モデルは人気ベースラインを超えなかった）**

## 検証条件
- 学習データ: 2024-01-01〜2024-12-31（47,181サンプル, 84特徴量, positive_rate=0.073）
- OOS評価: 2025-01-01〜2025-06-30（24,582サンプル, positive_rate=0.070）
- モデル: LightGBM + 確率較正（isotonic, CalibratedClassifierCV）。特徴量は馬の過去成績・騎手・調教師・血統・レース・オッズ・交互作用（include_odds=True）。
- ベースライン: 人気のみ（P(1着 | 単勝人気順位）を学習データから推定）。
- 注: 検証用縮小窓（特徴量生成が約100ms/行と重く、全期間24万行は約4時間のため。詳細は plan の Task4 参照）。

## 結果（OOS）
| 指標 | モデル | 人気ベースライン | 優劣 |
|---|---|---|---|
| Brier（低い程良い） | 0.05724 | 0.05727 | ほぼ互角（モデル僅差） |
| LogLoss（低い程良い） | 0.20608 | **0.20496** | ベースライン勝ち |
| AUC | 0.8228 | **0.8267** | ベースライン勝ち |
| top1的中率 | 0.3237 | **0.3335** | ベースライン勝ち |

合格条件（Brier・LogLoss でベースライン未満 かつ top1 でベースライン以上）を満たさず → **FAIL**。

## 解釈
- モデルは **オッズ/人気を特徴量に含んでいる**にもかかわらず、**人気のみ**の単純ベースラインを上回れなかった。
- これは「馬の過去成績・騎手・調教師・血統などの工学的特徴量が、市場（オッズ＝人気）が既に織り込んでいる以上の予測力を加えていない」ことを示す。競馬の単勝確率において市場は効率的で、それを上回るのは難しい、という既知の傾向と整合。
- AUC 0.82 は単体では悪くないが、**人気だけで 0.83 が出る**ため妙味（エッジ）にならない。

## 結論と含意（実弾ROI重視の観点）
- 単勝確率予測で市場（人気）を超えるエッジが**確認できない**。WIN5（5レース連続1着）は単勝予測力の積であり、単一レースで人気を超えられない以上、**予測スキルによるWIN5のエッジは見込めない**。
- spec §6 の方針通り、正直な結論は「機械学習による妙味なし」。**実弾でのWIN5購入は現時点で非推奨（"買わない"が正しい判断）**。

## 次の選択肢（未決・ユーザー判断）
1. 本結論を受け入れ、予測モデルでのWIN5は棚上げ（無駄な賭けを回避）。
2. 全期間データ（2021-2026, 24万行）で再検証（約4時間ビルド）。ただし傾向が覆る可能性は低い。
3. 予測スキルではなく**配当構造（キャリーオーバー）**でのエッジを検討（高CO週のみ妙味が出る可能性。P3的分析・別アプローチ）。
4. EV/オーバーレイ視点の深掘り（モデルが人気と"乖離して当たる"局面があるかの分析）。

## 追加検証: キャリーオーバー構造のエッジ（2026-06-07）

予測スキルではなく配当構造で+EVが出ないかを `scripts/analyze_carryover_ev.py` で検証（win5_events 326週）。

- 全期間回収率 = **0.699**（WIN5払戻率70%を実証。長期は必ず30%負ける）。
- キャリーオーバー週（的中0）は3回のみ。繰越が翌週に乗った的中週3つの回収率は **0.79〜0.80**（依然-20%）。
- 繰越/売上(co_ratio)が損益分岐 0.30 に届く週は **ゼロ**（最大でも0.11）。閾値0.10で1週のみ・回収率0.805。

**理由（構造的）**: 大きな繰越が出ると賞金目当ての投票が殺到し**売上が膨張**（通常5〜9億→繰越週は24〜63億）、繰越が希釈される。市場が繰越を効率的に吸収するため+EVに到達しない。

→ **結論: WIN5は予測でも配当構造でも+EVのエッジが確認できない。実弾購入は非推奨。**
（注: 観測期間2021-2026に5週以上連続不的中の巨大繰越は発生せず。理論上の極端CO週は別だが極めて稀で本期間では未観測。）
