# SPAT4 トリプル馬単予想モジュール

## 概要
地方競馬（南関東4場+門別）のトリプル馬単（3レース×馬単の全的中）戦略システム

## データ
- `data/spat4.csv` — 357開催分の過去データ (2025/4-2026/1)
- `data/spat4_enhanced.csv` — 推定オッズ付き拡張データ
- `data/template_with_odds.csv` — 今後のデータ記録用テンプレート

## 分析スクリプト
- `scripts/analyze_stats.py` — 統計分析（競馬場別・人気合計別・曜日別）
- `scripts/analyze_patterns.py` — パターン分析（配当分布・フラグ分析）
- `scripts/build_odds_analysis.py` — オッズ推定・分析

## 戦略書
- `reports/SPAT4_最終購入戦略.md` — 総合戦略書
- `reports/SPAT4_トリプル馬単_競馬場別戦略書.pdf` — 競馬場別戦略

## 5つの核心戦略
1. キャリーオーバー時のみ購入（CO時平均708万円 vs 通常238万円）
2. 堅いレースは1着固定、荒れレースは2着で穴拾い
3. 競馬場別戦略（門別46.8%, 川崎57.6% vs 浦和32.1%）
4. 人気合計15-19帯が最高コスパ
5. 開催4日目は穴狙い
