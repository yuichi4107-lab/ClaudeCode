### 3.3 推奨: オッズ帯別の買い方

#### 1番人気が1倍台のレース
```
→ このレースは「絞る」レースとして活用
→ 1着: 1番人気固定
→ 2着: 2-3番人気から1-2頭
→ 点数: 1-2点
→ 残り2レースに点数予算を回す
```

#### 1番人気が2倍台のレース
```
→ 軸にはするが1着固定は危険
→ 1着: 1-2番人気から2頭
→ 2着: 1-5番人気から3-4頭
→ 点数: 6-8点
```

#### 1番人気が3倍以上のレース
```
→ 混戦。広く流す
→ 1着: 1-4番人気から3頭
→ 2着: 1-6番人気から4-5頭
→ 点数: 12-15点
→ このレースが配当の「スパイス」になる
```

### 4.2 CO額の分布

| CO額帯 | 件数 | 割合 |
|--------|------|------|
| 500万以下 | 2件 | 3.4% |
| 500万-1000万 | 22件 | 37.3% |
| 1000万-1500万 | 28件 | **47.5%** |
| 1500万-5000万 | 5件 | 8.5% |
| 5000万以上 | 2件 | 3.4% |

→ COの約85%は500万〜1500万の範囲。平均1,342万円。

### 4.3 CO時の購入判断フロー

```
キャリーオーバー発生？
├─ NO → 基本的に見送り（通常時は期待値マイナス）
│        ただし、門別開催で人気合計が低そうなら少額参加もOK
│
└─ YES → CO額を確認
          ├─ CO 500万以下 → 少額参加（50円×30-50点=1,500-2,500円）
          ├─ CO 500万-1500万 → 通常参加（50円×50-100点=2,500-5,000円）
          └─ CO 1500万以上 → 積極参加（100円×50-100点=5,000-10,000円）
              ※ CO額 > 当日売上×30% なら期待値プラスの可能性
```

### 4.4 控除率の優位性

通常の馬単を3レース転がした場合の控除率:
- 馬単の控除率: 25%/レース → 3レース: 1-(0.75^3) = **57.8%**

トリプル馬単の控除率:
- 3レースまとめて**30%のみ**

→ **同じ3レースの馬単的中でもトリプル馬単は控除率で27.8%有利**。これがトリプル馬単に参加する構造的な理由。

## 第7章: 具体的な購入フォーメーション例

### 7.1 パターンA: 堅実型（CO時・堅い日向け）

**想定場面**: CO発生中、門別or川崎開催、1番人気に1倍台がいる
```
レース1（堅いレース・1番人気1倍台）:
  1着: 1番人気 [1頭]
  2着: 2番人気, 3番人気 [2頭]
  → 2点

レース2（普通のレース）:
  1着: 1番人気, 2番人気 [2頭]
  2着: 1-4番人気 [4頭]  ※裏目含む
  → 8点

レース3（やや広め）:
  1着: 1番人気, 2番人気 [2頭]
  2着: 1-5番人気 [5頭]
  → 10点

合計: 2 × 8 × 10 = 160点
投資額: 50円 × 160 = 8,000円
期待配当: 10万-200万円
```

### 7.2 パターンB: バランス型（CO時・標準日向け）★推奨★

**想定場面**: CO発生中、人気合計15-20程度が予想される日
```
レース1:
  1着: 1-2番人気 [2頭]
  2着: 1-4番人気 [4頭]
  → 8点

レース2:
  1着: 1-2番人気 [2頭]
  2着: 1-5番人気 [5頭]
  → 10点

レース3:
  1着: 1番人気（絞る）[1頭]
  2着: 1-3番人気 [3頭]
  → 3点

合計: 8 × 10 × 3 = 240点
投資額: 50円 × 240 = 12,000円
期待配当: 50万-500万円
```

### 7.3 パターンC: 穴狙い型（高額CO時・荒れ日向け）

**想定場面**: CO 1,500万以上、大井開催、月曜or4日目
```
レース1:
  1着: 1-3番人気 [3頭]
  2着: 1-6番人気 [6頭]
  → 18点

レース2:
  1着: 1-3番人気 [3頭]
  2着: 1-5番人気 [5頭]
  → 15点

レース3:
  1着: 1-2番人気 [2頭]
  2着: 1-4番人気 [4頭]
  → 8点

合計: 18 × 15 × 8 = 2,160点
投資額: 50円 × 2,160 = 108,000円 → 点数を絞って調整
調整版: 1着を各レース2頭に → 8×10×8 = 640点 = 32,000円
期待配当: 200万-5,000万円
```

### 7.4 パターンD: 超堅実型（確実に的中を取る）

**想定場面**: 門別開催、人気合計12以下が予想される日
```
レース1:
  1着: 1番人気 [1頭]
  2着: 2-3番人気 [2頭]
  → 2点

レース2:
  1着: 1番人気 [1頭]
  2着: 2-3番人気 [2頭]
  → 2点

レース3:
  1着: 1番人気 [1頭]
  2着: 2-4番人気 [3頭]
  → 3点

合計: 2 × 2 × 3 = 12点
投資額: 50円 × 12 = 600円
期待配当: 1万-10万円
的中率: 推定60-80%
```

## 第8章: リスク管理と資金管理

### 8.1 資金管理の原則

| ルール | 内容 |
|--------|------|
| **1回あたりの上限** | 総資金の5-10%以内 |
| **月間予算の設定** | 月2-5万円を上限に |
| **CO時の増額** | CO 1,000万以上で通常の2倍まで |
| **連敗時の対応** | 5連敗で投資額を半分に |
| **的中時の対応** | 利益の50%を確保、50%を次回原資に |

### 8.2 購入金額のガイドライン

| 資金レベル | 1回の投資額 | 月間予算 | 戦略 |
|-----------|-----------|---------|------|
| 少額（〜5万円） | 1,000-3,000円 | 1-2万円 | パターンA・Dを中心に |
| 中額（5-20万円） | 3,000-10,000円 | 2-5万円 | パターンBを中心に |
| 高額（20万以上） | 10,000-30,000円 | 5-10万円 | 状況に応じてA-C使い分け |

### 8.3 損益分岐点の計算

的中率と平均配当から、長期的な損益分岐点を試算:

| 投資パターン | 的中率（推定） | 平均配当（推定） | 期待値 |
|-------------|-------------|---------------|--------|
| 超堅実型（600円） | 60-80% | 5万円 | +2.5万-3.5万円 |
| 堅実型（8,000円） | 20-30% | 100万円 | +1.2万-2.2万円 |
| バランス型（12,000円） | 10-15% | 200万円 | +0.8万-1.8万円 |
| 穴狙い型（32,000円） | 3-5% | 1,000万円 | -0.2万-+1.8万円 |

→ **CO時に堅実型〜バランス型で参加するのが最も安定**
