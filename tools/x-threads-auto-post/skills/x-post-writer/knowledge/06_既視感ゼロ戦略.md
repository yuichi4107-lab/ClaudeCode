# 既視感ゼロ戦略

## 目的
**毎回違うポストに見せる。同じメッセージでも、別の角度・表現・構造で語る。**

---

## 【問題】既視感が出る3大要因

### 1. 構造が毎回同じ
- いつも同じ順序で展開（稼げない人のミス→正解→失敗談...）
- 読者が「またこのパターンね」と気づく

### 2. 同じ話を同じ角度で繰り返す
- フックと本文で同じ表現を使う
- 同じ数字・同じ事例を何度も使う
- 読者が「さっきも聞いたわ」と飽きる

### 3. 見せ方が固定
- 見出しが毎回同じ
- 接続詞が毎回同じ（まず〜、次に〜）
- CTAの表現が毎回同じ

---

## 【解決策1】構造パターンを3つ用意（順序を変える）

### パターンA: 基本型
```
[1] フック
[2] 稼げない人のミス
[3] これが正解
[4] Xアルゴ説明
[5] よくある誤解
[6] 失敗談
[7] テーマの魅力
[8] 具体的な方法
[9] 失敗パターン回避
[10] 不安払拭
[11] CTA
[12] 追加価値
[13] 最終警告
[14] 追撃CTA
```

### パターンB: 失敗談先出し型
```
[1] フック
[2] 自分の失敗談(先に共感)
[3] 稼げない人のミス(読者も同じ)
[4] これが正解
[5] Xアルゴ説明
[6] よくある誤解
[7] テーマの魅力
[8] 具体的な方法
[9] 失敗パターン回避
[10] 不安払拭
[11] CTA
[12] 追加価値
[13] 最終警告
[14] 追撃CTA
```

### パターンC: 逆説先出し型
```
[1] フック
[2] よくある誤解を潰す(先に常識破壊)
[3] 稼げない人のミス(なぜそうなるか)
[4] これが正解
[5] 自分の失敗談
[6] Xアルゴ説明
[7] テーマの魅力
[8] 具体的な方法
[9] 失敗パターン回避
[10] 不安払拭
[11] CTA
[12] 追加価値
[13] 最終警告
[14] 追撃CTA
```

**ポイント:**
- [2]〜[6]の順序を入れ替える（導入部分）
- [7]〜[14]は固定（本題と誘導）
- 3パターンをランダムに使う

---

## 【解決策2】繰り返し回避の3原則

### 原則1: 同じメッセージは「別の角度」で語る

**同じメッセージ:** 「売ることが大事」

**別の角度:**
- 自分の失敗談（売らなかった結果）
- 他人の成功事例（売った結果）
- データの話（売ると何がわかるか）
- スピードの話（売ると改善が早い）
- スキルの話（売ると実戦で身につく）

→ 同じメッセージでも、5つの角度で語れる

**❌ NG例: フックと本文で同じ表現**
```
【フック】
月100万稼げない人 vs 月100万稼げる人
→スキル磨き vs 売る・テスト・改善

【本文】
現実はこう。スキル磨き6ヶ月→売上ゼロ。売る→初日1万円。
```

**問題点:**
- フックで既に「スキル磨き vs 売る」を対比
- 本文でまた同じことを言っている
- 読者が「さっきも聞いたわ」と飽きる

**✅ OK例: 別の角度で語る**
```
【フック】
月100万稼げない人 vs 月100万稼げる人
→スキル磨き vs 売る・テスト・改善

【本文】
私も昔は勘違いしてた。「コピーライティング完璧にしてから」って本5冊読んで→3ヶ月経過→売上ゼロ。

「もういいわ。売ってみよ」って雑なレターを5000円で出したら、初日2人買った。1万円。
```

**ポイント:**
- フック: 抽象的な対比
- 本文: 自分の失敗談という具体例
- 同じメッセージ（売るべき）だが、伝え方が違う

---

### 原則2: 同じ数字・同じ表現は2回まで

**例: 「スキル磨き6ヶ月→売上ゼロ」**
- 1回目: OK（対比で使う）
- 2回目: NG（同じ表現を繰り返すな）

**代替案:**
- 「スキル磨き6ヶ月→売上ゼロ」を1回使ったら、
- 次は「3ヶ月勉強→商品ゼロ」等、別の数字・表現にする

**✅ 良い例: 同じメッセージ、別の角度**
```
(1回目は失敗談で語る)
私も昔は勘違いしてた。「コピーライティング完璧にしてから」って本5冊読んで→3ヶ月経過→売上ゼロ。

(2回目は別の人の事例で語る)
先月聞いた話、「レターなんてChatGPTに書かせただけっすよ」って言ってたけど、初月80万売ってた。

(3回目は改善サイクルのスピード差で語る)
スキル磨き→6ヶ月後に売る→失敗→また6ヶ月勉強。売る→失敗→翌日改善→また売る。
```

**ポイント:**
- 同じメッセージ（売るべき）を3回伝えているが、
  - 1回目: 自分の失敗談
  - 2回目: 他人の成功事例
  - 3回目: 改善サイクルのスピード差
- 角度が違うので、飽きない

---

### 原則3: 対比フックで言ったことは、本文では「深掘り」する

**対比フック:**
- 抽象的な対比（スキル磨き vs 売る）

**本文:**
- 具体的な失敗談・成功事例
- データ・数字
- スピード・スキルの話
- 別の人の事例

→ フックで「what（何が大事か）」を言ったら、本文では「why（なぜ大事か）」「how（どうやるか）」を語る

---

## 【解決策3】見せ方のバリエーション

### 見出しを毎回変える（同義語・表現変更）

#### 「稼げない人のミス」の見出しバリエーション
- 稼げない人のミス
- よくある失敗パターン
- 9割がやってる間違い
- これやってたら終わり
- 典型的な負けパターン
- 月100万いかない人の共通点
- （見出しなし、いきなり本文）

#### 「これが正解」の見出しバリエーション
- これが正解
- 正しいやり方
- 月100万の人がやってること
- 答えはシンプル
- 本質はこれだけ
- （見出しなし、いきなり本文）

#### 「何がいいか」の見出しバリエーション
- 〇〇の何がいいか
- なぜ〇〇なのか
- 〇〇が強い理由
- 〇〇のメリット
- 〇〇を選ぶべき理由
- （見出しなし、「まず〜」から開始）

**ポイント:**
- 同じブロックでも、見出しを毎回変える
- 見出しを削除して、いきなり本文から入るのもあり

---

### 展開パターンを変える（接続詞・リズム）

#### 「まず〜、次に〜、あと〜」の代替パターン

**パターンA: 基本型**
```
まず競合がいない。
次にXアルゴが味方する。
あと広告も安い。
```

**パターンB: 番号型**
```
1つ目、競合がいない。
2つ目、Xアルゴが味方する。
3つ目、広告も安い。
```

**パターンC: 接続詞なし型**
```
競合がいない。レッドオーシャンだと〜

Xアルゴが味方する。フォロワー1000人でも〜

広告も安い。ターゲットが明確だから〜
```

**パターンD: 疑問形導入型**
```
何がいいか?まず競合がいない。
他には?Xアルゴが味方する。
あと?広告も安い。
```

**パターンE: 体言止め連打型**
```
競合ゼロ。
Xアルゴ味方。
広告費激安。
```

**ポイント:**
- 毎回違うパターンを使う
- 同じ「箇条書き展開」でも、接続詞を変えるだけで印象が変わる

---

### CTAの位置・表現を変える

#### CTA位置のバリエーション

**パターンA: 基本型**
- [11] CTA（中盤）
- [14] 追撃CTA（最後）

**パターンB: 早出し型**
- [7] の途中にCTA挿入（「ちなみに、やり方わからん人はプロフのメルマガ見といて」）
- [14] 追撃CTA（最後）

**パターンC: 1回だけ型**
- CTAを[11]だけにして、[14]は「スキル磨き、後回しでいいから。今日から売っていこ。」のような締めの言葉

**パターンD: 3回型**
- [8]の途中、[11]、[14]の3箇所にCTA
- ただし表現を変える

#### CTA表現のバリエーション

**パターンA: 基本型**
```
※やり方わからん人はプロフのメルマガ登録してくれたら解説するから見といて。
```

**パターンB: 疑問形**
```
やり方知りたい?プロフのメルマガで全部解説してるから見といて。
```

**パターンC: 条件型**
```
本気で月100万目指すなら、プロフのメルマガ登録しといたほうがいい。具体的なテンプレ全部渡してるから。
```

**パターンD: 簡潔型**
```
プロフのメルマガで全部解説してる。見といて。
```

**パターンE: ストーリー型**
```
私がこれで月200万いったテンプレ、メルマガで全部公開してる。プロフから登録できるから見といて。
```

**ポイント:**
- CTAの表現を毎回変える
- 位置も変える（早出し、1回だけ、3回など）
- 「※」を使わない回もある

---

### 具体例・数字を毎回変える

#### 同じ内容でも、具体例を変える

**例: 「スキルなくても売れる」を説明**

**パターンA: ChatGPT例**
```
私の知り合いで「コピーライティング?知らん」って人が、ChatGPTでLP作って月200万売ってる。
```

**パターンB: テンプレ例**
```
先月会った人、「セールスレター?テンプレ使っただけ」って言ってたけど、月150万売ってた。
```

**パターンC: 外注例**
```
「LP作れない」って言ってた人、外注5万で作らせて、月100万売ってる。スキル?ゼロ。
```

**パターンD: 自分の例**
```
私も最初、コピーライティングとか知らんかったけど、ChatGPTに丸投げしたLP、初月30万売れた。
```

#### 数字を変える

**パターンA: 月200万**
```
ChatGPTでLP作って月200万売ってる。
```

**パターンB: 初月50万**
```
ChatGPTでLP作って、初月50万売ってる。
```

**パターンC: 半年で300万**
```
ChatGPTでLP作って、半年で月300万安定してる。
```

**ポイント:**
- 同じ「スキルなくても売れる」というメッセージでも、具体例と数字を変える
- 毎回違う人物・違う数字にすることで、既視感を消す

---

### 事例の構成パターンも変える

#### ❌NG: 過去のポストと同じ構成を繰り返す

**例: 箇条書き形式を毎回使う**
```
海外事例: 〇〇した→結果→数字
私の事例: 〇〇した→結果→数字
```

これを何度も使うと、同じフォロワーが見たときに「またこのパターンか」と気づく。

#### ✅OK: 事例の見せ方を毎回変える

**パターンA: 箇条書き形式（基本型）**
```
海外の事例。アメリカの起業家で、「商品ゼロ」の状態でセールスレター書いて先に売った人がいる。50人申し込み来た→「お、需要あるな」→そこから商品作った→初月300万。日本人？「商品完璧に作ってから売る」→作ったけど誰も買わない→「時間無駄にした...」
```

**パターンB: 長文形式（段階的成長ストーリー）**
```
私の事例でいうと、投資系のPDFも「とりあえず売ってみよ」で5000円で出したら初月10万。「お、いけるな」ってクオリティ上げて1万円にしたら次の月40万。半年後には月150万安定。スキル？売りながら全部学んだ。
```

**パターンC: 対比要素追加（成功vs失敗）**
```
知り合いの話。投資系の商品で、最初は5000円で雑なPDFを出した。初月10万。そこから何がウケたかを分析して、内容を絞り込んで1万円に値上げ。次の月40万。さらに購入者の質問をFAQにまとめて追加→半年後には月150万安定。

逆にセールスライティングを半年勉強してから商品出した人は、「完璧な販売ページ」を作ったけど誰も買わない。なぜなら、市場の反応を見ずに作ったから。「こんなに勉強したのに...」って泣いてた。
```

**ポイント:**
- 事例の構成は3パターンのみ使用（箇条書き/長文/対比要素）
- 同じフォロワーが複数のポストを見ても、「毎回違うパターンだな」と思わせる
- 過去のポストで使った構成は、最低3回は間を空けてから再利用

## 【禁止事項】

❌ フックと本文で同じ表現を繰り返す
❌ 同じ数字を3回以上使う
❌ 同じ説明を別のセクションで繰り返す
❌ 毎回同じ構造パターンを使う
❌ 毎回同じ見出しを使う
❌ 毎回同じCTA表現を使う

## 【最終ルール】

**構造は同じでいい。見せ方を変えろ。**

- 14ブロック構造 = 料理のレシピ（固定）
- バリエーション = 盛り付け・調味料・順序（変動）

同じレシピでも、毎回違う料理に見せることができる。それがこの既視感ゼロ戦略。

**次回のポスト生成時、このファイルを必ず参照し、前回と違うパターンを選択すること。**
