# フック50パターン集

## 【重要】フックの役割
- 最初の140字で**全てが決まる**
- インプレッションが伸びるか、読まれるかは**フック次第**
- 既視感があったら即スクロール

---

## 【フックの4大要素】全て入れる

1. **ターゲットコール**(誰に向けてるか明確)
2. **意外性・逆説**(既視感ゼロの切り口)
3. **具体的な数字/結果**(信憑性)
4. **強烈な断定/煽り**(読まずにいられない)

---

## 【A. ターゲットコール型】20パターン

### A-0: インサイト指定型（最強パターン）
```
{表面的な行動}とか言いながら、実は{本音}だけの奴へ
```
例: 「100点になってから出そう」とか言い訳して、実は失敗が怖いだけの奴へ

**インサイト指定型の必須要素:**
1. **表面的な言い訳を引用**（「〇〇してから」「もう少し〜」）
2. **「実は」で本音を暴く**（失敗が怖い/楽したい/認めたくない）
3. **「だけの奴へ」で煽る**

**良いインサイト指定例:**
```
✅ 「AI使ったら質が下がる」とか言いながら、手作業で3時間かけてゴミ量産してる奴へ
✅ 「努力は美徳」とか言いながら、本当は楽して稼ぎたいだけの奴へ
✅ 「もう少し勉強してから」とか言って、1年前も同じこと言ってた奴へ
✅ 「自分らしさが出ない」とか言いながら、売れないコピー書き続けてる奴へ
✅ 「完璧にしてから」とか言って、結局何も出さない奴へ
```

**インサイトの見つけ方:**
- 表面的な悩み: 「時間がない」→ 本音: 「優先順位つけたくない/全部やりたい」
- 表面的な悩み: 「スキルがない」→ 本音: 「学ぶのめんどくさい/楽したい」
- 表面的な悩み: 「お金がない」→ 本音: 「リスク取りたくない/失敗が怖い」
- 表面的な悩み: 「やり方がわからない」→ 本音: 「考えたくない/答えだけ欲しい」

**ターゲットの本音データベース（参考）:**
- 失敗が怖い
- 楽したい、努力したくない
- 認められたい、見下されたくない
- 答えだけ欲しい、考えたくない
- リスク取りたくない
- 完璧じゃないと出したくない
- 批判されたくない
- 自分は特別だと思いたい

### A-12: 逆恨み型

## 【B. 意外性・逆説型】15パターン

### B-1: 常識逆転型
```
{常識}は間違い。{逆の行動}したら{結果}になった
```
例: 毎日投稿は間違い。週1投稿したら月200万になった

---

### B-1-EX: 対比パターン型(特に強力)
```
{目標}稼げない人
→{失敗特徴1}、{失敗特徴2}、{失敗特徴3}...

{目標}稼げる人
→{成功特徴1}、{成功特徴2}、{成功特徴3}...

{結論・煽り}
```

**【対比パターンの必須要素】**
1. **「、」で時系列&特徴を羅列** (短く、テンポよく)
2. **小ボケ・いじり**を混ぜる (読者を笑わせつつ刺す)
3. **「」で心情描写** (言い訳、悩み、本音を可視化)
4. **行動の連打**で勢いを作る (〜する、〜する、〜する)

**【小ボケ・いじりの型】**
- セミナー行って名刺交換して満足→帰りに成功した気になって焼き肉食ってるデブ
- YouTube見てノート取って自己満
- 本100冊読んで知識メタボ
- コンサル受けて「勉強になりました!」で終わる
- 「なんで売れねぇんだよ」と泣く
- 夜シコって寝る

**【良い対比パターンの例】**
```
月100万稼げない人
→スキル磨き、「私にはセールスなんて早い」と言い訳して夜シコって寝る、セミナー行って名刺交換して満足→帰りに成功した気になって焼き肉食ってるデブ、YouTube見てノート取って自己満、「なんで売れねぇんだよ」と泣く、本100冊読んで知識メタボ、コンサル受けて「勉強になりました!」で終わる

月100万稼げる人
→売る、テスト、改善、また売る、スキル?後で学ぶ、失敗?データ取る、知識ゼロでも売りながら覚える、売れないなら価格下げてでも売る、売れたら分析→再現、売上出してから学びに投資

スキル磨きやめろ。コピーライティング?セールス?マーケティング理論?全部後回しでいい。
```

**【対比パターンが強力な理由】**
- 読者が「自分はどっちだ?」と自己診断する
- 失敗側で「刺さる+笑える」、成功側で「こうなりたい」
- 情報量が多いのに読みやすい(リズムとテンポ)
- 既視感ゼロ(小ボケ・いじりで個性全開)


## 【D. 強烈な断定/煽り型】10パターン

### D-1: 断言+理由型
```
{断定}。なぜなら{理由}だから
```
例: フォロワー1万以下は全員戦略ミス。なぜならポジション決めてないから

---

### D-2: 全否定型
```
{対象}、全部ゴミ。{代替案}以外価値ない
```
例: 無料note、全部ゴミ。有料商品への導線以外価値ない

---

### D-3: 期限恐怖型
```
{期限}以内に{行動}しない奴、マジで終わる
```
例: 今月以内にポジション決めない奴、マジで終わる

---

### D-4: 二極化宣言型
```
{ターゲット}は2種類。{タイプA}と{タイプB}。後者は死ぬ
```
例: 起業家は2種類。テストする奴としない奴。後者は死ぬ

---

### D-5: 煽り+救済型
```
{煽り}。でも{救済策}知ってるなら別
```
例: お前ら全員センスない。でもフレームワーク知ってるなら別

---

### D-6: 現実突きつけ型
```
残酷な事実を言う。{ターゲット}の{割合}は{悲惨な結果}
```
例: 残酷な事実を言う。副業始める人の90%は1円も稼げず終わる

---

### D-7: 格差提示型
```
{行動}してる奴と、してない奴。{期間}後の差は{結果}
```
例: テストしてる奴と、してない奴。1年後の差は年収2000万

---

### D-8: 無知批判型
```
{知識/スキル}知らないで{行動}してる奴、全員養分
```
例: LTV知らないで起業してる奴、全員養分

---

### D-9: 選別宣言型
```
{条件}の人以外、この先読むな。時間の無駄
```
例: 本気で月100万目指してない人以外、この先読むな。時間の無駄

---

### D-10: 覚悟確認型
```
{目標}達成したい? なら{犠牲}を捨てる覚悟あるか?
```
例: 年収3000万達成したい? なら安定を捨てる覚悟あるか?

## 【使い方】

### STEP3(フック選択)で使用

1. テーマに合うパターンを3つ選ぶ
2. 各パターンでフックを生成
3. 評価(ターゲットコール/意外性/既視感チェック)
4. ユーザーに選ばせる

### 選定基準

- **ターゲットが明確か?**
- **既視感ゼロか?**
- **140字以内か?**
- **4大要素が全て入ってるか?**

## 【禁止事項】

❌ 同じパターンを連続使用(前回A-1なら、今回は別パターン)
❌ 抽象的なターゲットコール(「稼ぎたい人」だけではダメ)
❌ 数字がない(具体性ゼロはNG)
❌ 既視感のある表現(「〜が重要です」等)
