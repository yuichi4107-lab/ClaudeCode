# 箇条書き単独型パターン

## 目的
**「・」だけで完結するポスト。ノウハウ・気づき・コツを大量に並べて圧倒し、保存させる。**

---

## 【根本思想】

### 箇条書き単独型 = 最強の保存装置

**なぜ強力か？**
- **情報量が圧倒的**（30-50個のノウハウを一気に提示）
- **保存率が異常に高い**（「後で読み返したい」と思わせる）
- **スクロールが止まらない**（「まだあるのか」と読み続ける）
- **権威性が一瞬で構築される**（「この人、マジで知ってる」と思われる）

**文字数:**
- 500-1500字程度
- 箇条書き30-50個
- 1項目 = 1-2行

---

## 【箇条書き単独型の絶対構造】

```
[1] 冒頭フック（1-2行）
   → ターゲットコール + 権威性提示
   → 例: 「コピーライティング勉強してるのに月30万も稼げてない奴へ。14年間、文章だけで億稼いで気づいたコツを教える。」

[2] 箇条書き本体（30-50個）
   → 「・」で統一
   → 各項目は1-2行
   → テーマごとにブロック分け（任意）

[3] オチ・追加情報（1行、任意）
   → 例: 「まだ100個くらいあるけど、疲れたからこの辺で。」

[4] CTA（1-2行）
   → 例: 「文章で億稼ぎたい人はいいねブクマ。詳細解説はプロフと固定ポストにあるメルマガで。」
```

---

## 【箇条書き単独型のパターン】

### ミックス型（対比 + 断定 + 理由）

**構造:**
```
・対比型
・断定型
・理由型（なぜなら〜）
```

**実例（ユーザー提供のポスト）:**
```
・誤字を直す→売上ダウン（対比型）
・完璧な文章より誤字で人間味（対比型）
・ですます→タメ口で精読率アップ（対比型）
・丁寧語＝距離を作る（対比型）
・読者をイラつかせる文章は強い（断定型）
・イラつかせる→フォローは最強（対比型）
・お前ら間違ってるぞでちょうどいい（断定型）
・優しい文章＝記憶に残らない（対比型）
・ターゲットは1人に絞れ（命令型）
・みんなへは誰にも届かない（断定型）
・100人にぼんやり好かれる＜1人に刺さる（対比型）
・長文と短文を織り交ぜる（命令型）
・5000字書いても最初の100字しか読まれない（断定型）
・数字なし＝嘘くさい（対比型）
・すごく稼いだは小学生の作文（断定型）
・時間・金額・人数は全部数字（命令型）
・理由なし＝人は動かない（断定型）
・稼げます＜なぜ稼げるか（対比型）
・メカニズムまで書いて初めて信頼（断定型）
・最初の1行で8割決まる（断定型）
・2行目まで読まれない前提（断定型）
・ハッシュタグ今すぐやめろ（命令型）
・プロは内容だけで勝負（断定型）
・いいね欲しがるな（命令型）
・いいね1万＜問い合わせ1件（対比型）
・バズ＝虚栄、金＝現実（対比型）
・社会貢献したい＝嘘くさい（対比型）
・金欲しい＝信頼される（対比型）
・失敗を隠すな（命令型）
・成功談だけ＝信用ゼロ（対比型）
・100万溶かしたで信頼構築（断定型）
・マイナス要素が共感を得る（断定型）
・汚い言葉を使え（命令型）
・クソ、ゴミ、アホ（具体例）
・上品＝退屈、下品＝記憶に残る（対比型）
・才能ないと言いながら稼ぐ奴が売れる（断定型）
・文章力＜誰に書くかが9割（対比型）
・読んだ後に行動が変わらない＝書くな（命令型）
・いい話で終わる＝無価値（対比型）
・読者の人生を1ミリでも動かせ（命令型）
```

**特徴:**
- 対比・断定・命令をミックス
- リズムが生まれる
- 飽きさせない
- 情報量が多いのに読みやすい

---

## 【箇条書き単独型の絶対ルール】

### ルール1: 冒頭フックで「誰に + 権威性」を示せ

**❌ 悪い例:**
```
コピーライティングのコツを教えます。
```
→ ターゲット不明、権威性ゼロ

**✅ 良い例:**
```
コピーライティング勉強してるのに月30万も稼げてない奴へ。14年間、文章だけで億稼いで気づいたコツを教える。
```
→ ターゲット明確、権威性（14年/億）提示

**必須要素:**
- **ターゲットコール**（〇〇してるのに稼げてない奴へ）
- **権威性提示**（14年間/億稼いだ/〇〇件成約させた）
- **何を教えるか明示**（コツを教える/ノウハウ公開する）

---

### ルール2: 箇条書きは30個以上（圧倒せよ）

**❌ 悪い例（10個）:**
```
・〇〇
・〇〇
...（10個）

以上です。
```
→ 情報量少ない、権威性出ない

**✅ 良い例（30-50個）:**
```
・〇〇
・〇〇
...（30-50個）

まだ100個くらいあるけど、疲れたからこの辺で。
```
→ 圧倒的情報量、「この人マジで知ってる」

**目安:**
- **最低30個**
- **理想は40-50個**
- 「まだあるけど疲れた」で余裕を見せる

---

### ルール3: 各項目は1-2行まで（簡潔に）

**❌ 悪い例:**
```
・誤字を直すと売上がダウンする理由は、完璧すぎる文章は人間味がなくて、読者が距離を感じるから
```
→ 長すぎ、読みづらい

**✅ 良い例:**
```
・誤字を直す→売上ダウン
・完璧な文章より誤字で人間味
```
→ 短い、テンポがいい

**1項目の文字数:**
- **10-30字程度**
- 長くても40字まで
- 説明は不要、結論だけ

---

### ルール4: 対比（→、＜、＝）を多用せよ

**対比の型:**
- **A → B**（AするとBになる）
- **A ＜ B**（AよりB）
- **A ＝ B**（AはB）

**実例:**
```
・誤字を直す→売上ダウン（A→B）
・100人にぼんやり好かれる＜1人に刺さる（A＜B）
・丁寧語＝距離を作る（A＝B）
```

**なぜ対比が強力か:**
- 意外性が生まれる
- 常識を否定できる
- 記憶に残る

**対比の割合:**
- 箇条書き50個中、**20-30個は対比型**
- 残りは断定型・命令型

---

### ルール5: オチで「まだあるけど」と余裕を見せる

**❌ 悪い例:**
```
以上です。参考になれば幸いです。
```
→ 弱い、権威性ゼロ

**✅ 良い例:**
```
まだ100個くらいあるけど、疲れたからこの辺で。
```
→ 余裕、権威性UP、「もっと聞きたい」と思わせる

**オチのバリエーション:**
- 「まだ50個あるけど、長くなるから続きはメルマガで」
- 「200個くらい溜まってるけど、出し惜しみしとく」
- 「本当はもっとあるけど、無料で全部出すのもったいないからこの辺で」

---

## 【箇条書き単独型の心理効果】

### 効果1: 圧倒的情報量で権威性を構築

**読者の心理:**
- 「この人、マジで知ってるわ」
- 「14年間の経験、ホンモノだ」
- 「この人から学びたい」

→ 一瞬で信頼構築

---

### 効果2: 保存率が異常に高い

**読者の行動:**
- 「後で読み返したい」
- ブックマーク
- スクショ

→ エンゲージメント爆上がり

---

### 効果3: スクロールが止まらない

**読者の心理:**
- 「まだあるのか」
- 「次は何だ？」
- 「全部読みたい」

→ 完読率60-80%

---

### 効果4: 「続きが欲しい」と思わせる

**オチで「まだあるけど」:**
- 「残りが知りたい」
- 「メルマガ登録しよう」

→ リスト取り成功

## 【テンプレート】

### テンプレート1: 対比ミックス型（基本）

```
【冒頭フック】
〇〇してるのに稼げてない奴へ。〇〇年間、〇〇で〇〇稼いで気づいたコツを教える。

【箇条書き本体】30-50個
・A → B（対比型）
・A ＜ B（対比型）
・A ＝ B（対比型）
・〇〇しろ（命令型）
・〇〇やめろ（命令型）
・〇〇するな（禁止型）
・〇〇が強い（断定型）
...

【オチ】
まだ〇〇個くらいあるけど、疲れたからこの辺で。

【CTA】
〇〇したい人はいいねブクマ。詳細はプロフのメルマガで。
```

---

### テンプレート2: 断定特化型

```
【冒頭フック】
〇〇で消耗してる人へ。〇〇年やってわかった真実。

【箇条書き本体】30-50個
・〇〇しろ
・〇〇やめろ
・〇〇が全て
・〇〇は無駄
・〇〇だけでいい
...（全て断定・命令）

【オチ】
これ全部実践したら月100万いく。

【CTA】
本気の人だけいいね。やり方はメルマガで。
```

---

### テンプレート3: 対比特化型

```
【冒頭フック】
〇〇で稼げない理由、全部教える。

【箇条書き本体】30-50個
・A → B
・A ＜ B
・A ＝ B
...（全て対比）

【オチ】
逆やってるから稼げない。

【CTA】
気づいた人はいいね。正解はメルマガで。
```

## 【文字数の目安】

### 短文型（500-800字）

**構造:**
- 冒頭フック: 1-2行
- 箇条書き: 30個
- 各項目: 10-20字
- オチ: 1行
- CTA: 1-2行

**合計:** 500-800字

---

### 中文型（800-1200字）

**構造:**
- 冒頭フック: 2-3行
- 箇条書き: 40-50個
- 各項目: 15-25字
- オチ: 1-2行
- CTA: 2-3行

**合計:** 800-1200字

**例:** ユーザー提供のポスト

---

### 長文型（1200-1500字）

**構造:**
- 冒頭フック: 3-4行
- 箇条書き: 50-60個
- 各項目: 20-30字
- 中間説明: 2-3箇所（任意）
- オチ: 2-3行
- CTA: 2-3行

**合計:** 1200-1500字

## 【実装時の注意点】

### 注意1: 長文パターンとの違い

**長文パターン（3000字）:**
- 教育価値重視
- 14ブロック構造
- ストーリー展開

**箇条書き単独型（500-1200字）:**
- 情報量重視
- 箇条書きのみ
- ストーリーなし

---

### 注意2: フローチャート単独型との違い

**フローチャート単独型（500-1000字）:**
- 時系列・論理展開
- 「↓」で階段構造
- 自己投影させる

**箇条書き単独型（500-1200字）:**
- ノウハウ・コツの羅列
- 「・」で並列
- 情報量で圧倒

---

### 注意3: ターゲット

**箇条書き単独型を使うべき場面:**
- ノウハウ・コツを一気に教える
- 権威性を示したい
- 保存させたい
- リスト取りしたい

**向いてないテーマ:**
- ストーリー系
- 失敗談
- 感情移入系

## 【評価基準（箇条書き単独型専用）】

```
1. 冒頭フックの強さ(20点)
   - ターゲットコールが明確か? (7点)
   - 権威性が示されているか?（年数/金額/実績） (7点)
   - 何を教えるか明示されているか? (6点)
   評価: /20点

2. 箇条書きの量と質(30点)
   - 30個以上あるか? (10点)
   - 各項目が1-2行以内か? (10点)
   - 対比型が20個以上あるか?（→、＜、＝） (10点)
   評価: /30点

3. 情報の意外性(20点)
   - 常識を否定する項目があるか? (10点)
   - 「え、マジで？」と思わせる項目があるか? (10点)
   評価: /20点

4. オチの余裕感(15点)
   - 「まだあるけど」等、余裕を見せてるか? (10点)
   - 権威性が補強されてるか? (5点)
   評価: /15点

5. CTAの強さ(15点)
   - 行動喚起が明確か?（いいね/ブクマ/メルマガ） (10点)
   - 自然か?（強引じゃないか） (5点)
   評価: /15点

総合評価: /100点
合格ライン: 80点以上
```

## 【まとめ】

### 箇条書き単独型の絶対法則

1. **冒頭フックで「誰に + 権威性」を示せ**
2. **箇条書きは30個以上**（圧倒せよ）
3. **各項目は1-2行まで**（簡潔に）
4. **対比（→、＜、＝）を多用せよ**
5. **オチで「まだあるけど」と余裕を見せる**

**情報量で圧倒し、保存させ、続きを欲しがらせよ。**
