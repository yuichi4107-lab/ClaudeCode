# 文体DNA抽出マニュアル

## 目的
ユーザーの投稿から「本人らしさ」を抽出し、AI生成文でも**本人が書いたと思われる**レベルに再現する。

---

## 【抽出すべき5大要素】

### 1. 語尾パターン

ユーザーの投稿から、**語尾の使用頻度**を分析する。

```
チェック項目:
□ 「〜から」で断定: ○%
□ 体言止め: ○%
□ 「〜してる」口語系: ○%
□ 「〜だ」断定: ○%
□ 「〜です」「〜ます」丁寧語: ○%
□ 「〜だよね」「〜じゃん」カジュアル: ○%
```

**例:**
```
サンプル投稿:
「ニッチジャンルの何がいいか。まず競合がいない。」
「それで勝ち確定。」
「私も何度それ系のミスしたかわからんくらいやらかしてるからわかる。」

→ 分析結果:
- 体言止め: 40% (「何がいいか。」「勝ち確定。」)
- 「〜から」断定: 30% (「〜からわかる」)
- 「〜してる」口語: 30%
```

---

### 2. 口語表現・口癖

**頻出する口語表現**をリストアップ。

```
チェック項目:
□ 「めっちゃ」「マジで」「正直」
□ 「www」「w」
□ 「〜な」(「〜なんだよな」等)
□ 「ムズ!」「ヤバい」
□ 「すまん」「ごめん」
□ 「〜ってこと」「〜ってやつ」
□ その他独自の口癖
```

**例:**
```
サンプル投稿から抽出:
- 「www」 → 煽り・皮肉で使用
- 「めちゃ」 → 強調で使用
- 「すまん」 → 情報伏せる時に使用
- 「ムズ!」 → 読者の不安を代弁
```

---

### 3. 改行リズム

**文章のリズム**を数値化。

```
チェック項目:
□ 1文あたりの文字数(平均)
□ 改行頻度(何文字で改行するか)
□ 短文→長文→短文のパターン有無
□ 箇条書きの使用頻度
```

**例:**
```
サンプル投稿:
「ニッチジャンルの何がいいか。(短文:14文字)

まず競合がいない。レッドオーシャンだと投稿が流れる。でもニッチなら、検索したらあなたしか出てこない。第一人者になれる。(長文:68文字)

それで勝ち確定。(短文:9文字)」

→ リズム分析:
- 短文(10-20文字) → 長文(50-80文字) → 短文(10-20文字)
- このパターンを繰り返す
```

---

### 4. 強調の仕方

**どうやって重要な部分を目立たせるか**を分析。

```
チェック項目:
□ 「」かぎかっこの使用頻度
□ !!、!の使用頻度
□ 【】【】墨付きかっこ
□ ※注意※、※やり方〜 などの記号
□ 太字、斜体(使える場合)
□ 改行+空白行で強調
```

**例:**
```
サンプル投稿から抽出:
- 「」: セリフ、引用、皮肉で使用(頻度:高)
- !!: ほぼ使わない
- ※〜※: 重要な補足・CTAで使用
- 改行+空白: セクション区切りで使用
```

---

### 5. 論理展開パターン

**どういう流れで話を進めるか**を分析。

```
チェック項目:
□ 結論先出し型 or ストーリー型
□ 問題提起→解決策 の流れ
□ 箇条書き → 各項目説明 の流れ
□ 具体例 → 抽象化 の流れ
□ 逆説・否定から入る
```

**例:**
```
サンプル投稿の展開:
1. フック(問題提起+煽り)
2. 「稼げない人のミス」(否定)
3. 「これが正解」(肯定)
4. 理由を箇条書き
5. 各理由を説明
6. 具体例(海外・自分)
7. 失敗パターン警告
8. 不安払拭
9. CTA

→ パターン: 否定→肯定→理由→具体例→警告→誘導
```

## 【抽出後の記録フォーマット】

ヒアリング後、以下の形式で内部メモを作成(ユーザーには見せない)。

```markdown
### 文体DNA(内部メモ)

**語尾パターン:**
*   **重要:** 語尾を統一しすぎない。「〜から」「〜でしょ？」「〜だし」などの口語的な崩し（ゆらぎ）を意識的に混ぜる。
*   比率イメージ: 丁寧語 50% : 断定 30% : 口語崩し 20%
- 体言止め: 40%
- 「〜から」断定: 30%
- 「〜してる」口語: 30%

**口語表現:**
- 「www」「めちゃ」「すまん」「ムズ!」を頻繁に使用
- 「マジで」「正直」は控えめ

**改行リズム:**
- 短文(10-20字) → 長文(50-80字) → 短文(10-20字)
- このパターンを3-4回繰り返す

**強調:**
- 「」で引用・セリフ・皮肉
- !!はほぼ使わない
- ※〜※で重要な補足

**論理展開:**
- 否定(稼げない人のミス) → 肯定(これが正解) → 理由 → 具体例 → 警告 → CTA

**独自の表現:**
- 「無双する」「屍化」「沼で死んでる」
- 「勝ち確定」「一択」「圧倒的に楽」
- 「テストすりゃ全部解決できる」
```

□ 強調の仕方を再現したか?

## 【注意事項】

### やってはいけないこと

❌ **完璧すぎる文章にする**
- 人間は完璧じゃない。適度な揺らぎ、冗長さが必要。

❌ **抽出した癖を無視する**
- 「本人らしさ」を無視したら0点。必ず再現すること。
- **「お前」呼びは禁止。**どんなに強い口調でも、読者を「お前」とは呼ばない。

❌ **全く同じ表現を繰り返す**
- 「www」を毎行入れる、等はNG。**適度に**が重要。

### やるべきこと

✅ **揺らぎを作る**
- 同じ語尾を連続させない
- 改行リズムに不規則性を入れる

✅ **本人の口癖を自然に配置**
- 「無双する」は1回だけ、効果的な場所で使う

✅ **完成度70%を目指す**
- 完璧主義を捨て、人間味を優先

## 【事例: 良い再現 vs 悪い再現】

### ❌ 悪い再現(AI臭い)

```
ニッチジャンルには多くのメリットがあります。
まず、競合が少ないため、市場での優位性を確保しやすいです。
次に、ターゲットが明確なため、マーケティング施策が効率的です。
これらの理由から、ニッチジャンルは初心者にもおすすめできます。
```

→ 問題点:
- 「〜です」調(本人は使わない)
- 完璧すぎる文章
- 口語表現ゼロ
- 本人の癖が全くない

---

### ✅ 良い再現(本人が書いたレベル)

```
ニッチジャンルの何がいいか。

まず競合がいない。レッドオーシャンだと投稿が流れるけど、ニッチなら検索したらあなたしか出てこない。

それで勝ち確定。

次にXアルゴが味方する。フォロワー1000人でも、その1000人が超濃いファン。レッドオーシャンで10万フォロワーより、ニッチで1000人の方が10倍稼げる。

広告も安い。ターゲットが明確だから狙い撃ちできる。
```

→ 良い点:
- 体言止め、「〜から」が再現されてる
- 短→長→短のリズム
- 口語「けど」「超濃い」が自然
- 「勝ち確定」という本人の表現
- 完璧すぎず、人間味がある
