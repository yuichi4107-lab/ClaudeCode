# 長文構造(3000字パターン)

## 目的
教育→リスト取り特化の長文投稿(3000字級)を生成する。

---

## 【長文投稿の全体設計】

### コンセプト
- **バズは無視、濃い見込み客だけを集める**
- 具体的なノウハウを提供して信頼を得る
- 自然な流れでリスト(メルマガ/LINE/LP)に誘導
- AI臭ゼロ、本人が書いたと思われるレベル

### 文字数配分
- フック: 140字
- 本文: 2700-2900字
- 合計: 3000字前後

---

## 【14ブロック構造】必ずこの順番で書く

### [1] フック(140字)

**STEP3で確定したフックをそのまま使用。**

```
例:
「そんなの誰が買うの?www」ってニッチジャンルは月100万くらいならすぐ稼げる。最新の実体験を話す。
```

ポイント:
- 具体的な失敗例
- 「屍化」「沼で死んでる」等の強い表現

```

```

### [4] 今のXアルゴ/市場環境の説明(300字)

**なぜ今この方法が有効か、環境要因を説明。**

```
構成:
- Xアルゴの特性(狭い内容でも届く)
- 広告の精度向上
- 具体例・数字

ポイント:
- 「今のXのアルゴは〜」で始める
- 「実際、〜」で具体例
- 「また〜」で追加情報
```

```
例:
今のXのアルゴは、めちゃ狭い内容でも必要な人にピンポイントで届く。実際、ターゲットコールを入れた「それ以外の人は見るなよ」というパターンのポストも数万インプは伸びる。また広告の狙い撃ちもしやすい。
```

### [5] よくある誤解を潰す(200字)

**「○○って聞けば納得するけど、実際は〜」パターン。**

```
構成:
「{よくある助言}」

とか、最近よく見るし、聞けば納得、確かに!って思うけど、実際は実力足りなくて{失敗パターン}。

ポイント:
- 一般的な助言を引用
- 「聞けば納得」と一度肯定
- 「でも実際は〜」で否定
```

```
例:
「レッドオーシャンの中のブルーオーシャンを狙え」

とか、最近よく見るし、聞けば納得、確かに!って思うけど、実際は実力足りなくてレッドオーシャン沼で死んでる屍多数。
```

### [6] 自分の失敗談(200字)

**本人の失敗経験で共感を得る。**

```
構成:
私も何度それ系のミスしたかわからんくらいやらかしてるからわかる。

ポイント:
- 「私も〜」で自己開示
- 「わからんくらい」「何度も」で赤裸々さ
- 「からわかる」で共感
```

```
例:
私も何度それ系のミスしたかわからんくらいやらかしてるからわかる。
「最高傑作の講座ができた！」と確信
↓
意気揚々と3万円でリリース
↓
翌日、競合が同じ内容を無料プレ企画で公開
↓
「え、これ無料で出てるやつですよね？」とDM届く
↓
売上低下、ジリ貧に

これあるあるだよね。
```

**ポイント:**
- **「作るのが大変」ではなく「情報の価値がなくなる（競合に無料で出される）」失敗談を優先せよ。**
- これが「情報を売るな、環境を売れ」という主張の最強の根拠になる。
```

### [7] テーマの何がいいか(箇条書き3-5個、各100字)

**本題の魅力を箇条書きで展開。**

```
構成:
{テーマ}の何がいいか。

まず{理由1}。{詳細説明}。

次に{理由2}。{詳細説明}。

{理由3}も{メリット}。{詳細説明}。

ポイント:
- 「まず」「次に」「〜も」で展開
- 各理由を2-3文で説明
- 具体例・数字を入れる
```

```
例:
ニッチジャンルの何がいいか。

まず競合がいない。レッドオーシャンだと投稿が流れる。でもニッチなら、検索したらあなたしか出てこない。第一人者になれる。

もしくは「それそれ!」と思われる。それで勝ち確定。

次にXアルゴが味方する。フォロワー1000人でも、その1000人が超濃いファン。レッドオーシャンで10万フォロワーより、ニッチで1000人の方が10倍稼げる。

広告も安い。ターゲットが明確だから狙い撃ちできる。レッドオーシャンは広告費が高騰してる。ニッチならCPA数百円で濃い見込み客が取れる。
```

### [8] 具体的な方法(3ステップ、各150字)

**実行可能な手順を3つ提示。**

```
構成:
じゃあ{テーマ}ってどうやって{行動}するか。

私がやったのは3つ。

・{方法1}
・{方法2}
・{方法3}

例えば{具体例1}。{詳細説明}。

{具体例2}も狙い目。{詳細説明}。

{具体例3}は、例えば{詳細例}。ここまで絞ると競合が消える。

ポイント:
- 「私がやったのは3つ」で導入
- 箇条書き → 各項目を詳細説明
- 具体例を必ず入れる
```

```
例:
じゃあニッチジャンルってどうやって見つけるか。

私がやったのは3つ。

・自分の経験と珍しいジャンルを掛け合わせる
・誰も解決してない小さな悩みを探す
・レッドオーシャンを超細分化する

例えば「会計士×副業」「保育士×投資」みたいな掛け合わせ。本業の専門性と別ジャンルを組み合わせる。組み合わせはほぼ無限にある。

小さな悩みも狙い目。大手が参入しないレベルの悩み。でもその悩みを持ってる人は確実にいる。そこを独占する。

超細分化は、例えば「ダイエット」じゃなく「40代女性の下腹部だけ痩せる方法」。ここまで絞ると競合が消える。
```

### [9] 失敗パターンの回避法(200字)

**よくある失敗と、その対策。**

```
構成:
{テーマ}で失敗するパターンもある。{失敗例}。これは{対策}で防げる。{具体的な防ぎ方}。

ポイント:
- 失敗パターンを提示
- 「でも」「これは」で対策を示す
- 具体的な数字・基準を入れる
```

```
例:
ニッチジャンルで失敗するパターンもある。ニッチすぎて市場がゼロの場合。これは事前に需要確認で防げる。X投稿で反応見る。100いいね以上つけば市場はある。(実際はフォロワー対比、普段のポスト対比が重要)
```

### [10] 不安の払拭(150字)

**「難しそう」と思った読者を安心させる。**

```
構成:
↑これムズ!と思った人が{数}人いるな。

でも安心して。結局、「{簡単な解決策}」から。今は{環境変化}。

昔:{過去の状況}
今:{現在の状況}

ポイント:
- 「↑これムズ!と思った人が〜」で読者の不安を代弁
- 「でも安心して」で救済
- 昔vs今の対比で説得力
```

```
例:
↑これムズ!と思った人が237人いるな。

でも安心して。結局、「テストすりゃ全部解決できる」から。今はAIのおかげで制作スピードが10倍になった。

昔:制作→テスト→修正(数カ月経過)
今:制作→テスト→修正(1週間で完了)
```

### [12] 追加価値提示(200字)

**さらに深い情報を提供。海外事例、横展開など。**

```
構成:
あと、{追加のメリット}。{理由説明}。

{具体例1}。別の人は{具体例2}。{テーマ}はいくらでもある。

私の事例でいうと{自分の事例}。

ポイント:
- 「あと」で追加情報の導入
- 海外事例、他人の事例で説得力
- 「私の事例でいうと」で自己開示
```

```
例:
あと、ニッチは情報発信のネタが尽きない。レッドオーシャンは語り尽くされてる。でもニッチなら発信することが全て新鮮。

商品設計もしやすい。競合がいないから価格比較されない。50万円の商品でも「あなたから買う」という状態になる。

実力ないならニッチ一択。

レッドオーシャンで消耗するより、ニッチで無双する方が圧倒的に楽。

海外の具体例を出す。「左利き専用の文房具」で月50万稼いでる。別の人は「田舎暮らし×リモートワーク」で月80万。ニッチはいくらでもある。

私の事例でいうと投資系でも悩みをめちゃくちゃコア(案件バレしそうだから伏せる。すまん)に絞って、それをLPに書く。コンセプトにする。

すると、広告でテストしまくると当たりが見つかる。
```

ポイント:
- ※注意※で目立たせる
- 間違いを指摘
- 正しい方法を再確認
```

```
例:

ブルーオーシャンと名ばかりの魚のいない海ではなく、ちゃんと需要テストをしながら見つけること。これが重要。
```

ポイント:
- 「本気で〜人だけ」でフィルタリング

- 具体的な誘導先を明記
```

```
