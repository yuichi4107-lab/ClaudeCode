# 対比パターン完全ガイド

## 目的
**「できる人 vs できない人」の対比で、刺さる+笑える+行動させるフックを作る。**

---

## 【対比パターンが最強な理由】

### 1. 読者が自己診断する
「自分はどっち側だ?」と無意識に判定→当事者意識が強まる

### 2. 失敗側で「刺さる+笑える」
小ボケ・いじりで笑わせつつ、痛いところを突く

### 3. 成功側で「こうなりたい」
行動の連打で勢いを作り、理想像を鮮明に描く

### 4. 情報量が多いのに読みやすい
「、」で羅列するため、テンポよく大量の特徴を並べられる

### 5. 既視感ゼロ
小ボケ・いじりで個性全開、誰の真似でもない

---

## 【対比パターンの基本構造】

```
{目標}できない人
→{失敗特徴1}、{失敗特徴2}、{失敗特徴3}、{失敗特徴4}、{失敗特徴5}...

{目標}できる人
→{成功特徴1}、{成功特徴2}、{成功特徴3}、{成功特徴4}、{成功特徴5}...

{結論・煽り}
```

---

## 【必須要素4つ】全て入れること

### 1. 「、」で特徴を羅列
**短く、テンポよく並べる**

```
✅ 良い例:
スキル磨き、YouTube見てノート取って自己満、本100冊読んで知識メタボ、コンサル受けて「勉強になりました!」で終わる

❌ 悪い例:
スキル磨きをします。次にYouTubeを見てノートを取ります。本を100冊読みます。
```

**ポイント:**
- 「、」で区切り、改行しない
- 1つ1つは短く(10-30文字程度)
- リズムとテンポを優先

---

### 2. 小ボケ・いじりを混ぜる
**読者を笑わせつつ、痛いところを突く**

```
✅ 良い小ボケ・いじり例:
- セミナー行って名刺交換して満足→帰りに成功した気になって焼き肉食ってるデブ
- YouTube見てノート取って自己満
- 本100冊読んで知識メタボ
- コンサル受けて「勉強になりました!」で終わる
- 「なんで売れねぇんだよ」と泣く
- 夜シコって寝る
```

**小ボケ・いじりの型:**
- **擬人化+デフォルメ**(例: 知識メタボ、焼き肉食ってるデブ)
- **行動+皮肉**(例: 名刺交換して満足→成功した気になって)
- **時系列の連鎖**(例: セミナー行って→名刺交換して→満足→帰りに→焼き肉)
- **感情の可視化**(例: 「なんで売れねぇんだよ」と泣く)
- **タブー表現**(例: 夜シコって寝る)

---

### 3. 「」で心情描写
**言い訳、悩み、本音を可視化**

```
✅ 良い心情描写例:
- 「私にはセールスなんて早い」と言い訳
- 「なんで売れねぇんだよ」と泣く
- 「勉強になりました!」で終わる
```

**心情描写の型:**
- **言い訳系**(例: 「私にはまだ早い」「実績がないから無理」)
- **悩み系**(例: 「なんで売れないんだ」「どうすればいいんだ」)
- **自己満足系**(例: 「勉強になった!」「いいこと聞いた!」)

---

### 4. 行動の連打で勢いを作る
**成功側は特に、動詞を連打してテンポを出す**

```
✅ 良い行動連打例:
売る、テスト、改善、また売る、スキル?後で学ぶ、失敗?データ取る、知識ゼロでも売りながら覚える、売れないなら価格下げてでも売る、売れたら分析→再現、売上出してから学びに投資

❌ 悪い例:
売ることを大切にします。テストをします。改善をします。
```

**ポイント:**
- 動詞を「、」で連打
- 「〜します」を使わない(体言止め、断定形)
- 疑問形を挟む(スキル?後で学ぶ、失敗?データ取る)

---

## 【対比パターンの作り方】ステップ

### STEP1: テーマを対比構造に変換

```
入力テーマ: 月100万稼ぐ方法

↓ 対比構造に変換

月100万稼げない人 vs 月100万稼げる人
```

**対比が有効なテーマ:**
- 稼げる/稼げない
- 成功する/失敗する
- 伸びる/伸びない
- 売れる/売れない
- モテる/モテない
- 痩せる/痩せない

---

### STEP2: 失敗側の特徴を10個リストアップ

```
月100万稼げない人の特徴:
1. スキル磨きばかりする
2. セミナーに行くだけで満足
3. YouTube見てノート取って終わり
4. 本を100冊読むだけ
5. コンサル受けて「勉強になった」で終わる
6. 「私にはセールスなんて早い」と言い訳
7. 「なんで売れないんだ」と悩むだけ
8. 売らない、テストしない
9. 実績作りに数カ月かける
10. 夜シコって寝る
```

---

### STEP3: 小ボケ・いじりを追加

```
1. スキル磨きばかりする
   → スキル磨き

2. セミナーに行くだけで満足
   → セミナー行って名刺交換して満足→帰りに成功した気になって焼き肉食ってるデブ

3. YouTube見てノート取って終わり
   → YouTube見てノート取って自己満

4. 本を100冊読むだけ
   → 本100冊読んで知識メタボ

5. コンサル受けて「勉強になった」で終わる
   → コンサル受けて「勉強になりました!」で終わる

6. 「私にはセールスなんて早い」と言い訳
   → 「私にはセールスなんて早い」と言い訳して夜シコって寝る

7. 「なんで売れないんだ」と悩むだけ
   → 「なんで売れねぇんだよ」と泣く
```

---

### STEP4: 成功側の特徴を10個リストアップ

```
月100万稼げる人の特徴:
1. 売る
2. テストする
3. 改善する
4. また売る
5. スキル?後で学ぶ
6. 失敗?データ取る
7. 知識ゼロでも売りながら覚える
8. 売れないなら価格下げてでも売る
9. 売れたら分析→再現
10. 売上出してから学びに投資
```

---

### STEP5: 行動の連打で勢いを出す

```
月100万稼げる人
→売る、テスト、改善、また売る、スキル?後で学ぶ、失敗?データ取る、知識ゼロでも売りながら覚える、売れないなら価格下げてでも売る、売れたら分析→再現、売上出してから学びに投資
```

**ポイント:**
- 動詞を連打
- 疑問形を挟む(スキル?後で学ぶ)
- 条件文を入れる(売れないなら〜、売れたら〜)

---

### STEP6: 結論・煽りを追加

```
スキル磨きやめろ。コピーライティング?セールス?マーケティング理論?全部後回しでいい。
```

**結論・煽りの型:**
- **命令形**(例: 〜やめろ、〜しろ)
- **疑問形の連打**(例: コピーライティング?セールス?マーケティング理論?)
- **極端な断定**(例: 全部後回しでいい)

---

```

Xで伸びる人
→週1投稿、ターゲット刺さる内容だけ、リプ?見込み客だけ、フォロワー数?売上見る、伸びない?仮説立てて改善、プロフ?後回し、投稿に全集中

毎日投稿やめろ。量より質。ターゲットに刺さる1投稿>どうでもいい7投稿。
```

## 【禁止事項】

❌ **失敗側と成功側を対称にしすぎる**
- 失敗側: 小ボケ・いじり多め
- 成功側: 行動の連打で勢い

→ 温度差を作ることで、成功側の魅力が際立つ

❌ **「、」を使わず改行で区切る**
- 改行するとリズムが死ぬ
- 「、」で羅列し、1行にまとめる

❌ **小ボケ・いじりが優しすぎる**
- 「少し勉強しすぎる」→NG
- 「本100冊読んで知識メタボ」→OK

❌ **結論・煽りが弱い**
- 「〜がおすすめです」→NG
- 「〜やめろ。全部後回しでいい」→OK

---

## 【最終確認】

対比パターンを作成したら、以下を確認:

```
□ 失敗側に小ボケ・いじりが3箇所以上入ってるか?
□ 失敗側に「」で心情描写が2箇所以上入ってるか?
□ 成功側は行動の連打でテンポが出てるか?
□ 「、」で羅列し、1行にまとまってるか?
□ 結論・煽りは命令形か?
□ 読んで笑えるか?(小ボケが効いてるか)
□ 読んで刺さるか?(痛いところを突いてるか)
□ 読んで行動したくなるか?(成功側に憧れるか)
```

全てクリアしたら完成。

---

**対比パターンは、刺さる+笑える+行動させる、最強のフック型。積極的に使え。**
