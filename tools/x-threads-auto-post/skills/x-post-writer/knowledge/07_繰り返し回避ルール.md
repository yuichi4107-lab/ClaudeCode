# 繰り返し回避ルール

## 目的
**同じ話を何度も繰り返さない。同じメッセージでも、別の角度・具体例で語る。**

---

## 【問題】同じ話の繰り返しパターン

### パターン1: 対比フックと本文で同じ表現
```
❌ 悪い例:

【フック】
月100万稼げない人 vs 月100万稼げる人
→スキル磨き vs 売る・テスト・改善

【本文】
現実はこう。スキル磨き6ヶ月→売上ゼロ。売る→初日1万円。
```

**問題点:**
- フックで既に「スキル磨き vs 売る」を対比している
- 本文でまた「スキル磨き6ヶ月→売上ゼロ。売る→初日1万円」と同じことを言っている
- 読者が「さっきも聞いたわ」と飽きる

**解決策:**
- フック: 抽象的な対比(スキル磨き vs 売る)
- 本文: 具体的なエピソード・データ・失敗談で語る

```
✅ 良い例:

【フック】
月100万稼げない人 vs 月100万稼げる人
→スキル磨き vs 売る・テスト・改善

【本文】
私も昔は勘違いしてた。「コピーライティング完璧にしてから」って本5冊読んで→3ヶ月経過→売上ゼロ。

「もういいわ。売ってみよ」って雑なレターを5000円で出したら、初日2人買った。1万円。
```

**ポイント:**
- フックでは「抽象的な対比」
- 本文では「自分の失敗談という具体例」
- 同じメッセージ(売るべき)だが、伝え方が違う

---

### パターン2: 同じ数字・同じ表現を何度も使う

```
❌ 悪い例:

スキル磨き6ヶ月→売上ゼロ。売る→初日1万円。(1回目)

どっちがいいか、猿でもわかる。

売上が出る。売らないと売上ゼロ。スキル磨き6ヶ月→売上ゼロ。売る→初日1万円。(2回目)
```

**問題点:**
- 「スキル磨き6ヶ月→売上ゼロ。売る→初日1万円」が2回出てくる
- 表現も数字も全く同じ
- 読者が「またか」と飽きる

**解決策:**
- 同じメッセージでも、別の角度・別の数字で語る

```
✅ 良い例:

(1回目は失敗談で語る)
私も昔は勘違いしてた。「コピーライティング完璧にしてから」って本5冊読んで→3ヶ月経過→売上ゼロ。

(2回目は別の人の事例で語る)
先月聞いた話、「レターなんてChatGPTに書かせただけっすよ」って言ってたけど、初月80万売ってた。

(3回目は改善サイクルのスピード差で語る)
スキル磨き→6ヶ月後に売る→失敗→また6ヶ月勉強。売る→失敗→翌日改善→また売る。
```

**ポイント:**
- 同じメッセージ(売るべき)を3回伝えているが、
  - 1回目: 自分の失敗談
  - 2回目: 他人の成功事例
  - 3回目: 改善サイクルのスピード差
- 角度が違うので、飽きない

---

### パターン3: 「データが取れる」「改善できる」を何度も同じ説明

```
❌ 悪い例:

データが取れる。
売ると、「どこで離脱したか」「どの文章で買ったか」全部わかる。これが財産。

(中略)

失敗しても改善できる。
売ると、「どこで離脱したか」「どの文章で買ったか」全部わかる。データ取って改善。
```

**問題点:**
- 「どこで離脱したか」「どの文章で買ったか」が2回出てくる
- 同じ説明を繰り返している

**解決策:**
- 1回目: データの種類を説明
- 2回目: データをどう使うかを説明

```
✅ 良い例:

(1回目: データの種類)
データが財産になる。
売ると、「どこで離脱したか」「どの文章で買ったか」「どんな人が買ったか」全部わかる。スキル磨きしてる人？データゼロ。想像だけで商品作る→爆死。

(2回目: データの使い方)
失敗しても改善できる。
「売ったけど売れなかった」→データ取って改善。「スキル磨いたけど売れなかった」→「え？なんで？」→エンドレス沼。売ってる人は、失敗＝改善ポイント。売ってない人は、失敗＝「才能がない」と凹む。
```

**ポイント:**
- 1回目: データの種類(何がわかるか)
- 2回目: データの使い方(失敗をどう捉えるか)
- 同じ「データ」というテーマだが、切り口が違う

---

## 【繰り返し回避の3原則】

### 原則1: 同じメッセージは「別の角度」で語る

**同じメッセージ:** 「売ることが大事」

**別の角度:**
- 自分の失敗談(売らなかった結果)
- 他人の成功事例(売った結果)
- データの話(売ると何がわかるか)
- スピードの話(売ると改善が早い)
- スキルの話(売ると実戦で身につく)

→ 同じメッセージでも、5つの角度で語れる

---

### 原則2: 同じ数字・同じ表現は2回まで

**例: 「スキル磨き6ヶ月→売上ゼロ」**

- 1回目: OK(対比で使う)
- 2回目: NG(同じ表現を繰り返すな)

**代替案:**
- 「スキル磨き6ヶ月→売上ゼロ」を1回使ったら、
- 次は「3ヶ月勉強→商品ゼロ」等、別の数字・表現にする

---

### 原則3: 対比フックで言ったことは、本文では「深掘り」する

**対比フック:**
- 抽象的な対比(スキル磨き vs 売る)

**本文:**
- 具体的な失敗談・成功事例
- データ・数字
- スピード・スキルの話
- 別の人の事例

→ フックで「what(何が大事か)」を言ったら、本文では「why(なぜ大事か)」「how(どうやるか)」を語る

---

## 【チェックリスト】繰り返し回避

```
□ 対比フックで言ったことを、本文でそのまま繰り返していないか？
□ 同じ数字・同じ表現が3回以上出ていないか？
□ 同じ説明を別のセクションで繰り返していないか？
□ 同じメッセージを「別の角度」で語っているか？
□ フックで「what」、本文で「why/how」を語っているか？
```

全てクリアしたら、繰り返しゼロ。

---

## 【実例: 繰り返し回避の正しい構成】

### フック(抽象的な対比)
```
月100万稼げない人 → スキル磨き
月100万稼げる人 → 売る、テスト、改善
```

### 本文1: 自分の失敗談(具体例)
```
私も昔は勘違いしてた。「コピーライティング完璧にしてから」って本5冊読んで→3ヶ月経過→売上ゼロ。

「もういいわ。売ってみよ」って雑なレターを5000円で出したら、初日2人買った。1万円。
```

### 本文2: データの話(別の角度)
```
データが財産になる。
売ると、「どこで離脱したか」「どの文章で買ったか」全部わかる。スキル磨きしてる人？データゼロ。想像だけで商品作る→爆死。
```

### 本文3: スピードの話(別の角度)
```
改善サイクルが10倍速い。
スキル磨き→6ヶ月後に売る→失敗→また6ヶ月勉強。売る→失敗→翌日改善→また売る。
```

### 本文4: 他人の成功事例(別の角度)
```
先月聞いた話、「レターなんてChatGPTに書かせただけっすよ」って言ってたけど、初月80万売ってた。
```

**ポイント:**
- フック: 抽象的な対比
- 本文1: 自分の失敗談
- 本文2: データの話
- 本文3: スピードの話
- 本文4: 他人の成功事例

→ 全て「売ることが大事」というメッセージだが、角度が全て違う

---

## 【禁止事項】

❌ **フックと本文で同じ表現を繰り返す**
- フックで「スキル磨き6ヶ月→売上ゼロ」→本文でまた「スキル磨き6ヶ月→売上ゼロ」

❌ **同じ数字を3回以上使う**
- 「初日1万円」が3回出てくる

❌ **同じ説明を別のセクションで繰り返す**
- 「データが取れる」セクションと「失敗しても改善できる」セクションで、同じ「どこで離脱したか」を2回説明

---

**繰り返しを避け、同じメッセージを別の角度で語れ。それが読者を飽きさせないコツ。**
