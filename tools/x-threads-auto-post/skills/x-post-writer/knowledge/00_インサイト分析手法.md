# インサイト分析手法

## 目的
**ターゲットの「本音」を暴き、刺さるターゲットコールを作る。**

---

## 【インサイトとは？】

**インサイト = ターゲットが口に出さない本音・潜在的な欲求**

- 表面的な悩み: 「時間がない」
- 本音: 「優先順位つけたくない」「全部やりたい」

- 表面的な悩み: 「スキルがない」
- 本音: 「学ぶのめんどくさい」「楽したい」

- 表面的な悩み: 「完璧にしてから出す」
- 本音: 「失敗が怖い」「批判されたくない」

---

## 【なぜインサイトが重要か？】

### 従来型ターゲットコール
```
月100万稼ぎたい人へ
```
→ 抽象的で刺さらない

### インサイト指定型ターゲットコール
```
「100点になってから出そう」とか言い訳して、実は失敗が怖いだけの奴へ
```
→ 「自分のことだ...」と刺さる

**刺さる理由:**
- 本人も気づいていない本音を指摘される
- 「見透かされてる」と感じる
- 「この人、わかってる」と共感する

---

## 【インサイトの見つけ方】3ステップ

### ステップ1: 表面的な悩みをリストアップ

**質問:**
「あなたのターゲットは、どんな悩みを口にしていますか？」

**例（AIトミーくんのターゲット）:**
- 「ライティングに時間がかかる」
- 「売れるコピーが書けない」
- 「AIは質が下がりそうで怖い」
- 「完璧にしてから出したい」
- 「外注しても期待通りにならない」

---

### ステップ2: 「なぜそう言うのか？」を掘り下げる

**質問:**
「その悩みの裏に、どんな本音が隠れていますか？」

**例:**
- 「ライティングに時間がかかる」
  - 本音: 「めんどくさい」「楽したい」「でも楽してると思われたくない」

- 「売れるコピーが書けない」
  - 本音: 「学ぶのがめんどくさい」「努力したくない」「答えだけ欲しい」

- 「AIは質が下がりそうで怖い」
  - 本音: 「自分のスキルが否定されるのが怖い」「手作業じゃないと認められないと思ってる」

- 「完璧にしてから出したい」
  - 本音: 「失敗が怖い」「批判されたくない」「恥をかきたくない」

- 「外注しても期待通りにならない」
  - 本音: 「自分でコントロールしたい」「他人を信用できない」「丸投げしたい」

---

### ステップ3: 潜在的欲求を特定する

**質問:**
「ターゲットは本当は何を手に入れたいのか？」

**例:**
- 「努力せずに結果だけ欲しい」
- 「寝てる間も自動で売れる仕組みが欲しい」
- 「家族との時間を最優先にしたい」
- 「『もう疲れた...』という苦痛から解放されたい」
- 「プロレベルの成果を一瞬で手に入れたい」
- 「競合を見下して『うちの方が圧倒的』と優越感に浸りたい」

## 【インサイトを使ったターゲットコール例】

### パターン1: 言い訳暴露型
```
「{表面的な言い訳}」とか言いながら、実は{本音}だけの奴へ
```

**例:**
- 「100点になってから出そう」とか言い訳して、実は失敗が怖いだけの奴へ
- 「AI使ったら質が下がる」とか言いながら、手作業で3時間かけてゴミ量産してる奴へ
- 「もう少し勉強してから」とか言って、1年前も同じこと言ってた奴へ

---

### パターン2: 矛盾指摘型
```
{理想}って言いながら、{現実の行動}してる奴へ
```

**例:**
- 「努力は美徳」とか言いながら、本当は楽して稼ぎたいだけの奴へ
- 「自分らしさが大事」とか言いながら、売れないコピー書き続けてる奴へ

---

### パターン3: 行動停止指摘型
```
{表面的な理由}で止まってる奴へ。お前、{期間}前も同じこと言ってたよね？
```

**例:**
- 「もう少し勉強してから」で止まってる奴へ。お前、1年前も同じこと言ってたよね？
- 「完璧にしてから」で止まってる奴へ。そのまま一生出さないの？

---

## 【インサイト分析の実例】

### ケース1: AIトミーくん

**ターゲット:** 毎日長時間ライティングに追われている経営者・起業家

**表面的な悩み:**
- ライティングに時間がかかる
- 売れるコピーが書けない
- AIは質が下がりそうで怖い

**本音:**
- 楽したい、努力したくない
- 失敗が怖い、批判されたくない
- 自分のスキルが否定されるのが怖い

**潜在的欲求:**
- 努力せずに結果だけ欲しい
- 寝てる間も自動で売れる仕組みが欲しい
- 競合を見下して優越感に浸りたい

**インサイト指定型ターゲットコール:**
- 「AI使ったら質が下がる」とか言いながら、手作業で3時間かけてゴミ量産してる奴へ
- 「100点になってから出そう」とか言い訳して、実は失敗が怖いだけの奴へ

---

### ケース2: ニッチ市場攻略（仮想例）

**ターゲット:** レッドオーシャンで消耗してる起業家

**表面的な悩み:**
- 競合が多すぎて売れない
- 差別化できない
- 広告費が高すぎる

**本音:**
- ニッチは怖い（市場が小さすぎて失敗しそう）
- レッドオーシャンの方が安全（みんなやってるから）
- 考えるのがめんどくさい（ニッチ探すの大変そう）

**潜在的欲求:**
- 競合ゼロで独占したい
- 広告費を安く抑えたい
- 楽に稼ぎたい

**インサイト指定型ターゲットコール:**
- 「ニッチは怖い」とか言いながら、レッドオーシャンで消耗してる奴へ
- 「差別化できない」とか言って、結局みんなと同じことやってる奴へ

