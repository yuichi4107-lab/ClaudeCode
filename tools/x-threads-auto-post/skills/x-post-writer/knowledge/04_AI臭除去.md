# AI臭除去ルール

## 目的
**本人が書いたと100%思われる文章にする。AI臭は即アウト。**

---

## 【AI臭とは?】

### AI臭がする文章の特徴

❌ 完璧すぎる文法・構成
❌ 均等な改行リズム
❌ 接続詞が多すぎる(そして、また、さらに、etc)
❌ 「〜が重要です」「〜がポイントです」の連発
❌ 絵文字が毎回同じ位置
❌ 感情の揺らぎがない(一定のテンション)
❌ 冗長さゼロ(人間はくどい)
❌ **AI臭い繋ぎ言葉**(完全禁止リスト下記参照)

---

## 【人間味の5大要素】必ず全て入れる

### 1. 失敗談を赤裸々に完璧じゃない自分をさらけ出す

```
✅ 良い例:
「私も何度それ系のミスしたかわからんくらいやらかしてるからわかる。」

❌ 悪い例:
「過去に失敗した経験があります。」
```

**ポイント:**
- 「何度」「わからんくらい」で生々しさ
- 「やらかしてる」で口語
- 完璧じゃない自分を見せる

---

### 2. 迷いや葛藤「本当はこう思ってた」という本音

```
✅ 良い例:
「↑これムズ!と思った人が237人いるな。」
「案件バレしそうだから伏せる。すまん。」

❌ 悪い例:
「難しいと感じる方もいらっしゃると思います。」
```

**ポイント:**
- 読者の心を代弁
- 「すまん」で本音
- 完璧に説明できない部分も隠さない

---

### 3. 口語表現「マジで」「めっちゃ」「正直」を適度に

```
✅ 良い例:
「めちゃ狭い内容でも必要な人にピンポイントで届く。」
「実力なくて無理w」

❌ 悪い例:
「非常に狭い内容でも、必要な人に届きます。」
```

**ポイント:**
- 「めちゃ」「マジで」「正直」
- 「www」「w」で煽り・皮肉
- 完璧な文章じゃなくていい

**注意:**
- 入れすぎNG。3000字で3-5箇所程度

---

### 4. 具体的な情景描写時間、場所、天気、その時の感情

```
✅ 良い例:
「先日、お客さんがこんな失敗を...」
「昔:制作→テスト→修正(数カ月経過)」

❌ 悪い例:
「以前、ある事例がありました。」
```

**ポイント:**
- 「先日」「昨日」「3年前」で時間
- 「お客さん」「俺」で具体性
- Before/Afterで対比

---

### 5. 自分だけの気づき一般論ではなく、個人的な発見

```
✅ 良い例:
「私の事例でいうと投資系でも悩みをめちゃくちゃコアに絞って、それをLPに書く。」

❌ 悪い例:
「一般的には、ターゲットを絞ることが重要です。」
```

**ポイント:**
- 「私の事例でいうと」で個人化
- 「めちゃくちゃコア」で口語
- 一般論を避ける

---

## 【NGワード】絶対に守る

### 1. 「〜が重要です」「〜がポイントです」

**使用制限: 1回まで**

```
❌ 悪い例:
「ターゲット選定が重要です。」
「ここがポイントです。」

✅ 良い例:
「ターゲット選定、ここミスったら終わる。」
「ここで全てが決まる。」
```

**代替表現:**
- 「〜が全て」
- 「〜で勝ち確定」
- 「〜ミスったら終わる」
- 「〜だけでいい」

- 「〜だけでいい」

---

### 2. 「お前」呼び

**使用禁止**

```
❌ 「お前は〜」
❌ 「お前ら」

✅ 「自分は〜」
✅ 「あなたは〜」
✅ (主語なし)「〜すればいい」
```

---

### 3. 専門用語のそのまま使用（FOMO等）

**使用禁止**

```
❌ 「FOMOを刺激する」
❌ 「LTVを高める」

✅ 「飢餓感を煽る」「渇望させる」
✅ 「客単価を上げる」「リピートさせる」
```

**理由:**
- 専門用語は「賢いふり」に見えて冷める。
- 直感的な日本語（身体感覚に訴える言葉）に変換せよ。

### 4. 「いかがでしたか?」

**使用禁止**

```
❌ 「いかがでしたか?」
❌ 「お分かりいただけましたか?」

✅ (そもそも締めの問いかけは不要。CTAに直行)
```

---

### 5. 「〜だと思います」

**使用制限: 1回まで。断定的に書く。**

```
❌ 悪い例:
「ニッチ市場が良いと思います。」
「おすすめだと思います。」

✅ 良い例:
「ニッチ市場一択。」
「これ以外ありえない。」
```

**代替表現:**
- 「〜から」で断定
- 体言止め
- 「〜だけ」「〜しかない」

---

### 6. 過度な記号や装飾(!!!、☆★など)

**使用禁止**

```
❌ 「これ超重要!!!」
❌ 「★必見★」

✅ 「これ超重要。」
✅ 「※注意※」
```

**許可される記号:**
- 「」かぎかっこ
- ※〜※
- !!は1箇所まで
- www、w

---

### 7. AI臭い繋ぎ言葉（完全禁止リスト）

**以下の繋ぎ言葉は絶対に使用禁止**

```
❌ 「現実はこう。」
❌ 「答えはシンプル。」
❌ 「じゃあどうやるか」
❌ 「これが現実」
❌ 「真実を教える」
❌ 「本質はこうだ」
❌ 「ポイントは3つ」
❌ 「結論から言うと」（例外：冒頭1回のみ許可）
❌ 「いかがでしょうか」
❌ 「お分かりいただけたでしょうか」
❌ 「ここで重要なのは」
❌ 「では次に」
❌ 「最後に」
❌ 「まとめると」
```

**✅ 代替表現（自然な繋ぎ）**
```
✅ いきなり本題に入る（繋ぎ言葉なし）
✅ 「で、」「じゃあ、」（口語的）
✅ 「いいか？」「わかる？」（問いかけ）
✅ 「↑はいメモ。」（指示）
✅ 「よくあるパターンと推奨方法を解説する。」（宣言）
```

**なぜ禁止か:**
- AIが多用する定型文
- 人間は「繋ぎ言葉」をあまり使わず、いきなり本題に入る
- 「現実はこう」「答えはシンプル」は説教臭くてウザい

## 【文体の揺らぎを作る】人間は完璧じゃない

### 1. 完璧すぎる文章を崩す

```
❌ AI臭い(完璧):
「ニッチ市場には3つのメリットがあります。1つ目は競合が少ないこと、2つ目はターゲットが明確なこと、3つ目は差別化が容易なことです。」

✅ 人間味(崩す):
「ニッチ市場の何がいいか。まず競合がいない。次にターゲットが明確。あと差別化も楽。」
```

**ポイント:**
- 「〜があります」を「〜がいいか」に
- 「1つ目、2つ目」を「まず、次に、あと」に
- 「〜があります」を「〜がいいか」に
- 「1つ目、2つ目」を「まず、次に、あと」に
- 文末を揃えない(いない/明確/楽)
- **「〜だ。〜である。」の連続はAI臭の極み。必ず「〜から」「〜だし」「〜でしょ？」を混ぜる。**

---

### 2. 改行リズムに不規則性

```
❌ AI臭い(均等):
ニッチ市場は競合が少ない。
ターゲットが明確である。
差別化が容易である。

✅ 人間味(不規則):
ニッチ市場の何がいいか。

まず競合がいない。レッドオーシャンだと投稿が流れるけど、ニッチなら検索したらあなたしか出てこない。

それで勝ち確定。
```

**ポイント:**
- 短文 → 長文 → 短文
- 空白行を不規則に入れる
- 文字数を揃えない

---

### 3. 接続詞の省略AIは接続詞を入れすぎる

```
❌ AI臭い(接続詞多い):
「まず競合が少ないです。そして、ターゲットが明確です。さらに、差別化も容易です。また、広告費も安いです。」

✅ 人間味(省略):
「まず競合がいない。ターゲットも明確。差別化も楽。広告費も安い。」
```

**ポイント:**
- 「そして」「さらに」「また」を削る
- 「〜も」で並列
- リズムを優先

---

### 4. 体言止めと倒置法の混在

```
❌ AI臭い(統一されすぎ):
「競合が少ないです。ターゲットが明確です。差別化が容易です。」

✅ 人間味(混在):
「競合がいない。ターゲットは明確。差別化も楽だから。」
```

**ポイント:**
- 体言止め + 「〜は」 + 「〜から」を混ぜる
- 語尾を統一しない

---

### 5. 意図的な冗長表現人間は時々くどい

```
❌ AI臭い(簡潔すぎ):
「ニッチ市場は競合が少なく、成功しやすい。」

✅ 人間味(適度に冗長):
「ニッチ市場の何がいいか。まず競合がいない。レッドオーシャンだと投稿が流れる。でもニッチなら、検索したらあなたしか出てこない。第一人者になれる。それで勝ち確定。」
```

**ポイント:**
- 1つの内容を2-3文で説明
- 「でも」「それで」で繋ぐ
- 簡潔すぎない

---

### 6. 感情の揺らぎテンション一定はAI臭い

```
❌ AI臭い(一定):
「ニッチ市場は有効です。競合が少ないです。ターゲットが明確です。」

✅ 人間味(揺らぎ):
「ニッチ市場の何がいいか。(落ち着き)

まず競合がいない。レッドオーシャンだと投稿が流れる。でもニッチなら、検索したらあなたしか出てこない。第一人者になれる。(説明)

それで勝ち確定。(断定)

↑これムズ!と思った人が237人いるな。でも安心して。(共感)」
```

**ポイント:**
- 落ち着き → 説明 → 断定 → 共感
- テンションに波を作る

## 【チェックリスト】AI臭除去の最終確認

### 人間味の5大要素
```
□ 失敗談を赤裸々に入れた
□ 迷い・葛藤・本音を入れた
□ 口語表現を適度に入れた(3-5箇所)
□ 具体的な情景描写を入れた
□ 個人的な気づきを入れた
```

### NGワード・NG表現回避
```
□ 「〜が重要です」を1回以内に抑えた
□ 「いかがでしたか?」を使っていない
□ 「〜だと思います」を1回以内に抑えた
□ 過度な記号(!!!)を使っていない
□ AI臭い繋ぎ言葉(「現実はこう」「答えはシンプル」等)を使っていない
□ 記号を全角に統一した(？！（）：％)
□ 同じ話を繰り返していない(別の角度で語っている)
```

### 文体の揺らぎ
```
□ 完璧すぎる文章を崩した
□ 改行リズムに不規則性を入れた
□ 接続詞を適度に省略した
□ 体言止めと倒置法を混在させた
□ 意図的な冗長表現を入れた
□ 感情の揺らぎを作った
```

### 文体DNA適用
```
□ STEP1で抽出した語尾パターンを再現
□ 口癖・決まり文句を反映
□ 改行リズムを再現
□ 強調の仕方を再現
□ 論理展開を再現
```
