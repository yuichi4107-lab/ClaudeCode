# GAS X自動投稿 セットアップ手順

## 必要なもの

- Google アカウント
- X（Twitter）Developer アカウント + APIキー 4つ
- Threads のアクセストークン（Threads に投稿する場合のみ）

> **X APIキーの取得方法** は [`docs/SETUP.md`](../../docs/SETUP.md) を参照してください。

---

## セットアップ手順

### Step 1: スプレッドシートを新規作成する

1. [Google スプレッドシート](https://sheets.google.com) を開く
2. 「**空白のスプレッドシート**」をクリックして新規作成
3. スプレッドシートのタイトルは任意（例: `X投稿管理`）

---

### Step 2: GAS スクリプトを貼り付ける

1. スプレッドシートのメニューから「**拡張機能**」→「**Apps Script**」を開く
2. エディタに最初から書かれているコードを**全て削除**する
3. このリポジトリの [`skills/gas-x-post/Code.gs`](./Code.gs) の内容を**全てコピーして貼り付け**る
4. **Ctrl+S**（Mac は Cmd+S）で保存する

---

### Step 3: スプレッドシートを自動セットアップする

1. GAS エディタ上部の関数リストから **`setupSpreadsheet`** を選択する

   ```
   ▶ 実行  [関数リスト▼]  ← ここをクリックして選ぶ
             postNextScheduledItem
             setupSpreadsheet     ← これを選ぶ
             setupTrigger
             dryRun
   ```

2. **▶（実行）ボタン**をクリックする
3. 初回は「**権限を確認**」画面が表示される → 自分のGoogle アカウントを選択 → 「**詳細**」→「**安全ではないページに移動**」→「**許可**」をクリック
4. 「セットアップ完了！」のダイアログが表示されれば成功

> スプレッドシートに `X投稿` シートが自動作成され、ヘッダー・チェックボックス・サンプルデータ（5件）が挿入されます。

---

### Step 4: APIキーを設定する

1. GAS エディタの左メニュー「**プロジェクトの設定**」（歯車アイコン）を開く
2. 下にスクロールして「**スクリプトプロパティ**」→「**プロパティを追加**」をクリック
3. 以下を1つずつ追加する：

| プロパティ名 | 値 | 取得元 |
|---|---|---|
| `X_API_KEY` | X の API キー | [docs/SETUP.md](../../docs/SETUP.md) |
| `X_API_SECRET` | X の API シークレット | 同上 |
| `X_ACCESS_TOKEN` | X のアクセストークン | 同上 |
| `X_ACCESS_TOKEN_SECRET` | X のアクセストークンシークレット | 同上 |
| `THREADS_ACCESS_TOKEN` | Threads のアクセストークン | ※Threads 投稿しない場合は不要 |
| `THREADS_USER_ID` | 空欄でOK | 初回実行時に自動取得されます |

4. 「**スクリプトプロパティを保存**」をクリック

---

### Step 5: 自動実行トリガーを設定する

1. GAS エディタの関数リストから **`setupTrigger`** を選択して実行する
2. 「トリガー設定完了」とログに表示されれば成功

> 30分ごとに自動で投稿時刻をチェックし、スケジュール通りに X / Threads へ投稿されます。

---

### Step 6: 動作確認（ドライラン）

1. 関数リストから **`dryRun`** を選択して実行する
2. ログに「次の投稿対象」が表示されれば正常に動作しています
3. 問題なければセットアップ完了です 🎉

---

## 投稿データの入力方法

スプレッドシートの `X投稿` シートに直接入力するか、Claude（X投稿くん）に依頼すると自動で書き込まれます。

| 列 | 内容 | 入力例 |
|---|---|---|
| A | 投稿日 | `2026/4/1` |
| B | 時 | `7`（0〜23） |
| C | 分 | `0`（0〜59） |
| D | 投稿内容 | ツイート本文 |
| E | X投稿する | チェックを入れる |
| F | Threads投稿する | チェックを入れる |
| G〜J | 画像URL（任意） | 画像の直リンクURL |
| K | 投稿済み | GASが自動更新（触らない） |
| L | X投稿URL | GASが自動記入（触らない） |
| M | Threads投稿URL | GASが自動記入（触らない） |

## よくあるエラー

| 症状 | 原因 | 対処 |
|---|---|---|
| 「シートが見つかりません」 | シート名が違う | シート名が `X投稿` になっているか確認 |
| 「X用APIキーが設定されていません」 | スクリプトプロパティ未設定 | Step 4 をやり直す |
| `403 Forbidden` | App Permissions が「Read」のまま | [docs/SETUP.md](../../docs/SETUP.md) の Step 3 をやり直す |
| `401 Unauthorized` | APIキーが間違っている | スクリプトプロパティの値を確認 |
| 投稿されない | 時刻が過去になっていない | 投稿日・時・分が現在より過去になっているか確認 |

---

## 仕組み（参考）

```
スプレッドシート（投稿データ）
        ↓
GAS（30分ごとに自動実行）
        ↓
時刻到達した行を1件処理
        ↓
X API / Threads API へ投稿
        ↓
投稿URLをシートに記録 → 投稿済みにチェック
```
