# ひらがな で あそぼう！ 🚛🦁

子どもがひらがなを覚えるための、ブラウザで動く学習ゲームです。
「はたらく くるま」や「どうぶつ」の絵を見て、その名前の **さいしょの ひらがな** を選んで遊びます。

## とくちょう
- **絵に合う文字を選ぶ** クイズ形式（タップ／クリック）
- **音声読み上げ**（ブラウザ標準の Web Speech API・日本語）で、文字が読めない子でも遊べる
- 絵は **絵文字** で表示。あとから本物の **画像に差し替え可能**
- **ビルド不要**・外部ライブラリなし。`index.html` を開くだけで動く
- スマホ／タブレットのタッチ操作対応

## ゲームの開き方（どちらでもOK）

### ① パソコンですぐ遊ぶ（ファイルを開くだけ）
1. GitHub のこのリポジトリで **Code → Download ZIP**（または PR #3 から）でファイル一式をダウンロード
2. ZIP を解凍する
3. `games/hiragana/index.html` を **ダブルクリック** してブラウザ（Chrome / Edge 推奨）で開く
4. 音が出ないときは、最初に画面を一度クリックしてください（ブラウザの自動再生制限の解除）

> 補足：このゲームは通信もインストールも不要なので、ファイルを開くだけで完全に動きます。

### ② URLで開く（GitHub Pages で公開）
スマホ・タブレット・パソコンのどれでも、同じURLで遊べるようになります。
1. リポジトリの **Settings → Pages → Build and deployment → Source** を **「GitHub Actions」** に設定（初回の一度だけ）
2. 数分待つと、次のURLで公開されます：
   **https://yuichi4107-lab.github.io/ClaudeCode/**
3. このURLをブックマークすれば、いつでもワンタップで開けます

> 公開は `.github/workflows/pages.yml`（GitHub Actions）が自動で行います。`main` または `claude/hiragana-learning-game-km4xpy` ブランチに変更が入るたびに更新されます。

### （開発者向け）ローカルサーバーで開く
```bash
cd games/hiragana
python -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

## 遊び方
1. 上記いずれかの方法でゲームを開く
2. 「はたらく くるま」「どうぶつ」「ぜんぶ」からカテゴリを選ぶ
3. 大きな絵が出て、名前が読み上げられる
4. 絵の名前の **さいしょの ひらがな** のボタンを選ぶ
   - 正解 → 「せいかい！」とお祝い、⭐ が増えて次の問題へ
   - まちがい → 「もういちど」、正解するまで再挑戦できる
5. 絵をもう一度タップすると、名前を読み上げ直す（聞き直し）
6. 🏠 ボタンでカテゴリ選択にもどる

## 絵文字を本物の画像に差し替える手順
1. `games/hiragana/assets/images/` フォルダを作り、画像（png / svg など）を置く
2. `js/data.js` の該当お題の `image` にパスを設定する
   ```js
   // 例：いぬ の絵を画像に差し替える
   { word: 'いぬ', answer: 'い', emoji: '🐶', image: 'assets/images/inu.png', category: 'animal' },
   ```
3. `image` が設定されていれば、絵文字より優先して画像が表示されます（`null` のままなら絵文字のまま）

## お題を追加・変更する
`js/data.js` の `ITEMS` 配列に項目を追加するだけです。
```js
{ word: 'ぱとかー', answer: 'ぱ', emoji: '🚓', image: null, category: 'vehicle' },
```
- `word`: 読み上げ・表示する単語（ひらがな）
- `answer`: 正解となる「さいしょの ひらがな」
- `emoji`: 表示する絵文字
- `image`: 画像パス（使わないときは `null`）
- `category`: `'vehicle'`（はたらくくるま）または `'animal'`（どうぶつ）

## 補足
- 音声は端末に日本語の音声が入っているときに再生されます。無い場合でも、絵と文字だけで遊べます。
- 最初のタップ以降に音声が有効になります（ブラウザの自動再生制限への対応）。
