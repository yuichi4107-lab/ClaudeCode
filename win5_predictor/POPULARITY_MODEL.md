# 人気分布ベース WIN5 モデル

JRA-VAN の WIN5 結果一覧（画像）から起こした「各レース当選馬の人気」だけを使う、
出走馬データ不要の軽量モデルです。既存の特徴量ベースシステム（`src/scraper`〜`src/model`）
とは独立して動きます。

## 何ができるか

- **人気分布の推定** — 1着になった馬が何番人気かの頻度から `P(1着 = k番人気)` を推定
- **買い目戦略** — 5レース一律に上位 r 番人気を買ったときの的中率・点数・費用・損益分岐配当
- **ROI バックテスト** — 実際の払戻金で各戦略の回収率を試算
- **メタ分析** — 人気が無くても、配当分布・難易度（票数との相関）・キャリーオーバー回を集計

## データ

`data/win5_results_2026.csv`（2026年1〜5月の28回・140レース、全て検証済み）。

| 列 | 内容 |
|----|------|
| date, race, grade | 日付・5レース目（メイン）のレース名・グレード |
| payout_yen | WIN5 払戻金（100円あたり）。空欄=不的中/キャリーオーバー |
| hit_tickets | 的中票数 |
| p1..p5 | 各レース当選馬の単勝人気順位（1=1番人気）。1〜5レース目の順 |
| pops_verified | 人気5つを検証済みか（True） |

回を追加するときは、各回の当選5頭の単勝人気を `p1`〜`p5` に入れ、`pops_verified` を `True` に。
全部埋める必要はなく、埋まった回だけでモデルは学習します。

## 実行

```bash
cd win5_predictor
pip install pandas numpy        # 既存 requirements.txt でも可
python run_popularity.py        # data/win5_results_2025.csv を読む
python run_popularity.py path/to/other.csv
```

人気が未入力でもメタ分析は出ます。人気が入っている回があれば分布・戦略・ROI も出力します。

## モデルの考え方

各レースは必ず1頭が1着になるので、勝ち馬の人気の頻度分布は
「ランダムに選んだ1レースで k 番人気が勝つ確率」の推定量になります。
WIN5 は5レース独立とみなし、上位 r 番人気で買うときの的中率は
`P(1着が上位r人気以内)^5`、点数は `r^5`。これを払戻と突き合わせて回収率を評価します。

## 限界

- 出走馬の能力差・展開・馬場などは一切見ていません（人気のみ）。
- 28回・最大140レースと少数のため、分布推定の分散は大きめ。回を足すほど安定します。
- 5レースを独立・同一分布と仮定（実際はレース毎に頭数や堅さが異なる）。
  本格運用は既存の特徴量ベースモデル（netkeiba スクレイピング）へ。

## 単勝オッズで組み立てるモデル（推奨）

人気順だけより、**対象レースの単勝オッズ**を使うほうが情報量が多く実用的です。
`src/popularity/odds.py` に実装。

### 考え方
1. **オッズ → 暗黙勝率**: `q_i = (1/odds_i) / Σ(1/odds_j)`。割り算で控除率（オーバーラウンド）を除去。
2. **人気-穴バイアス補正（任意）**: `p_i ∝ q_i^β`（β>1 で本命寄り）。既定 β=1.0。
3. **買い目最適化**: 各レースで「どの馬を買うか」を点数（予算）制約下で的中確率最大に貪欲選択。
   人気が割れたレースに手広く、堅いレースは絞る配分に自動でなる。
4. **人気順**: オッズ並び順との不一致検出に使用（入力ミス検知）。

### 使い方
```bash
# data/sample_target_odds.csv を当日の実オッズに差し替えて実行
python run_odds.py data/target_odds.csv --budget 10000 --beta 1.0
```
入力 CSV 列: `race(1..5), umaban, odds, horse(任意), pop(任意)`。

出力: 各レースの暗黙勝率、買い目フロンティア（点数 vs 的中率 vs 損益分岐配当）、
予算内の推奨買い目。学習データ不要で当日のオッズだけで完結する。

### 限界
- 暗黙勝率は「市場が正しい」前提。バイアス補正 β は実データで較正していない（既定 1.0）。
- 全出走馬の単勝オッズを買う直前に入力する必要がある。
