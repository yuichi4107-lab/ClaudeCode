# サーキットブレーカー仕様書

**バージョン**: 1.0
**作成日**: 2026-04-12
**対象プロジェクト**: FX自動売買 Phase 1

---

## 概要

サーキットブレーカーは「想定外の損失拡大を自動停止するセーフガード機構」である。
4種のトリガー条件を定義し、いずれかが発火した場合に所定の動作（戦略停止・ロット縮小・アラート送信）を実行する。

実装は工程Cで行う。本書は仕様のみを定義する。

---

## トリガー一覧

### CB-1: 連敗N回 トリガー

| 項目 | 内容 |
|------|------|
| **トリガー名** | 連敗N回 (Consecutive Loss Stop) |
| **監視対象** | 同一戦略の連続損失回数 |
| **閾値** | N = 5 回（推奨値。`portfolio_config.json` の `consecutive_loss_limit` で設定可） |
| **発火条件** | ある戦略が同一取引セッション内（1日）で連続5回損失を記録した場合 |
| **動作** | その戦略のシグナル生成を当日中停止する。翌営業日の取引開始時に自動再開する |
| **対象範囲** | 発火した戦略のみ。他戦略への影響なし |
| **リセット条件** | 翌営業日の取引開始時（00:00 JST）に連敗カウンターをリセット |
| **実装ヒント** | 戦略ごとに `consecutive_loss_count` カウンターを保持し、勝ちトレードで 0 リセット |

---

### CB-2: 月次ドローダウン閾値 トリガー

| 項目 | 内容 |
|------|------|
| **トリガー名** | 月次DD閾値 (Monthly Drawdown Limit) |
| **監視対象** | 月初残高に対するドローダウン率 |
| **閾値** | -10%（推奨値。`portfolio_config.json` の `monthly_dd_limit_pct` で設定可） |
| **発火条件** | 当月の口座残高が月初残高から -10% 以上低下した場合 |
| **動作** | 全戦略のシグナル生成を即時停止。残りの月末まで全シグナルを無視する（ノートレードで月末を迎える） |
| **対象範囲** | 全戦略 |
| **リセット条件** | 翌月1日の取引開始時に月初残高を更新しカウンターをリセット |
| **実装ヒント** | `monthly_start_balance` を月初に記録し、毎トレード後に `(current_balance - monthly_start_balance) / monthly_start_balance` を計算 |

---

### CB-3: 累積ドローダウン閾値 トリガー

| 項目 | 内容 |
|------|------|
| **トリガー名** | 累積DD閾値 (Cumulative Drawdown Limit) |
| **監視対象** | 運用開始残高（またはピーク残高）に対する累積ドローダウン率 |
| **閾値** | Sim環境: -25%、Live環境: -20%（`portfolio_config.json` の `cumulative_dd_limit_pct` で設定） |
| **発火条件** | 口座残高がピーク（最高値）から 25%（Sim）または 20%（Live）以上低下した場合 |
| **動作** | 全戦略を即時停止し、オーナーへのアラート通知を送信する。自動再開はしない（オーナー判断が必要） |
| **対象範囲** | 全戦略 |
| **リセット条件** | オーナーによる手動解除のみ |
| **アラート内容** | 発火日時・現在残高・ピーク残高・ドローダウン率・直近10トレードのサマリー |
| **実装ヒント** | `peak_balance` を都度更新し、`(current_balance - peak_balance) / peak_balance` を監視 |

---

### CB-4: 月末ポジション縮小 トリガー

| 項目 | 内容 |
|------|------|
| **トリガー名** | 月末縮小 (End-of-Month Reduction) |
| **監視対象** | 月末5営業日前時点での当月損益 |
| **閾値** | 当月リターン = 0%（当月がマイナスまたはゼロの場合に発火） |
| **発火条件** | 月末5営業日前（月末の第5営業日前から月末まで）の時点で、当月の口座残高が月初残高を下回っている場合 |
| **動作** | ロットサイズを通常計算値の 50% に削減する。月末まで縮小モードを継続する |
| **対象範囲** | 全戦略（新規エントリーのロットサイズのみ。既存ポジションには影響なし） |
| **リセット条件** | 翌月1日の取引開始時に自動解除 |
| **実装ヒント** | `position_sizing.calculate_lot_size()` に `reduction_mode: bool` フラグを渡し、True の場合はロットを 0.5 倍にする |

## 優先度と相互作用

複数のサーキットブレーカーが同時に発火した場合の優先度:

```
優先度高 CB-3（累積DD） > CB-2（月次DD） > CB-4（月末縮小） > CB-1（連敗）
```

- CB-3 が発火している間は CB-1・CB-2・CB-4 はすべて無効（全停止が最優先）
- CB-2 が発火している間は CB-1・CB-4 は無効（月内全停止が優先）
- CB-4 は CB-3・CB-2 が発火していない状態でのみ有効

## 設定値（portfolio_config.json での対応キー）

```json
{
  "circuit_breaker": {
    "consecutive_loss_limit": 5,
    "monthly_dd_limit_pct": 10.0,
    "cumulative_dd_limit_pct": 25.0,
    "end_of_month_reduction_threshold_pct": 0
  }
}
```

| キー | 型 | 説明 | 推奨値 |
|------|----|------|--------|
| `consecutive_loss_limit` | int | CB-1 の連敗閾値 N | 5 |
| `monthly_dd_limit_pct` | float | CB-2 の月次DD閾値（正値で %） | 10.0 |
| `cumulative_dd_limit_pct` | float | CB-3 の累積DD閾値（正値で %） | 25.0（Sim）/ 20.0（Live）|
| `end_of_month_reduction_threshold_pct` | float | CB-4 の発動閾値（0=当月マイナスなら発動） | 0 |
