## 発見・修正したバグ
- **モーダルがクリックを奪う**: `#modal` に CSS で `display:flex` 指定があり、`hidden` 属性（既定 `display:none`）を上書きしてしまい、非表示のはずのモーダルが全画面オーバーレイとして残存。開始画面の大名カードがクリックできなかった。
  - 修正: `styles.css` に `[hidden] { display: none !important; }` を追加し、hidden 属性を最優先化。開始/ゲーム画面の切替も堅牢化。
- main.js の未使用 import `hasSave` を除去（軽微なクリーンアップ）。

## 最終レビューで修正した項目（仕様内）
- **同盟破棄ロジックを実装**（spec §7.4）: `maybeBreakAlliances` を `endTurn` 冒頭で実行。国力が2倍以上傾けば50%、通常8%で破棄。最後の相手と同盟して勝利不能になるソフトロックを解消。
- **balanced/defensive AIも徴兵するよう修正**: 兵力が `RECRUIT_MIN`(1500)未満の弱小守備は補充。非攻撃的大名が痩せ細る偏りを是正。
- **同盟国への「出陣」ボタンを非表示化**（render.js）: 同盟先は出陣対象から除外。

## 既知の挙動・今後の調整候補（仕様内）
- 出陣は出撂元の全兵を動員するため、本拠でも空になると即座に奪われうる（今回、尾張の全軍で三河を攻めた隙に浅井へ尾張を奪われた）。リスク選択として機能しているが、駐留兵を残すオプションは将来拡張候補。
- 勝敗モーダル（全国統一/自家滅亡）は victory ロジックをユニットテスト済み・モーダル表示も修正済みだが、実ゲームでの到達確認は長時間プレイが必要なため未到達（ロジックは検証済み）。
- 山岳・城防御の国（美濃等）は守りが堅く、正面攻撃は失敗しやすい（バランスは想定どおり）。
