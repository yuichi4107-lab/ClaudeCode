# キャロットクラブ出資検討 (2026年度募集)

過去3年(2020〜2022年募集)の全276頭のデビュー後成績を netkeiba から照会し、
出資検討基準を導出して2026年度募集馬94頭を採点したプロジェクト。

## 成果物

- **キャロット2026検討.xlsx** — メインの検討資料
  - `募集馬一覧`: 確定94頭(2026/8/1確定・8/18測尺反映)。価格・測尺・予定厩舎・母年齢・産駒数・基準スコア(6点満点)・スコア内訳
  - `検討基準`: 過去276頭の分析から導出したスコア基準と厩舎相性
  - `過去募集馬成績`: 2020-22年募集276頭の成績・回収率・スコア(答え合わせ用)

## スコア基準 (各1点・6点満点)

| 条件 | 根拠(過去276頭) |
|---|---|
| 牡馬 | 勝ち上がり74% vs メス56% |
| 3〜4月生まれ | 3月74% vs 2月55% |
| ノーザンF生産 | 重賞勝ち16頭すべてノーザンF系 |
| 母年齢8〜11歳 | 勝ち上がり67%・回収≥1が30%でピーク |
| 募集総額2500〜5999万円 | 2500-3999万帯が回収最良。8000万+は回収率最低 |
| 募集時馬体重430kg以上 | 430未満のメスは勝ち上がり42% |

過去実績: スコア6=勝ち上がり100%(12頭) / スコア5=82% / スコア4=67% / 3以下=55%

## ディレクトリ

- `scripts/` — netkeiba照会・Excel生成スクリプト(レート制限3秒・HTMLキャッシュ付き)
- `data/` — 照会結果データ
  - `roster.csv`: 過去3年の募集馬276頭(検討Excelから抽出)
  - `final_results.json`: 276頭のnetkeiba成績(父名照合で全頭検証済み)
  - `dams2026_v3.json`: 2026年募集馬の母情報(母馬ID基準で産駒数を確定)
  - `kakutei.json`: 2026年確定94頭(確定PDF由来)

## 注意

- 回収率 = 賞金(中央+地方) / 募集総額。進上金・維持費・メスの繁殖価値は未考慮
- 2022年募集世代は現役馬が多く数値は今後変動する
- netkeibaのHTMLキャッシュ(`nk_cache/`)はコミット対象外
